## 概述

**Owly** 将交易员发现、跟单、交易终端和自动化策略整合到 [Hyperliquid](https://hyperliquid.xyz)。通过账户管理连接交易钱包或受支持的协议账户；网站 Assistant 可以解释现有操作流程。

  <Card title="面向跟单者" icon="users" href="/zh/introduction/who-is-owly-for#跟单者">
    查看交易员历史，按所选账户和风险设置配置自动跟单。

## 核心使命

我们相信，获取复杂交易策略的机会不应仅限于专业交易员。Owly 通过以下方式实现交易民主化：

<Steps>
  <Step title="发现">
    浏览并分析平台上已验证交易员的业绩数据。
  </Step>
  <Step title="连接">
    添加 API 钱包账户、Hyperliquid 原生子账户或 LeverAcc 账户，并完成必要授权。
  </Step>
  <Step title="监控">
    查看机器人状态、成交、持仓和收益，检查风险设置并按需停止策略。
  </Step>
</Steps>

## 主要功能

| 功能 | 当前行为 |
| --- | --- |
| **交易员发现** | 通过探索页面查看业绩与风险指标 |
| **跟单交易** | 按账户配置策略、市场过滤和组合风险阈值 |
| **Trade 终端** | 手动交易、内嵌资金操作和 Ghost 只读观察 |
| **网格机器人** | 独立交易机器人页面的永续中性、做多和做空网格 |
| **账户管理** | 自动生成 API 钱包授权、原生子账户设置和 LeverAcc（Alpha） |
| **投资组合** | 账户价值、盈亏、考虑资金流的收益率和操作历史 |

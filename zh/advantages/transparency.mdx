Owly 使用 Hyperliquid 的账户、仓位、成交及账本数据展示交易活动并计算业绩。交易记录可以结合底层账户地址核对，Owly 的统计结果则取决于所选范围和可用历史。

## 如何阅读数据证据

<AccordionGroup>
  <Accordion title="基于账户的历史">
    查看交易员地址及可用交易历史，不必仅依赖交易员自己的介绍。比较记录时，请选择相同市场和时间窗口。
  </Accordion>
  <Accordion title="查看统计范围">
    永续盈亏、全账户价值与 NAV 收益率衡量的内容不同。充值、提现、手续费和资金费都可能造成差异。
  </Accordion>
  <Accordion title="数据可用性">
    实时更新、缓存历史和后端计算的刷新时间可能不同。缺失、加载中或不完整数据，不能解释为零活动，也不能视为历史一定完整。
  </Accordion>
</AccordionGroup>

## 我们追踪的指标

## 数据来源

| 数据类型 | 来源 | 核对重点 |
| :--- | :--- | :--- |
| 成交与交易历史 | Hyperliquid 数据及后端交易重建 | 地址、市场、时间戳及已加载历史范围 |
| 仓位与余额 | 通过实时更新和快照请求取得的 Hyperliquid 账户数据 | 账户模式、估值范围和数据时效 |
| 业绩指标 | 根据账户历史、交易及账本资金流计算 | 公式、所选期间、可支持资金流及数据缺失提示 |
| 交易费用 | 交易所成交费用字段，包括存在时的 Builder 手续费 | 区分交易所手续费与平台 Builder 手续费 |
| 跟单配置与策略状态 | Owly 保存的配置和策略状态数据 | 策略是否活跃，以及已保存的具体设置 |

业绩计算和策略配置本身并不是不可篡改的智能合约记录。经过四舍五入或汇总的指标，也无法仅凭某一笔交易复现。

## 独立核对

使用账户地址在 Hyperliquid 中检查活动，再用相同市场、周期和统计范围与 Owly 对比。核对跟单策略时，应同时比较源账户和跟单账户；资金规模、手续费、执行时间和筛选条件不同，都可能产生不同结果。

<Note>
历史记录帮助进行有依据的比较，不能保证未来收益或精确复制表现。页面只能展示当前可取得的历史与数据来源。
</Note>

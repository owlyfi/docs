Owly 通过钱包签名和授权交易密钥连接账户。资金所有权与交易密钥的保管是两回事：你控制资金所属钱包，已授权的 API 钱包则可执行交易，并可能造成亏损。

## 账户与密钥角色

| 角色 | 当前行为 |
| --- | --- |
| **Owly 登录钱包** | 登录并管理账户，也可以同时作为交易资金所有者 |
| **交易资金钱包／主钱包** | 持有或控制资金账户，签署需要所有者确认的授权和提现 |
| **跟单 API 钱包** | 开户时由 Owly 生成并保存，用于签署已授权的策略操作 |
| **Trade 终端 API 钱包** | 当前 Trade 界面将其持久化保存在本设备浏览器中 |
| **LeverAcc 执行钱包** | 通过协议项目绑定授权，抵押和债务遵循 LeverAcc 规则 |

三种开户路径见[账户类型](/zh/guide/account-types)。API 钱包路径不要求先创建 Hyperliquid 原生子账户。

## 授权允许什么

API 钱包可签署受支持的交易操作，包括开仓和平仓；它不能替代资金所属钱包的对外提现签名。这也不意味着代理钱包没有任何协议内部资金操作权限。

签名前核对连接的所有者地址、API 钱包地址、有效期、Builder 费用上限及合约交易。充值和换币还可能需要单独的代币授权；代币授权额度与换币报价的支出上限不同。

<Warning>
交易 API 密钥泄露可能导致恶意交易和亏损。资金非托管不能消除市场亏损、清算、恶意交易或协议故障风险。
</Warning>

## 保护和撤销权限

- 不要将助记词、资金钱包私钥或交易 API 密钥发送给 Assistant、客服或聊天工具。
- 仅在可信设备上使用 Trade 授权。清除浏览器存储可能删除本地交易凭据及待确认操作恢复记录，但不会撤销 Hyperliquid 上的授权。
- 停止受影响的机器人，检查剩余仓位和委托。撤销 API 钱包时，由所属主钱包前往 [Hyperliquid API 页面](https://app.hyperliquid.xyz/API)操作。
- 重新启动前更新 Owly 对应授权。LeverAcc 使用专用的执行钱包更新流程。
- 移除 Owly 基金经理会收回管理权限，不会自动停止机器人，也不会撤销协议授权。

资金入口及所有者签名见[资产管理](/zh/guide/asset-management)，委托范围见[资产所有者指南](/zh/guide/owner-guide)。

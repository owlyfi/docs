## 钱包与交易密钥安全

资金所属钱包由你控制，自动策略使用的 API 密钥由 Owly 生成并保存。当前 Trade 终端会将 API 交易授权持久化保存在本设备浏览器中。不要向 Assistant 或客服发送任何私钥和助记词。参见[非托管安全](/zh/advantages/non-custodial)。

API 钱包不能替代所有者的对外提现签名，但能执行造成亏损的交易。核对签名钱包及权限范围，发现泄露时由所属钱包撤销授权。停止机器人、移除经理和撤销 API 钱包是不同操作。

## 交易风险

| 风险 | 含义 |
| --- | --- |
| **市场与杠杆** | 价格变化、资金费和清算可能减少或耗尽账户权益 |
| **跟单执行** | 延迟、流动性、最低委托额、市场过滤和可用抵押品会使成交及仓位与来源不同 |
| **风险阈值** | 须自行配置止损止盈；监控和平仓可能失败，或在越过阈值后以更差价格成交 |
| **网格敞口** | 方向网格可能累积仓位，价格也可能离开设定区间 |
| **数据限制** | 收益和回放依赖可用历史、账户统计范围和数据时效 |

历史结果不保证未来表现。排名、模拟和 Ghost 只读观察，都不能保证策略适合你或能够成功复制。

## 资金与协议风险

- 签名前检查当前路径使用的网络和代币。内嵌 Trade 资金流程支持 Arbitrum One 主网，LeverAcc 还涉及 HyperEVM。
- 分别核对 Gas、换币、跨链/CCTP、激活及协议费用。
- 提交结果不明时，先检查已有操作，不要重复发送。
- 合约、跨链桥、交易所、钱包软件及上游服务都可能出现故障；公开源码本身不代表已通过安全审计。
- LeverAcc 抵押借贷涉及利息和清算风险，停止交易或平仓不会自动还债。

## 出现异常时

1. 停止受影响的自动化，检查持仓和未成交委托。
2. 由资金所属钱包撤销或更换受影响的交易授权；LeverAcc 使用专用执行钱包更新流程。
3. 继续转账前核对待确认资金操作和交易哈希。
4. 通过 [Telegram 客服](https://t.me/owlyfi_support)或 [security@owly.fi](mailto:security@owly.fi)提供公开地址、问题时间及脱敏证据，不要在公开群聊发送秘密或漏洞细节。

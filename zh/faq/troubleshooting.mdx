## 钱包与开户

| 现象 | 检查事项 |
| --- | --- |
| 钱包无法连接 | 解锁钱包，检查站点权限和冲突插件，确认目标地址后重试 |
| 签名钱包不正确 | 对比 Owly 登录、交易所有者和资金钱包地址；这些地址可以不同，应切回当前步骤要求的钱包 |
| API 钱包设置要求充值 | 资金所属地址尚未在 Hyperliquid 激活；先完成内嵌充值并等待激活，再启用统一账户和 API 授权 |
| 所有者地址被拒绝 | 使用资金所属的 Hyperliquid 用户钱包，不能使用代理、金库或原生子账户地址 |
| 没有可选原生子账户 | 核对登录主钱包并刷新列表，只有资格和数量检查通过后才能使用创建选项 |
| 已达账户上限 | 三种受支持类型共用最多 10 个有效 Owly 交易账户的上限 |
| API 钱包授权失败 | 核对有效期和 Hyperliquid API 钱包剩余名额，再由正确主钱包完成待处理授权 |

Owly 登录会话过期与 Hyperliquid 交易授权过期不同：前者重新连接并签名登录，后者需更新账户交易授权。

## 充值、换币与提现

- **使用正确入口。** Trade 操作当前登录资金钱包；账户管理中的 API 钱包和原生子账户按钮引导前往 Hyperliquid；LeverAcc 使用内嵌界面。参见[资产管理](/zh/guide/asset-management)。
- **网络或资产不符：**内嵌 Trade 流程使用 Arbitrum One 主网，以 USDC 入金，可先将 USDT 换成 USDC。LeverAcc 所需 HYPE 位于 HyperEVM。核对交易实际网络和代币。
- **没有可用换币报价：**Gasless 依赖服务配置、受支持授权方式、余额和新报价。没有报价时，应自行准备所需资产。
- **ETH 已到但仍缺 HYPE：**LeverAcc 独立检查两种资产；完成剩余准备步骤，再检查余额。
- **提交待确认或结果不明：**恢复原操作并检查状态，按提示提供源交易哈希；结果明确前不要重复发送。
- **提现被拒绝：**核对资金所属钱包、统一账户模式、可提现余额和实时费用。Trade 提现金额须同时大于 0.2 USDC 和适用费用。
- **充值未显示：**核对资金账户地址、源链交易和目标余额。钱包提交成功不代表 Hyperliquid 已入账。

## 策略与账户访问

| 现象 | 检查事项 |
| --- | --- |
| 旧版托管账户不能启动机器人 | 该类型已停止启动、重启和配置更新；处理剩余策略并使用受支持的提现路径 |
| LeverAcc 无法开始跟单 | 核对项目绑定、执行钱包授权、资金及当前开放状态；该类型不支持复制挂单 |
| 网格中找不到 LeverAcc | 当前网格机器人账户选择器不包含 LeverAcc |
| 交易未复制 | 核对机器人状态、授权有效期、可用抵押品、启用市场、币种过滤、最低委托额和来源活动 |
| 仓位或入场价不同 | 跟单比例、行情变化、取整、过滤条件及保证金余额都会影响执行 |
| 已移除经理但机器人仍运行 | 移除管理权限不会停止机器人，须由所有者单独停止或关闭 |
| 网格追踪控件不可用 | 当前界面未开放区间追踪，后端保留字段不代表此处可启用 |

止损止盈不是自动填好的默认保护，须检查实际保存的设置。参见[风险管理](/zh/advantages/risk-management)。

Owly 允许资产所有者添加经理并选择交易管理权限。**经理授权覆盖该所有者名下全部活跃交易账户，包括以后新增的账户。** 这是所有者与经理之间的关系，不是对某一个子账户单独分配。

## 准备交易账户

以资产所有者身份登录 [Owly](https://app.owly.fi/accounts)。普通交易账户可按[快速入门](/zh/guide/quick-start)配置 API 钱包，也可按下方流程添加 Hyperliquid 原生子账户。Owly 的统一账户数量上限与 Hyperliquid 的原生子账户条件分别计算，详见[账户类型](/zh/guide/account-types)。

### 添加 Hyperliquid 原生子账户

1. 使用拥有该原生子账户或将用于创建子账户的 Hyperliquid 主钱包登录。
2. 打开账户管理，选择 **新建跟单账户**，再选择 **Hyperliquid 子账户**。
3. 选择已有子账户。符合条件时，也可在同一表单选择 **创建子账号**，输入不重复且不超过 16 个字符的名称，按提示完成授权与创建。该流程会先准备或复用所需的普通 API 钱包授权。继续前核对签名钱包地址和创建结果。
4. 若创建结果尚未确认，先刷新子账户列表核对原请求，不要直接重复创建。
5. 填写账户显示名称并继续。使用主钱包核对并完成必要的统一账户启用、专用 API 钱包授权和 Builder 费用授权。
6. 等待完成并核对所选交易账户地址。无需输入或复制私钥。

您也可以先在 [Hyperliquid](https://app.hyperliquid.xyz/subAccounts) 创建符合条件的原生子账户，再回到 Owly 选择。原生子账户仍受支持。旧版 Owly 托管钱包属于另一种账户类型，已禁用新建、新配置机器人和重启机器人。

<Note>
原生子账户没有自己的私钥，由所属主钱包授权 API 钱包。Owly 为每次导入生成专用 API 钱包以减少共享 Nonce 冲突；这不等于在 Hyperliquid 协议层将该代理限制为只能操作一个子账户。
</Note>

## 添加经理

经理必须是已注册 Owly 的 EVM 地址，不能是本人，也不能重复添加。每位所有者最多添加 **20 位经理**。

1. 在账户管理找到 **管理账户**，选择 **添加管理账户**。
2. 输入经理已注册的钱包地址，可填写备注昵称。
3. 核对 **查看**、**启动** 和 **停止** 权限。默认三项均勾选，只保留您希望授予的权限。
4. 确认后，经理可在 **我管理的子账户** 中按所获权限访问您的账户。

<Warning>
此操作授权的是所有者名下全部活跃账户，也包括未来新增账户。确认前请核对完整范围；在该所有者下另建一个交易子账户，不会把经理权限缩小到该子账户。
</Warning>

## 权限范围

| 权限 | 允许的操作 |
| --- | --- |
| **查看（`VIEW`）** | 在受支持管理页面查看账户与策略信息 |
| **启动（`START`）** | 启动或重启受支持的机器人 |
| **停止（`STOP`）** | 停止机器人，或请求终止及清理 |

机器人配置修改使用启动/停止权限校验，没有独立的经理“修改配置”权限开关。经理权限不包含提现、修改账户所有权或设置、添加其他经理等所有者操作；账户类型限制和钱包授权仍然适用。

API 钱包用于已授权的交易签名。外部充值与提现仍需资金钱包或主钱包承担相应签名角色。API 钱包泄露仍可能通过恶意交易造成亏损。LeverAcc 账户的抵押、债务、还款及协议提现由 LeverAcc 管理；停止机器人不等于还款。

## 监控与停止交易

在账户管理和投资组合中查看余额、持仓、订单、盈亏与机器人状态。除生命周期状态外，也应核对执行和清理状态。

- **停止**会停止自动执行，本身不平掉已有持仓。
- **关闭／终止**请求终止策略并清理持仓和相关订单。请确认清理结果及实际持仓，不要假定每次关闭都会成功。
- 清理进行中或失败时需要继续处理。确认剩余风险前，应保留账户所需保证金。

## 修改或移除经理

在经理卡片选择 **编辑**，修改备注昵称或权限；选择 **移除**，撤销该所有者对这位经理的授权。

**移除经理不会自动停止运行中的机器人、平仓、撤单或撤销 Hyperliquid API 钱包授权。** 如果希望结束交易，请由所有者逐个停止或关闭相关机器人，并核对状态及剩余风险。移除一位经理也不会取消其他经理的权限。

如果怀疑 API 钱包泄露，请先停止受影响的自动交易，再使用所属主钱包到 [Hyperliquid API 页面](https://app.hyperliquid.xyz/API)核对授权，并按 Owly 账户管理流程授权替换钱包。不要把助记词或任何私钥发送给 Assistant、客服或经理。

## 常见问题

<AccordionGroup>
  <Accordion title="能否只给经理分配一个交易账户？">
    当前经理关系覆盖所有者名下的活跃账户。在同一所有者下另建原生子账户，不会把授权范围限制为这个账户。
  </Accordion>
  <Accordion title="为什么添加经理失败？">
    检查 EVM 地址及注册状态，并确认不是本人或已添加的经理。每位所有者上限为 20 位经理。
  </Accordion>
  <Accordion title="为什么不能创建原生子账户？">
    按表单返回的资格和数量限制处理，也可选择已有子账户。若创建尚未确认，请先刷新检查，避免重复创建。
  </Accordion>
  <Accordion title="经理能提走资金吗？">
    Owly 的查看、启动、停止权限不授予提现或转账权限。此类操作由所有者钱包及账户所在协议的规则控制。
  </Accordion>
</AccordionGroup>

## 步骤 1: 准备工作

### 1.1 注册 Owly 账户

<Steps>
  <Step title="访问 Owly 官网">
    前往 [app.owly.fi](https://app.owly.fi)
  </Step>
  <Step title="连接主钱包">
    点击 "Connect Wallet" 连接您的主钱包
  </Step>
  <Step title="完成签名验证">
    签名验证消息以确认钱包所有权
  </Step>
  <Step title="注册成功">
    完成注册，进入 Owly 平台
  </Step>
</Steps>

### 1.2 确认基金经理已注册

<Check>基金经理必须已注册为 Owly 用户</Check>
<Check>获取基金经理的钱包地址</Check>

<Warning>
如基金经理未注册，分配将失败。
</Warning>

## 步骤 2: 准备 Hyperliquid 子账户

### 2.1 前置条件

<Note>
新建原生子账户需满足 [Hyperliquid 当前创建条件](https://hyperliquid.gitbook.io/hyperliquid-docs/trading/sub-accounts)。已有子账户可直接按下方流程导入。
</Note>

### 2.2 创建 Sub Account

<Steps>
  <Step title="访问 Hyperliquid">
    前往 [app.hyperliquid.xyz](https://app.hyperliquid.xyz)
  </Step>
  <Step title="连接钱包">
    连接您的主钱包
  </Step>
  <Step title="进入 Sub Accounts">
    在菜单中找到 Sub Accounts
  </Step>
  <Step title="创建 Sub Account">
    点击 Create Sub Account，输入名称并确认创建
  </Step>
</Steps>

### 2.3 由 Owly 自动生成 API 钱包

导入前无需去 Hyperliquid 创建 API 钱包或保存私钥。Owly 会为每个导入的子账户自动生成并安全保存专用 API 钱包，再由所属主钱包在下一步签名授权。

<Note>
独立 API 钱包可减少共享 Nonce（交易序号）造成的冲突，但不等于在协议层将 API 钱包限制为只能操作一个子账户。详见[账户类型指南](/zh/guide/account-types)。
</Note>

## 步骤 3: 导入 Sub Account 到 Owly

### 3.1 进入添加页面

<Steps>
  <Step title="登录 Owly">
    使用拥有该 Hyperliquid 子账户的主钱包登录 Owly
  </Step>
  <Step title="进入子账户管理">
    在导航中找到 **子账户管理**
  </Step>
  <Step title="添加 Sub Account">
    点击 **新建跟单账户**，然后选择 **Hyperliquid 子账户**
  </Step>
</Steps>

### 3.2 选择 Sub Account

Owly 会自动获取您的 Sub Account 列表，选择要导入的 Sub Account。

### 3.3 设置名称并生成 API 钱包

填写账户名称并继续。如果主账户尚未启用统一账户（Unified Account），先核对并签署 Owly 的启用请求。随后 Owly 自动生成并保存专用 API 钱包，无需输入私钥。

### 3.4 授权并确认导入

核对生成的 API 钱包公开地址和当前连接的主钱包，由 **所属主钱包**签署 API 钱包授权及必要的 Builder 费用授权。已确认的授权会被跳过。等待导入成功，再检查所选子账户地址。

原生子账户没有自己的私钥，不要在此流程输入主钱包私钥或助记词。

## 步骤 4: 分配给基金经理

<Steps>
  <Step title="进入子账户管理">
    在 Owly 中进入 **子账户管理**
  </Step>
  <Step title="选择 Sub Account">
    选择要分配的 Sub Account
  </Step>
  <Step title="分配基金经理">
    点击 **分配基金经理**
  </Step>
  <Step title="输入地址">
    输入基金经理的钱包地址
  </Step>
  <Step title="确认分配">
    确认分配
  </Step>
</Steps>

<Note>
如果基金经理未注册 Owly，分配将失败并提示"该地址未注册"。
</Note>

## 步骤 5: 日常管理

### 查看账户状态

进入 **子账户管理** 查看所有账户，包括持仓、盈亏、Bot 运行状态。

### 停止 Bot

<Steps>
  <Step title="选择账户">
    选择 Sub Account
  </Step>
  <Step title="停止 Bot">
    点击 **停止 Bot**
  </Step>
  <Step title="完成">
    Bot 将停止执行新交易
  </Step>
</Steps>

### 解除基金经理分配

<Steps>
  <Step title="选择账户">
    选择 Sub Account
  </Step>
  <Step title="解除分配">
    点击 **解除分配**
  </Step>
  <Step title="确认">
    确认后，基金经理失去管理权限，关联的 Bot 会自动停止
  </Step>
</Steps>

### 紧急撤销 (链上操作)

如需完全撤销 API Key:

<Steps>
  <Step title="访问 Hyperliquid">
    前往 Hyperliquid
  </Step>
  <Step title="进入 Sub Account">
    进入对应 Sub Account
  </Step>
  <Step title="撤销 API">
    删除/撤销 API Key
  </Step>
</Steps>

## 权限与安全说明

### API Key 技术限制

| 限制 | 说明 |
|:-----|:-----|
| **权限范围** | API Key 可签名操作主账户及所有 Sub Account |
| **Nonce 机制** | 每个 API Key 使用独立的 Nonce 序列 |
| **共享签名风险** | 多个账户共用 API 钱包会共享交易序号状态，可能发生冲突 |
| **Owly 要求** | 每个 Sub Account 必须使用独立的 API Key |

### API 钱包与资金操作

API 钱包用于已授权的交易签名。资金转账或提现应由资产所有者在 Hyperliquid 的受支持流程中本人核对并完成。API 钱包泄露可能导致恶意交易和资金亏损；不能把无提现权限理解为资金绝对安全。密钥输入边界与账户区别见[账户类型指南](/zh/guide/account-types)。

### 基金经理权限

分配给基金经理后，其可以：

| 操作 | 权限 |
|:-----|:-----|
| 配置和启停 Copy Trade Bot | ✅ 允许 |
| 查看持仓和盈亏 | ✅ 允许 |
| 提现或转出资金 | ❌ 不允许 |
| 修改账户设置 | ❌ 不允许 |
| 分配给其他人 | ❌ 不允许 |

### 安全建议

<Warning>
1. **核对钱包授权**：导入时由 Owly 自动生成并保管 API 钱包；任何私钥或助记词都不要发送给 Assistant、客服或聊天
2. **每个 Sub Account 使用独立 API 钱包**，导入时由 Owly 自动创建
3. **只分配给您信任的基金经理**
4. **定期检查交易记录**，发现异常及时停止 Bot
5. **如怀疑 API 泄露**，立即在 Hyperliquid 撤销
</Warning>

### 风险提示

| 场景 | 风险 | 您的控制手段 |
|:-----|:-----|:-------------|
| 基金经理策略亏损 | 资金减少 | 停止 Bot、解除分配 |
| 高杠杆操作 | 爆仓风险 | 监控持仓、及时干预 |
| API Key 泄露 | 恶意交易 | 在 Hyperliquid 撤销 API |
| 市场极端行情 | 大幅亏损 | 提前设置止损 |

## 常见问题

<AccordionGroup>
  <Accordion title="无法创建 Sub Account">
    检查 [Hyperliquid 当前创建条件](https://hyperliquid.gitbook.io/hyperliquid-docs/trading/sub-accounts)；若只是添加普通 API 钱包账户，无需先创建原生子账户
  </Accordion>
  <Accordion title="导入失败提示 Builder Fee 未设置">
    回到导入表单，使用子账户所属主钱包按页面提示完成必要授权；不要使用旧版授权测试页面
  </Accordion>
  <Accordion title="找不到我的 Sub Account">
    确认使用的是创建 Sub Account 的主钱包
  </Accordion>
  <Accordion title="分配失败提示该地址未注册">
    基金经理需先注册 Owly 账户
  </Accordion>
  <Accordion title="基金经理能提走我的资金吗">
    不能，API Key 无提现权限
  </Accordion>
  <Accordion title="为什么每个 Sub Account 要单独的 API">
    共享 API 钱包会共享交易序号状态，可能冲突；Owly 要求每个导入子账户单独配置 API 钱包
  </Accordion>
</AccordionGroup>

# Owlyfi 邀请分佣系统

分享邀请码或邀请链接，邀请好友使用 Owly。符合条件的交易活动可以产生直接（L1）和间接（L2）返佣，被邀请用户也可能享有一段时间的平台交易手续费折扣。

## 等级与返佣结构

邀请系统支持 Normal、Advanced 和 VIP 等级。各等级的手续费贡献门槛、L1 与 L2 返佣比例、好友折扣、折扣期限和邀请名额上限由当前适用配置决定。这些规则可能调整，因此本文不使用固定表格代表所有正在生效的规则。

自动等级评估依据你直接邀请的有效用户（L1）产生的累计合格 Builder 手续费。部分账户可能适用指定等级或单独调整的邀请名额。请在**邀请分佣**页面查看当前等级、邀请名额使用情况、可提现奖励和返佣记录。

返佣按**符合条件的成交记录中实际收取的 Builder 手续费**乘以适用返佣比例计算。好友支付的手续费降低后，返佣的手续费基数也可能随之降低，不能仅用交易量确定返佣金额。

## 好友折扣说明

绑定邀请关系时，系统按邀请人的适用等级规则确定折扣到期时间。该折扣期限与浏览器保存邀请码的归因期限是两回事。

- 折扣期内，符合条件且由 Owly 管理费率的策略可以自动应用较低的 Builder 手续费。
- 折扣比例取决于邀请人当前适用的等级配置，并非一定锁定为注册时的比例。
- 折扣通过减少交易时收取的费用体现，不会生成一笔需要好友单独提现的现金返还。
- 使用独立 Builder 费率配置的策略可能适用其他规则，请在交易前确认实际费率。

有关实际交易费与 Builder 授权上限的区别，请参阅[费用结构](/zh/faq/fees)。

## 邀请归因逻辑

Owly 在注册前采用**同一浏览器内的首次接触归因**：

1. 访问有效邀请链接后，首个邀请码保存在浏览器 Cookie 中，最长保留 **30 天**。
2. 该 Cookie 有效期间，后续邀请链接不会覆盖它；已登录用户访问邀请链接也不会更换现有邀请人。
3. 注册时尝试使用保存的邀请码。无效邀请码可能被拒绝，但不会因此阻止用户注册。

Cookie 不等于永久账户绑定：清除 Cookie、到期或更换浏览器、设备后，原先保存的归因可能丢失。账户一旦已有邀请人，普通绑定流程不允许更换；如果注册时没有绑定邀请人，符合条件的用户可以在邀请分佣页面补填一次邀请码。

邀请码由 **4–16 位字母、数字、下划线或连字符**组成。绑定还需通过邀请码有效性、剩余邀请名额和邀请资格检查。

## 结算与提现

系统通过定时结算流程，根据已记录的 Builder 手续费计算奖励，再加入可用返佣余额。记录出现的时间受结算调度和上游数据可用性影响，成交后不会立即生成可提现返佣。

邀请关系可能先处于 `pending` 状态，待记录到符合条件且产生手续费的交易活动后再激活。邀请分佣页面分别展示邀请用户、已交易用户、返佣记录和提现历史。

### 如何提现

1. 打开**邀请分佣**页面，查看可提现返佣余额。
2. 输入不超过该余额的金额。当前提现表单要求至少 **1 USDC**，实际适用规则可能要求更高的最低金额。
3. 提交申请。申请金额会先从可用返佣余额中扣除，进入后续处理流程。
4. 在提现历史中跟踪结果，核对最终状态和交易凭证。

| 状态 | 含义 |
| :--- | :--- |
| `pending` | 已提交，等待审核 |
| `approved` | 已批准，等待处理 |
| `processing` | 正在处理 |
| `completed` | 已记录为完成 |
| `rejected` / `failed` | 审核拒绝或处理失败，请查看记录详情 |

<Note>
提交申请不等于立即完成链上转账。请以提现记录确认结果，本文不承诺固定到账时间。
</Note>

## 分佣计算示例

仅作说明：假设一位符合条件的好友产生了 **$5 实际 Builder 手续费**，适用的 L1 返佣比例为 30%，则你的返佣为 `$5 × 30% = $1.50`。另一位符合条件的用户产生 $2 实际手续费，适用 L2 比例为 5%，则 L2 返佣为 `$2 × 5% = $0.10`。

示例比例不代表当前等级规则。实际金额请以适用规则和已结算返佣记录为准。

## 参与条件

系统拒绝自我邀请和循环邀请关系。邀请码也受使用次数限制，除非适用等级或账户名额另有安排。请勿使用虚假账户或人为制造的活动绕过邀请规则。

资金操作前先核对 **账户地址**、**网络**和 **币种**。API 钱包是交易签名代理，不是资金账户，也不是充值目标。

## 选择正确入口

| 账户或入口 | 当前资金操作方式 |
| --- | --- |
| **Trade 交易终端** | **充值**和 **提现**操作当前登录钱包自己的 Hyperliquid 账户 |
| **API 钱包开户** | 尚未激活的交易钱包可通过内嵌充值流程激活 Hyperliquid 账户，再继续授权 |
| **账户管理中的 API 钱包账户** | 资金按钮引导前往 Hyperliquid，须连接实际交易钱包 |
| **账户管理中的 Hyperliquid 子账户** | 由所属主钱包在 Hyperliquid 完成充值或划转 |
| **链上借贷（Alpha）** | **充值**、**还款**、**提现**、**借款**和 **资金划转**打开内嵌 LeverAcc 界面 |
| **旧版 Owly 托管账户** | 已停止新增充值和一般内部转账；使用受支持的提现流程转回所有者 |

Trade 终端不会切换到任意跟单账户。若资金账户地址与当前登录地址不同，应使用该账户对应的受支持流程。参见[账户类型](/zh/guide/account-types)。

## 通过 Trade 终端充值

1. 打开 **Trade → 充值**，确认当前连接的是资金所属钱包。
2. 选择 **Arbitrum One 主网**上的 **USDC** 或 **USDT**。转入 Hyperliquid 的资产为 USDC；选择 USDT 时，先按准备步骤换成 USDC。
3. 按表单显示的要求准备源钱包余额。ETH 不足时，如果 Gasless 服务已配置且有受支持报价，页面可提供 USDC 换 ETH 的步骤。
4. 分别核对报价、代币授权额度、网络费、CCTP 费用和预计到账金额。首次激活 Hyperliquid 地址还需页面显示的 **1 USDC 激活费**。充值金额须高于适用费用；源钱包准备门槛不等于通用最低充值额。
5. 本人逐步签名，等待目标确认及 Hyperliquid 余额入账后再交易。

API 钱包开户遇到尚未激活的交易钱包时，也可进入同一内嵌充值流程；交易钱包可以与 Owly 登录钱包不同。

<Note>
换币使用你自己的资产：USDT 换 USDC 消耗 USDT，准备 ETH 消耗 USDC。“Gasless”不代表免费赠送 Gas。换币支出上限与代币授权额度是两回事；即使换币支出有上限，报价仍可能请求无限代币授权。
</Note>

## 通过 Trade 终端提现

**提现**将 **USDC 发送到当前资金钱包的 Arbitrum One 地址**。Hyperliquid 账户须已激活且处于统一账户模式。提现金额须 **大于 0.2 USDC**、高于实时提现费，并且不超过可提现余额。这不代表所有高于 0.2 USDC 的金额都可提现。

核对收款地址、网络、金额、费用和预计到账后，由资金所属钱包签名。API 交易代理不能替代所有者的提现签名。等待收款余额核验完成；请求提交不代表已到账。

## 待确认或中断的资金操作

保持原钱包和网络，使用 **检查状态**或恢复已有操作。页面提供 **查找交易**时，可核验已有的源链交易。结果不明时不要重复转账；报价在提交前过期时，应获取并核对新报价。

保留浏览器存储以支持待确认操作恢复。联系客服时，只提供公开地址、网络、问题时间和交易哈希，不要提供助记词或私钥。

## LeverAcc 资金与债务

LeverAcc 创建流程会按需检查 **Arbitrum USDC 和 ETH**，以及 **HyperEVM HYPE**。ETH 与 HYPE 的准备步骤使用页面显示的独立 USDC 预算。抵押、借款、还款和提现须遵循内嵌界面的协议规则。

停止跟单不会自动还款，平仓也不代表抵押品已全部释放或债务清零。提现或更改项目绑定前，须单独确认债务及还款状态。

## 费用和余额

资金操作可能涉及 Gas、换币、跨链/CCTP、激活及协议费用，以实时报价为准。不能对所有路径统一承诺固定到账时间或“只收网络 Gas”。参见[费用结构](/zh/faq/fees)。

**账户价值**与 **可提现余额**不同。持仓、保证金、现货抵押和借贷都会影响可提现金额。对比 Owly 和 Hyperliquid 时，应使用同一资金账户地址，不要使用 API 钱包地址。

在 **机器人 → 网格交易** 打开[网格交易页面](https://app.owly.fi/trading-bots/grid)，登录后管理 Bot。

## 当前支持范围

网格编辑器支持永续市场，提供 **中性、做多、做空** 三种方向、**等差、等比** 两种价格算法，以及 **全仓、逐仓** 保证金模式。还可以设置触发价、方向初始仓位，以及策略止盈价和止损价。

<Note>
此编辑器暂不支持现货网格。向上、向下移动网格的控件虽然可见，但目前被禁用。独立[交易终端](/zh/guide/trading-terminal)下单菜单里的网格选项也仅为预览；管理网格 Bot 请使用网格交易页面。
</Note>

## 选择可用账户

先在[账户管理](https://app.owly.fi/accounts)创建或导入账户，再返回网格交易。创建时的账户选择器要求账户有可读取的正数可用余额，且没有运行中的 Bot。已经配置为其他 Bot 类型的账户会被排除。

- **API 钱包**和 **Hyperliquid 子账户**满足上述条件时可以使用。
- **链上借贷 / LeverAcc** 账户不出现在网格账户选择器中。
- 旧版 **Owly 托管子账户**不能再修改 Bot 配置或启动 Bot。请通过仍支持的提现流程，把剩余资金迁移到自托管账户。

未出现在选择器中的账户仍可能存在于账户管理中。先检查账户类型、余额和已有 Bot 配置，再决定是否需要新增账户。

## 配置网格

点击**创建**，选择账户和合约交易对，再核对以下字段。

| 字段 | 含义 |
| --- | --- |
| 方向 | 中性、做多或做空 |
| 保证金模式和杠杆 | 全仓或逐仓，杠杆受所选市场的上限约束 |
| 区间下限和上限 | 网格运行价格区间，上限必须高于下限 |
| 网格数量 | 区间划分数量；至少 2 格，受预估可用挂单额度约束 |
| 投入金额 | 分配给整个网格的总资金，支持两位小数；必须大于 0 且小于账户可用余额 |
| 价格算法 | 等差为固定价格差，等比为固定价格比例 |
| 触发价 | 可选；开启后，价格达到所选上破或下破条件才开始运行 |
| 初始仓位 | 做多、做空模式可用，中性模式下禁用 |
| 止盈价 / 止损价 | 可选的策略级价格阈值，命中后发起风险退出 |
| 同步周期 | 检查并同步挂单的间隔，表单初始值为 15 秒 |

页面根据市场和区间预估最低投入、单档数量和每格利润。这些仅是估算；能否启动和成交仍受交易所最小下单金额、精度、费用、可用保证金和实时价格约束。

<Warning>
增加网格数量会把投入分配到更多订单。网格越多不代表利润越高，也可能使单档订单低于交易所最低要求。请为亏损和费用预留可用保证金。
</Warning>

## 方向与初始仓位

**中性**模式在参考价下方挂买单、上方挂卖单，不会自动建立方向底仓。

**做多**通过买单增加多头敞口，用仅减仓卖单减少敞口；**做空**通过卖单增加空头敞口，用仅减仓买单减少敞口。两种方向模式都可以开启初始建仓。启动前核对已有仓位；方向不兼容或保证金不足可能导致无法激活。

## 保存、启动与停止

1. **保存**只保存配置，不启动 Bot。
2. 使用启动操作，核对确认弹窗，再确认启动。如果保存成功但启动失败，配置仍已保存；检查错误和状态后再重试。
3. 持续查看运行状态、账户余额、挂单和持仓。配置已保存或请求已受理，不代表每档订单都已成交。
4. 修改前先停止 Bot；运行中的网格在编辑器中为只读状态。
5. 停止弹窗中的**同时关闭所有仓位**默认勾选。取消勾选会请求停止但保留持仓；保留勾选会请求停止并平仓。两种操作后都应核对最终挂单和持仓。

止盈、止损触发后，Bot 会离开正常网格维护流程并发起风险退出。执行可能延迟、被拒绝或部分成交。停止、平仓请求或风险阈值均不能保证立即成交或固定最终亏损。

## 界面配置与 API 兼容字段

当前表单把总投入提交为 `total_invest`，不要求填写单档 `order_size` 或独立的 `bootstrap_size`。历史配置可能仍包含这些字段，请勿把旧版单档数量示例当作当前投入金额。

新网格配置使用 `account_mode: "auto"`，已有配置明确指定模式时会保留原值。编辑器没有账户模式选择器；这与添加账户时可能要求开启统一账户模式是不同步骤。

请求保留 `trailing_up_limit`、`trailing_down_limit` 的兼容能力，也可以读取历史移动网格值。但当前界面的两个移动网格控件均被禁用，新建表单默认保持 `0`。后端接受或保留某个字段，不等于用户可以在编辑器中开启它。`rebalance_tolerance_bps` 等后端参数同样不是当前可编辑的表单控件。

账户准备见[账户类型](/zh/guide/account-types)，交易成本见[费用](/zh/faq/fees)。

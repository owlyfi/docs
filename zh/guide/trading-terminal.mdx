通过 **交易** 打开 [app.owly.fi/trade](https://app.owly.fi/trade)，查看行情图、订单簿、最近成交和账户信息，并从终端当前提供的永续、现货市场中选择交易对。

## 使用哪个账户交易？

在自己的交易终端中，交易地址就是**已完成 Owly 登录认证的钱包地址**，不使用跟单账户选择器。在跟单开户弹窗中连接另一个交易钱包，不会切换终端的交易身份。

Owly 使用 Privy 连接外部钱包。当前仅支持钱包登录，不创建内嵌钱包，也不提供邮箱或社交账号登录。充值、提现和交易前都要核对显示的地址及网络。

## 完成交易授权

终端会检查账户激活状态、统一账户模式、Builder 授权和 API 钱包连接。请在**交易设置**中完成页面提示，并逐项核对钱包请求。

1. 钱包尚未在 Hyperliquid 激活时，先完成充值流程并等待确认到账。
2. 按提示开启统一账户模式。
3. 核对并完成 Builder 授权。已经确认的配置可以复用；页面会提示不可用或尚未确认的步骤。
4. 授权此终端使用的 API 钱包。授权过期或发生变化时，使用设置中显示的恢复操作。

授权完成后，终端可能使用已授权代理为尚无推荐人的账户尝试可选的 Hyperliquid 推荐设置。已有推荐关系会保留；该可选步骤失败不会阻断交易就绪。

终端会将已授权的 API 交易密钥保存在本设备浏览器中，供后续访问使用。当前 Trade 界面要求持久化本地交易连接，没有仅保留当前标签页的切换选项。此设备存储与跟单开户时由 Owly 生成、管理的 API 钱包不同。更换授权可能使其他浏览器或设备需要重新授权。

<Warning>
只在自己控制的设备上使用交易终端。API 钱包可以签署交易操作，密钥被盗仍可能造成交易损失。请勿在 Owly、助手或客服聊天中输入主钱包私钥或助记词。
</Warning>

## 从 Arbitrum 充值

内置资金流程目前仅支持 **Arbitrum One 主网**。资金来自所选钱包在 Arbitrum 上的 **USDC 或 USDT**，最终通过 CCTP 向该钱包的 Hyperliquid 账户充值 USDC。

- 选择 USDT 时，先兑换为 USDC。
- 使用 USDC 但 ETH 不足以支付 Gas 时，在服务可用且有支持的报价条件下，可以使用 USDC 兑换 ETH。
- 兑换和充值需要分别核对。兑换完成不代表 Hyperliquid 已充值到账。
- 此流程不把 API 签名钱包、金库或原生子账户地址作为资金所有者钱包充值，请按账户类型提示操作。

最初的源钱包余额检查要求：已激活账户至少持有 **1 个所选代币**，未激活地址至少持有 **2 个所选代币**。这是余额检查门槛，不保证以该数额就能充值成功。最终充值金额必须大于**当前 CCTP 费用与账户激活费之和**；兑换和 Gas 也需要足够资金。签名前以页面的费用报价和预计到账金额为准。

创建 API 钱包跟单账户时，也可能出现同一充值组件。该场景充值到**开户弹窗中明确选择的交易钱包**，它可以与登录钱包不同，详见[快速开始](/zh/guide/quick-start)。

## 提现到 Arbitrum

终端将 **USDC 提现到当前连接钱包在 Arbitrum One 上的同一地址**，表单不提供任意收款地址输入框。

钱包必须是已激活的 Hyperliquid 用户，并已开启统一账户模式。提现金额必须同时满足：

- **大于 0.2 USDC**；
- 大于当前协议提现费用；
- 不超过扣除所需提现 Gas 预留后的当前可用金额。

因此，实际最低金额取决于实时费用和账户状态。请核对费用和预计到账金额。提交请求不代表完成：流程会核对交易和目标到账证据，再显示已验证完成。若仍为等待或结果不确定，请使用同一钱包检查原操作，再决定是否重新提交。确认完成后会返回终端的**转账**历史标签页。

## 下单与账户历史

终端提供市价、限价和 TWAP 下单。下单菜单中的网格选项目前为预览，不能提交；独立网格 Bot 请使用[机器人 → 网格交易](/zh/guide/grid-bot)。

选择市场、方向、价格或运行时长、数量及可用的风控设置，再核对确认弹窗。市场精度、保证金、最小下单金额和当前行情数据均可能限制操作。账户面板提供余额、持仓、挂单、TWAP、成交历史、资金费历史、订单历史和转账记录。选择某个市场不代表账户历史中所有记录都属于该市场；可执行操作会另外检查。

## 用 Ghost 模式查看其他地址

在交易员详情页点击地址链接，可以打开该公开账户的终端。链接格式如下：

```text
https://app.owly.fi/trade?ghost=0x1111111111111111111111111111111111111111
```

请把示例替换为有效的 42 字符 EVM 地址。Ghost 模式为**只读**：可以浏览市场及该地址可读取的公开余额、持仓、挂单和历史，不能替该地址下单、撤单、充值或提现。点击跟单操作会进入该交易员的跟单流程，仍需另选自己的账户并确认。

使用 Ghost 退出控件返回自己的终端。Ghost 地址格式无效时会显示错误，不会自动改为另一个账户。

## 先了解 Hyperliquid API 钱包

Hyperliquid 的 **API 钱包**也叫 **Agent 钱包**，是由主账户授权的签名代理。它可以代表该主账户或其名下的原生子账户签署受支持的交易操作。**生成或授权一个 API 钱包，不会新建一个 Hyperliquid 主账户，也不会为它单独划出交易资金。** 查询余额、持仓和盈亏时，应使用实际主账户或子账户的地址，而不是 API 钱包地址。参见 [Hyperliquid API 钱包官方说明](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/nonces-and-api-wallets#api-wallets)。

API 钱包授权不提供资金钱包的入金签名能力，也不能代表主账户提现到外部钱包。入金由持有资金的钱包发起；提现需要主钱包签名。API 钱包不是充值目标。这里区分的是对外入金和提现，不能理解为 API 钱包没有任何协议内部资金操作权限。相关流程见 [Hyperliquid 入金说明](https://hyperliquid.gitbook.io/hyperliquid-docs/onboarding/how-to-start-trading)和[提现接口](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/exchange-endpoint#initiate-a-withdrawal-request)。

<Warning>
API 钱包泄露仍可能导致恶意交易和资金亏损。不要向 API 钱包充值，也不要把它当作独立持有跟单资金的账户。
</Warning>

## 再区分 Owly 登录身份与交易账户

Owly 的“子账户”是用于管理交易账户的统称，创建页面直接展示 **API 钱包**、**Hyperliquid 子账户** 和 **链上借贷（Alpha）** 三种类型。Hyperliquid 子账户可以导入已有原生子账户，也可以在主账户符合资格时新建；链上借贷通过内嵌界面创建或接入 LeverAcc 协议账户。

- **Owly 主账户**：用于登录 Owly 和管理账户。
- **交易账户**：实际持有 Hyperliquid 交易资金和仓位的账户。
- **API 钱包**：为交易账户签名的授权代理，不是上述交易资金账户。

**Owly 主账户和交易账户可以是同一个钱包地址。** 如果希望分开管理，也可以用一个地址登录 Owly，再添加另一个地址作为交易账户。采用独立地址时，要分别核对登录地址、资金账户地址和签名地址；同一地址时无需为了添加账户另建第二个钱包账号。

**三种类型共用同一 Owly 主账户下最多 10 个有效交易账户的上限。** 例如，API 钱包和 Hyperliquid 子账户共 9 个，再加上 1 个有效的链上借贷账户，就已达到上限。下文 Hyperliquid 原生子账户的创建资格和数量额度另行计算。

## 三种类型怎么选

| 类型 | 适合的情况 | 添加前准备 | 需要注意 |
|:--|:--|:--|:--|
| **API 钱包** | 希望使用自己控制的 Hyperliquid 主账户交易；适合大多数新用户 | 用于交易的钱包，在 Owly 中连接并签名授权 | 每个交易账户对应独立的 Hyperliquid 主账户地址；它可以与 Owly 登录地址相同 |
| **Hyperliquid 子账户** | 希望在主账户下管理 Hyperliquid 原生子账户 | 所属主钱包，以及已有子账户或创建资格；专用 API 钱包由 Owly 自动生成 | 新建时须通过 Hyperliquid 的资格与数量检查 |
| **链上借贷（Alpha）** | 希望通过 LeverAcc 抵押资产借入 USDC 后交易 | 准备设置页要求的 USDC 和 Gas 资产的资金钱包，或已有 LeverAcc 交易账户 | 处于 Alpha 阶段；创建、绑定、借款和启动策略是分开的操作 |

## API 钱包数量限制与清理

每个 Hyperliquid 主账户默认最多可授权 **3 个有名称的 API 钱包**，使用该主账户的不同应用共用这些名额。Hyperliquid 另外允许 1 个未命名 API 钱包，每个原生子账户还会增加 2 个有名称的 API 钱包名额。参见 [Hyperliquid API 钱包数量规则](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/exchange-endpoint#approve-an-api-wallet)。这一授权数量限制与上文 Owly 的交易账户数量限制分开计算。

如果新增或更新 API 钱包时提示数量已达上限：

1. 前往 [Hyperliquid API 页面](https://app.hyperliquid.xyz/API)，连接拥有该授权的主钱包。Hyperliquid 子账户应使用其所属主钱包。
2. 核对 API 钱包的名称和地址，删除或撤销不再需要的授权。不要删除 Owly 或其他应用仍在使用的 API 钱包，否则对应应用将无法继续使用该授权交易。
3. 确认已释放名额后，返回 Owly 重试创建 API 钱包或更新授权。

## API 钱包有效期与更新

Hyperliquid 官方规定，API 钱包授权的有效期**最长为 180 天**。这是授权的有效期，不是交易账户的使用期限。参见 [Hyperliquid API 钱包授权规则](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/exchange-endpoint#approve-an-api-wallet)。

Owly 默认使用以下有效期：

| 账户类型 | API 钱包默认有效期 |
|:--|:--|
| API 钱包 | **180 天** |
| Hyperliquid 子账户 | **180 天** |
| 链上借贷（LeverAcc，Alpha） | 接入页当前提示 **90 天**，以核验后的实际到期时间为准 |

<Warning>
对于 **API 钱包和 Hyperliquid 子账户**，授权进入到期前 **10 分钟**窗口后，定时检查会尝试终止运行中的机器人。这项检查不覆盖 LeverAcc，也不保证精确停止时间或成功清理全部持仓。请提前更新授权，确认核验后的新到期时间，并检查机器人状态及剩余仓位。
</Warning>

## Owly 的 API 钱包类型

这一类型使用的是**独立的 Hyperliquid 主账户，即一个 EVM 资金地址**，不是 Hyperliquid 原生子账户。若要添加多个这类交易账户，应分别准备不同的主账户地址，而不是给同一个主账户多建几个 API 钱包。这些交易账户中的一个可以直接使用 Owly 登录地址；“独立”并不要求它与登录地址不同。

选择 **API 钱包**后，填写账户名称，点击 **连接**并选择你的 Hyperliquid 交易钱包。核对页面显示的地址；它可以与 Owly 登录地址相同。如果地址尚未在 Hyperliquid 激活，按充值提示完成入金并等待激活后再继续。代理钱包、金库和原生子账户地址不能作为此类型的资金主钱包。此设置流程不要求填写 API 钱包私钥。

Owly 会检查交易账户是否启用 **统一账户（Unified Account）**，未启用时先请求签名启用。随后 Owly 自动生成并安全保存 API 钱包，展示其公开地址，再由当前连接的交易钱包签名授权。若还需要 **Builder 费用授权**，核对费率上限后完成签名。已经确认的授权会被跳过。

<Info>
生成的 API 交易密钥由 Owly 管理，主钱包仍由你控制。余额、持仓和盈亏对应交易账户地址，不要向 API 钱包充值。新增账户无需先去 Hyperliquid API 页面手动创建钱包，也无需复制或导入 API 钱包私钥。
</Info>

第一次使用时，按照[快速入门](/zh/guide/quick-start)完成准备、充值、连接钱包和签名授权。

## Hyperliquid 子账户

这是 Hyperliquid 主账户名下的**原生子账户**，与上面的独立主账户不同。根据 [Hyperliquid 官方规则](https://hyperliquid.gitbook.io/hyperliquid-docs/trading/sub-accounts)，主账户达到 **100,000 美元交易量**后，可创建最多 **10 个**子账户；之后每增加 **100,000,000 美元交易量**可增加 1 个，最高 **50 个**。因此，10 个是基础额度，不是 Hyperliquid 的最终硬上限。这一额度与上文 Owly 的账户数量限制分开计算。

先使用拥有原生子账户的 Hyperliquid 主钱包登录 Owly，再选择 **Hyperliquid 子账户**。Owly 会读取该登录主钱包下的子账户列表。选择要导入的已有子账户并填写名称。Owly 检查主账户的统一账户模式，按需请求启用签名，再自动生成并保存本次导入专用的 API 钱包。核对生成的 API 钱包地址，由 **所属主钱包**完成 API 钱包授权及必要的 Builder 费用授权。无需去 Hyperliquid 手动创建 API 钱包，也不需要填写私钥。已添加的子账户不能重复选择。

当 Owly 确认主账户符合资格且仍有名额时，也可以直接从选择器创建原生子账户。填写有效且未使用的账户名称并选择创建选项。按需先完成主账户的 API 钱包授权，用于提交原生子账户创建；等待 Hyperliquid 确认新账户后，再继续导入并授权该子账户的专用 API 钱包。无法创建时，核对当前主钱包，并到 [Hyperliquid 子账户页面](https://app.hyperliquid.xyz/subAccounts)检查资格。

<Warning>
Hyperliquid 原生子账户没有自己的私钥；不要寻找或填写“子账户钱包私钥”。API 钱包由所属主账户授权。Owly 会为每个导入子账户自动创建独立 API 钱包，以减少共享交易序号造成的冲突；这不等于该 API 钱包在协议层被限制只能操作这个子账户。参见 [Hyperliquid 子账户签名说明](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/exchange-endpoint#subaccounts-and-vaults)和 [API 钱包说明](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/nonces-and-api-wallets#api-wallets)。
</Warning>

需要委托基金经理时，继续阅读[资产所有者指南](/zh/guide/owner-guide)。

## 链上借贷（Alpha）

**链上借贷**通过 LeverAcc 抵押资产借入 USDC 后用于交易。在账户类型选择中直接选择 **链上借贷（Alpha）**即可进入。

<Warning>
该类型目前处于 **Alpha 阶段**。项目绑定已核验且执行授权有效的账户，可以在跟单中选择；当前网格机器人的账户选择器不包含 LeverAcc 账户。添加账户不会自动借款或启动策略；功能是否可用仍取决于当前应用配置与协议检查。
</Warning>

1. 填写账户名称并 **连接资金钱包**。资金钱包可以与 Owly 登录钱包不同；Owly 会检测已有 LeverAcc 交易账户，无需填写私钥或手动输入交易合约地址。
2. 尚无交易账户时，在 Owly 内嵌的 LeverAcc 界面中创建。设置流程会先检查资金钱包的 Arbitrum USDC 和 Gas 余额；按页面显示的最低金额准备资产，等待创建及激活状态核验。
3. 功能可用时，设置流程会提供 USDC 换 ETH、USDC 换 HYPE 的准备步骤。两者预算独立，须分别核对报价支出和代币授权额度；完成 ETH 换币不代表 HYPE 已准备完成。没有可用报价时，自行准备所需资产，再检查余额。
4. 核对资金账号和交易账号，继续查看 **关联项目**。如果项目不匹配，点击 **关联到 Owly**，核对签名和合约交易。更换项目要求账户没有未偿债务及阻断风险状态，并会停用原执行钱包。
5. 使用资金钱包完成执行钱包及必要的 Builder 费用授权，等待 Owly 核验绑定并提示添加成功。已有待确认操作时，先恢复原流程或检查状态，再考虑发起新操作。
6. 在 **账户管理**中使用 LeverAcc 账户的 **充值**、**还款**、**提现**按钮，或菜单中的 **借款**和 **资金划转**，打开内嵌 LeverAcc 界面。账户资金和授权准备就绪后，在对应策略设置中选择该账户，单独确认启动。

策略停止时借款仍可能产生利息。停止机器人不会自动还债，平仓也不代表贷款已清偿；应在 LeverAcc 界面核对还款和提现限制。Alpha 阶段的开放状态和可用交易功能以当前页面提示为准。

## 旧版 Owly 托管账户

旧版 Owly 托管账户（`sub`）已停止新建、充值、内部转账，以及机器人启动、重启和配置更新。已有账户仍可查看、停止或关闭机器人，并使用受支持的提现流程。这一限制**不适用于**上文的 **Hyperliquid 子账户**（`hl_sub`）。

## 填写信息的安全边界

- 钱包助记词、Owly 登录钱包私钥和交易账户主钱包私钥，均不能发送给 Assistant、客服或第三方。
- 新增 API 钱包和 Hyperliquid 子账户时，API 交易密钥由 Owly 自动生成并保管，无需手动创建、复制或导入。
- Assistant 可以根据账户类型和公开地址说明步骤；实际连接、授权、充值、转账和交易由你在对应页面核对后完成。
- API 钱包泄露可能导致恶意交易和资金亏损。怀疑泄露时，停止对应机器人并在 Hyperliquid 撤销授权；授权过期或需要更换时，按 Owly 账户管理的更新提示处理。

本指南以 **API 钱包**类型为例，带你在 Owly 内完成跟单账户创建。使用可连接 Owly 的 EVM 钱包，例如 OKX Web3 浏览器钱包。**充值已经集成到添加账户流程中，无需先打开 Hyperliquid 注册、充值或手动创建 API 钱包。**

```text
登录 Owly → 新建跟单账户 → 选择 API 钱包 → 填写名称并连接交易钱包
  → 未激活时在当前流程充值 → 等待到账核验 → 返回开户页
  → 按需启用统一账户 → 生成并授权 API 钱包 → 完成创建 → 选择账户开始跟单
```

## 先确定交易钱包

| 名称 | 用途 |
| --- | --- |
| **Owly 登录钱包** | 登录 Owly、添加和管理跟单账户 |
| **交易钱包** | 持有充值资产、接收 Hyperliquid 入金并签署授权；可以与登录钱包相同，也可以不同 |
| **API 钱包** | 充值激活后由 Owly 生成的交易签名代理，不是充值地址 |

第一次使用可以直接选择当前登录的钱包作为交易钱包，不必再建一个钱包账号。若使用不同地址，后续充值和授权都以设置页显示的**交易钱包地址**为准。

<Warning>
不要把资金转入 API 钱包地址。新增账户不要求输入助记词、主钱包私钥或 API 钱包私钥。
</Warning>

## 步骤 1：登录 Owly

1. 打开 [Owly 账户管理](https://app.owly.fi/accounts)。
2. 点击连接钱包，选择你的钱包，在钱包中核对地址并完成登录签名。
3. 首次进入时，阅读服务条款和隐私政策，按页面提示完成首次设置。

首次登录设置与下文的跟单账户创建是不同流程。登录成功不代表已添加跟单账户，也不会自动为另一个交易钱包充值。

## 步骤 2：新建 API 钱包类型的账户

1. 在账户管理点击 **新建跟单账户**。
2. 在 **选择账户类型**中选择 **API 钱包**，点击 **下一步**。
3. 在 **设置 API 钱包**中填写 **账户名称**。
4. 点击 **连接**，选择实际用于交易的钱包。核对页面显示的交易地址；需要更换时点击 **切换**。

<Note>
也可以从交易员详情的 **跟单交易**弹窗进入，点击账户下拉中的 **创建新的独立账户**，前往账户管理完成同一创建流程。
</Note>

Owly 会检查连接地址是否为 Hyperliquid 的资金所属用户钱包。**尚未激活的地址会自动进入下面的内嵌充值流程。** 已激活的交易钱包会通过检查，可直接继续步骤 5；无需重复支付激活费。代理钱包、原生子账户或金库地址不能作为此类型的资金主钱包。

## 步骤 3：在开户流程内准备充值资产

充值界面操作的是步骤 2 中连接的**交易钱包**，即使它与 Owly 登录钱包不同也不会改变充值归属。

1. 在 **充值**界面的 **币种**中选择 **USDC** 或 **USDT**，点击 **下一步**。
2. 确认网络为 **Arbitrum One 主网**。内嵌流程会把 USDC 充入所选交易钱包的 Hyperliquid 账户。
3. 若源钱包余额不足，按页面显示的地址、币种和最低余额向该交易钱包准备资产。核对网络后再转账；页面会自动检查余额。
4. 余额达到当前要求后，继续当前流程，不必转去 Hyperliquid 网站操作。

| 页面提示 | 下一步操作 |
| --- | --- |
| **USDC 已足够，ETH 也足够** | 继续核对充值金额与费用 |
| **选择了 USDT** | 先按报价将 USDT 换成 USDC；核验后若 ETH 仍不足，先准备 ETH，再继续充值 |
| **USDC 已足够，但 ETH 不足** | 功能可用且有受支持报价时，按提示用部分 USDC 换 ETH；也可以自行准备 Arbitrum ETH 后重新检查 |
| **没有可用换币报价** | 按提示准备所需的 USDC 或 ETH，再回到当前流程检查余额 |

换币消耗你自己的资产：USDT 换 USDC 使用 USDT，准备 ETH 使用 USDC，不是赠送 Gas。**每个换币步骤都要单独核对并确认，换币完成不代表充值已到账。**

## 步骤 4：确认充值并等待激活

1. 输入充值金额，核对交易钱包地址、网络、**报价费用**和 **预计到账**。
2. 首次激活 Hyperliquid 地址会涉及 **1 USDC 激活费**，另有当前路径的 CCTP、网络或换币费用。金额须满足页面的实时校验，并为准备步骤留足余额。
3. 按顺序点击页面要求的 **确认本步骤**、**确认兑换**或 **确认充值**，在钱包中核对授权额度及交易后签名。已经完成的步骤会跳过。
4. 等待流程核验源交易、Hyperliquid 实际入账和账户激活。不要只凭钱包“已提交”就关闭页面或重复充值。
5. 核验完成后，流程会回到 **设置 API 钱包**，重新检查交易钱包状态。确认名称和地址后点击 **下一步**。

<Note>
源钱包的余额准备门槛与最终最低充值额不是同一个数。以页面显示的实时费用、可用余额和预计到账为准，不要把某个固定金额当作所有情况都适用的最低充值额。
</Note>

### 待确认或中途关闭怎么办？

使用原交易钱包和原网络，恢复已有操作并 **查询状态**；页面要求时，可通过 **查询交易**核验已有源交易。结果不明时不要重新发送。保留浏览器存储，以便恢复待确认操作；报价在提交前过期时，重新获取并核对报价。

## 步骤 5：启用统一账户并生成 API 钱包

在 **设置 API 钱包**中确认账户名称和交易地址，点击 **下一步**。激活状态通过后，Owly 检查交易账户的 **统一账户（Unified Account）**状态。未启用时，按提示由交易钱包签名启用；已经确认启用的会跳过。

状态确认后，Owly 自动生成并保存这个跟单账户专用的 API 钱包，进入 **授权 API 钱包**页面。你无需到 Hyperliquid 手动创建、复制或导入私钥。

## 步骤 6：授权并完成创建

1. 核对生成的 **API 钱包公开地址**和资金所属的 **交易钱包地址**。
2. 点击 **授权并创建**，先由交易钱包签署 API 钱包授权，等待 Owly 核验。
3. 如仍需 **Builder 费用授权**，核对费用上限并签名，再等待确认。常规授权上限为 **0.1%**，它是允许收费的上限，不是每笔交易的实际费率；详见[费用结构](/zh/faq/fees)。
4. 流程可能尝试可选的 Hyperliquid 推荐设置；已有推荐关系不会被覆盖。按页面提示继续，已确认的授权无需重复签署。
5. 等待账户创建成功，检查成功页显示的是所选**交易账户地址**，点击 **确定**完成。

如果取消签名或授权仍未确认，保留正确交易钱包，按当前步骤的提示继续。充值完成、API 钱包授权、账户创建和启动跟单是不同状态。

## 步骤 7：选择新账户开始跟单

1. 回到要跟随的交易员详情，打开 **跟单交易**。
2. 在账户下拉中选择刚创建的账户。
3. 核对来源交易员、交易账户、跟单比例、当前账户的止盈止损及其他设置，再确认启动。止盈止损阈值默认未填，应检查实际配置。
4. 启动成功后，页面会进入投资组合的对应账户卡片。检查机器人状态、实际委托和持仓；创建账户本身不会启动交易。

## 常见问题

### 交易钱包已经在 Hyperliquid 激活，还要充值吗？

不需要重复激活。状态检查通过后可继续授权；如果需要增加资金，使用[资产管理](/zh/guide/asset-management)中对应账户的充值入口。

### 钱包里有 USDC，为什么还要充值？

Arbitrum 钱包中的 USDC 与 Hyperliquid 交易余额不同。开户内嵌充值会把所选钱包的资产转入其 Hyperliquid 账户，完成入账核验后才能按该账户余额继续操作。

### 我用另一个钱包登录 Owly，应该向哪个地址准备资产？

向 **设置 API 钱包**及内嵌充值页显示的交易钱包地址准备 Arbitrum 资产。只给登录地址转账不会自动为另一交易地址充值，更不能向生成的 API 钱包地址转账。

### 余额或充值进度一直不更新怎么办？

先核对原交易地址、Arbitrum One 网络、所选币种和源交易，再使用当前流程的查询或刷新操作。不要反复充值。需要支持时，只提供公开地址、问题时间和交易哈希。

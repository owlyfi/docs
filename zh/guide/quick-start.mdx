本手册以 **OKX Web3 钱包浏览器插件**和 **API 钱包**为例，指导你添加用于跟单的 Hyperliquid 交易账户。其他两种类型见[账户类型](/zh/guide/account-types)。

如果已经登录 Owly，或已完成钱包准备、充值、API 钱包授权，可跳过对应的已完成步骤。从交易员详情的 **跟单交易**弹窗进入时，点击 **添加账户**即可开始下面的账户设置流程。

## 先选择账户关系

**Owly 主账户与交易账户可以是同一个账号，也可以分开。** 先按你的选择确定公开地址，再继续下方流程。

| 选择 | 登录 Owly | 持有交易资金、授权 API 钱包 | 操作区别 |
|:--|:--|:--|:--|
| **使用同一个账号** | 同一个钱包地址 | 同一个钱包地址 | 无需创建第二个账号，也无需在两个账号之间切换 |
| **使用独立交易账号** | Owly 主账户地址 | 另一个交易账户地址 | 登录和签名时按页面提示核对并切换账号 |

本文后续使用以下名称描述角色：

| 名称 | 用途 | 充值目标 |
|:--|:--|:--|
| **Owly 主账户** | 登录 Owly、管理跟单 | 如果同时作为交易账户，就为该地址准备交易资金；仅用于登录时无需为本流程充值 |
| **交易账户** | 持有 Hyperliquid 交易资金、应用推荐码、授权 API 钱包 | 是，以你选定的交易账户地址为准 |
| **API 钱包** | 代表交易账户进行交易签名 | 否，不要充值 |

<Info>
API 钱包只是交易签名代理，不是 OKX 中需要充值的另一个账号。Owly 查询余额、持仓和盈亏时使用的是 **交易账户地址**。
</Info>

```text
同一账号：钱包地址 → 登录 Owly，同时作为 Hyperliquid 交易账户 → 授权 API 钱包
独立账号：地址 A → 登录 Owly；地址 B → Hyperliquid 交易账户 → 授权 API 钱包
```

<Note>
下方双账号截图演示的是独立账号路径，不是必须创建两个账号。若两个派生账号共用助记词，分开地址也不等于助记词隔离。
</Note>

## 操作流程概览

```text
准备钱包并选择同一账号或独立交易账号
  → 用交易账户连接 Hyperliquid 并充值
  → 登录 Owly，需要时将推荐码应用到交易账户
  → 为交易账户创建并授权 API 钱包
  → 在 Owly 表单中填写交易账户地址和 API 钱包私钥
  → 按页面提示使用交易账户签名并完成创建
  → 用 Owly 主账户管理跟单
```

## 步骤 1：安装并初始化 OKX Web3 钱包

1. 从 [OKX 官方页面](https://web3.okx.com/zh-hans/help/how-do-i-manage-my-wallet-web) 安装 OKX Web3 钱包浏览器插件。
2. 打开插件，选择 **创建钱包**。
3. 设置插件密码。
4. 按插件提示备份并验证助记词。

<Warning>
- 钱包助记词及主钱包私钥须妥善保管，不能发送给 Assistant、客服或第三方，也不能填写在导入表单中。API 钱包私钥仅在后续专用表单中填写，不发送到聊天。
- 不要截取或上传包含助记词、私钥、二维码备份或插件密码的图片。
- 本手册后续截图只保留必要界面，地址和余额会打码。
</Warning>

### 1.1 按所选路径准备账号

- **使用同一个账号**：记录当前账号的公开地址，它同时是 Owly 主账户和交易账户。无需添加第二个账号。
- **使用独立交易账号**：在钱包账号列表中选择 **添加账户**，将两个账号分别命名为 `Owly 主账户`和 `Owly 交易账户`，记录“名称 ↔ 公开地址”的对应关系。

- [ ] 已核对名称与地址的对应关系

## 步骤 2：使用交易账户连接 Hyperliquid

1. 在 OKX Web3 钱包中选择 **Owly 交易账户**；同一账号路径下保持当前账号。
2. 打开 [Hyperliquid](https://app.hyperliquid.xyz/trade)。
3. 点击 **连接**，选择 OKX Web3 钱包支持的连接方式。
4. 在插件中确认当前地址属于交易账户，再批准连接。
5. 如果页面要求启用交易或建立连接，按页面提示完成签名。
6. 核对 Hyperliquid 右上角显示的地址与选定的交易账户地址一致。

<Info>
本步骤使用有独立 EVM 资金地址的 Hyperliquid 主账户，通过已授权的 API 钱包接入 Owly。每个这类交易账户使用不同的主账户地址，其中一个可以与 Owly 登录地址相同。生成 API 钱包本身不会新建主账户，此路径也无需先创建 Hyperliquid 原生子账户。
</Info>

<Note>
API 钱包路径无需满足原生子账户的交易量条件。原生子账户的创建门槛、基础额度和更高额度例外，见[账户类型指南](/zh/guide/account-types)。API 钱包只提供授权签名，不是独立资金账户；入金由资金来源钱包发起，提现需要主钱包签名，不能用 API 签名代理代替。
</Note>

## 步骤 3：为交易账户充值

本手册采用 Hyperliquid 官方的 **Arbitrum USDC** 充值流程。

### 3.1 准备 Arbitrum 资产

1. 复制 **Owly 交易账户** 的地址。
2. 向该地址准备：
   - Arbitrum 网络上的原生 USDC；
   - 少量 Arbitrum ETH，用于支付充值交易的网络手续费。
3. 转账前逐字核对网络、币种和收款地址，建议先进行小额测试。

<Warning>
- 充值对象是你选定的交易账户；若它同时是 Owly 主账户，两者就是同一地址。不要向 API 钱包充值。
- 按 Hyperliquid 充值弹窗显示的最低额度和规则操作；低于最低额度可能不会到账。参见 [Hyperliquid 充值说明](https://hyperliquid.gitbook.io/hyperliquid-docs/support/faq/deposit-or-transfer-issues-missing-lost/deposited-via-arbitrum-network-usdc)。
- 不要把 USDT、其他网络上的 USDC 或不受支持的资产当作 Arbitrum USDC 发送。
</Warning>

### 3.2 在 Hyperliquid 发起充值

1. 确认 Hyperliquid 当前连接的仍是 **Owly 交易账户**。
2. 点击 **充值**。
3. 选择 USDC 与 Arbitrum 网络，阅读页面显示的最低额度和到账说明。
4. 输入充值金额并再次核对当前账户地址。
5. 在 OKX Web3 钱包中确认交易详情并提交。
6. 等待 Hyperliquid 余额更新，不要因短暂延迟连续重复充值。

- [ ] 充值归属为选定的交易账户，未向 API 钱包充值

<Note>

</Note>

## 步骤 4：登录 Owly，并将推荐码应用到交易账户

### 4.1 保持 Hyperliquid 使用交易账户

1. 不要关闭前面使用的 Hyperliquid 标签页。
2. 核对 Hyperliquid 右上角地址仍然属于 **Owly 交易账户**。
3. Hyperliquid 默认会自动连接上一次使用的钱包，因此按本手册顺序操作时通常已经连接交易账户；但仍须人工核对，不能只依赖自动连接。
4. 如果地址不一致，先在 OKX Web3 钱包中切换到 Owly 交易账户，再重新连接 Hyperliquid。

<Info>
如果选择使用推荐码，应将其应用到实际交易的 Hyperliquid 账户。同一账号路径下，这就是 Owly 主账户；独立账号路径下，是你另外选择的交易账户。
</Info>

### 4.2 使用 Owly 主账户登录 Owly

1. 新开一个浏览器标签页，使用 **Owly 主账户**；同一账号路径下无需切换，独立账号路径下切换到登录用的账号。
2. 打开 [Owly 账户管理](https://app.owly.fi/accounts)。
3. 点击连接钱包，选择 **OKX Web3 钱包**。
4. 在插件中核对当前地址属于 Owly 主账户，然后连接并完成登录签名。
5. 首次登录时，阅读 Owly 的服务条款和隐私政策后，由你本人决定是否勾选同意。
6. 如果希望使用 Owly 推荐码，保留对应选项；当 Owly 触发或引导 Hyperliquid 推荐码设置时，必须回到 Hyperliquid 标签页确认连接地址属于 **Owly 交易账户**，并由该账户完成页面要求的确认。
7. 完成后回到 Owly，确认 Owly 页面显示的登录地址属于 Owly 主账户。

![Owly 主账户首次登录后的快速设置页面，地址已遮挡](/images/regular-user-guide/03-owly-master-connected.png)

*图 6：出现注册成功提示，表示 Owly 主账户登录成功；条款和推荐码选项应由用户本人阅读并选择。推荐码对应的 Hyperliquid 账户必须是交易账户。*

<Note>
两个标签页可以同时打开，但切换 OKX Web3 钱包当前账号可能影响已打开网站的连接状态。每次回到 Owly 或 Hyperliquid 标签页，都要重新核对页面显示的地址。
</Note>

## 步骤 5：为交易账户创建 API 钱包

1. 在 OKX Web3 钱包中选择 **Owly 交易账户**；只有独立账号路径下才需要切换。
2. 回到 Hyperliquid 标签页，核对右上角显示的地址属于交易账户；如果连接状态已变化，使用该账号重新连接。
3. 在 Hyperliquid 打开 **更多 → API**，或访问 [API 页面](https://app.hyperliquid.xyz/API)。
4. 输入容易识别的名称，例如 `owly-api`。
5. 点击 **生成**。
6. 立即将新生成的 API 钱包私钥保存到可信的密码管理器；该私钥通常只完整显示一次。
7. 点击 **授权 API 钱包**，设置有效期，并使用交易账户完成授权签名。
8. 记录 API 钱包名称和公开地址，以便日后核对或撤销。

## 步骤 6：将交易账户导入 Owly

同一个 Owly 主账户同时最多可有 **10 个有效交易账户，三种类型合计计算**。这与 Hyperliquid 原生子账户的数量额度分开计算。

### 6.1 导入 API 钱包

1. 确认 Owly 当前使用 **Owly 主账户**登录；只有独立账号路径下才需要切回登录用的账号。
2. 进入 Owly 的账户管理页面。
3. 点击 **创建子账户**；如果从交易员详情的 **跟单交易**弹窗进入，则点击 **添加账户**。
4. 在 **设置跟单账户**中选择开始方式：
   - **我是跟单新手**：打开 Assistant 引导，同时保留账户弹窗；你可以边阅读步骤边填写。
   - **我已熟悉操作**：直接进入账户类型选择。

   然后在 **选择账户类型**中选择 **API 钱包**并点击 **下一步**。类型旁的说明入口可让 Assistant 解释该类型；如果助手暂不可用，仍可直接选择类型并按本文继续。
5. 进入 **导入 API 钱包** 后填写：
   - **账户名称**：自定义显示名称，例如 `我的 Hyperliquid 账户`；
   - **API 钱包主账户**：填写 **交易账户地址**；
   - **API 钱包私钥**：填写步骤 5 生成的 API 钱包私钥。

   如果浏览器把私钥误认为登录密码并询问是否保存，请选择 **不保存**；不要让浏览器在该站点自动填充 API 钱包私钥。

6. 点击 **下一步**。
7. 在 **授权 API 交易** 页面检查账户名称和地址。
8. 若页面提示钱包地址不匹配，在 OKX Web3 钱包中切换到选定的 **交易账户**，并把该账号连接到 `app.owly.fi`。同一账号路径下通常无需切换。
9. 等待页面显示地址匹配，再次核对账户名称和地址。
10. 点击 **授权并创建**，在 OKX Web3 钱包中使用 **Owly 交易账户** 完成授权签名。
11. 创建完成后，检查账户列表中的地址是否等于交易账户地址。独立账号路径下，切回 **Owly 主账户**管理跟单。

如果已有相应授权，页面可能直接创建成功，无需重复签名。

API 钱包主账户必须填写选定的交易账户地址。若误填 API 钱包地址，可能看到空余额或错误的账户数据。需要授权时，由交易账户签名；它可以与 Owly 登录账号相同。API 钱包私钥只填入此表单，不要发送给 Assistant。
</Warning>

## 步骤 7：配置和管理跟单

1. 创建成功后返回要跟随的 **交易员详情**页面。
2. 打开 **跟单交易**弹窗，在账户选择中选中刚添加的交易账户。
3. 逐项检查投入金额、仓位比例、杠杆、止损和其他风险参数；需要时可继续向 Assistant 询问说明。
4. 核对交易员、所选交易账户和配置，再由你本人确认跟单。
5. 启动后检查机器人状态、首笔委托和 Hyperliquid 持仓是否一致。

### 日常管理

- 定期检查持仓、盈亏、保证金和机器人状态。
- 不再跟随时，先停止机器人，并确认没有新的委托继续产生。
- 如需完全撤销交易权限，在 Hyperliquid 的 API 页面撤销对应 API 钱包。
- 撤销或更换 API 钱包后，应同步更新或停止 Owly 中的对应账户配置。

<Info>
API 钱包只允许 Owly 代为签署交易操作。Owly 不能替交易账户转账或提现；资金操作必须由用户使用交易账户在 Hyperliquid 完成。
</Info>

## 常见问题

### 应该把资金充到哪个地址？

为你选定的 **交易账户**充值；同一账号路径下，这也是 Owly 主账户地址。独立账号路径下，资金不会从登录账户自动同步到交易账户。不要给 API 钱包充值。

### 没有 ETH 或 USDC 怎么办？

可以在支持提币到 Arbitrum 的合规交易所购买 ETH 和 USDC，再分别提现到 **Owly 交易账户**。提现前确认交易所支持所选币种通过 Arbitrum 网络提币，并逐项核对币种、网络、收款地址、手续费和最低提现额。建议首次先进行小额测试，确认到账后再转入其余金额。

USDC 用作 Hyperliquid 交易资金，ETH 用于支付 Arbitrum 网络手续费。应先把资产提到 OKX Web3 钱包中的交易账户，不要直接提到陌生地址或未经核实的合约地址。

### 充到 Owly 主账户算充错了吗？

如果主账户也是选定的交易账户，地址本身没有选错，还需确认网络、币种和入账状态。只有独立账号路径下，充到仅用于登录的地址才不会出现在另一交易账户；先确认资金归属，再由你本人按受支持流程处理，不要使用陌生人提供的“找回服务”。

### Hyperliquid 中看不到充值余额怎么办？

依次核对：当前连接地址是否为选定的交易账户、网络是否为 Arbitrum、资产是否为原生 USDC、金额是否达到页面显示的最低值，以及链上交易是否成功。不要在原因未确认前重复充值。

### Owly 子账户余额与 Hyperliquid 余额不一致怎么办？

分别查看 Owly 子账户显示的地址，以及 Hyperliquid 当前连接账户右上角显示的地址，并逐字符核对。两边必须显示同一个 **Owly 交易账户地址**。

如果地址不一致，应检查 Owly 导入时填写的 API 钱包主账户地址，并使用正确的交易账户地址重新导入；不要填写或比较 API 钱包地址。如果地址一致但余额仍不一致，先刷新两个页面并等待同步；仍未恢复时，联系 Owly 支持并只提供公开地址和问题发生时间，不要提供私钥或助记词。

### 如何从交易账户提现？

在 OKX Web3 钱包中切换到 **Owly 交易账户**，用该账户连接 Hyperliquid，并在 Hyperliquid 的提现页面由你本人核对和确认。不要把 API 钱包当作提现钱包，也不要依赖 Owly 账户页面替交易账户完成转账或提现。

### 必须准备两个 OKX 账号吗？

不需要。可以用同一个账号登录 Owly 和交易；如果选择独立交易账号，则分别核对两个公开地址，并始终为选定的交易账户准备资金。

### API 钱包私钥丢失或泄露怎么办？

立即在 Hyperliquid API 页面撤销旧 API 钱包，创建一个使用全新地址的新 API 钱包，再更新 Owly 配置。不要重复使用已经撤销的 API 钱包地址。

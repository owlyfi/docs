学习如何有效使用 Owly 的跟单交易功能。

## 寻找交易员

从 **跟单交易 → 探索**进入，查看来源账户及指标。

### 发现页面

发现页面采用**多维排名系统**，帮助您基于综合指标（而不仅仅是 ROI）发现"聪明的钱"：

<CardGroup cols={2}>
  <Card title="智能排名" icon="trophy">
    平衡收益、风险和稳定性的算法加权评分。
  </Card>
  <Card title="业绩筛选" icon="filter">
    按 ROI、胜率和时间段筛选。
  </Card>
  <Card title="风险指标" icon="chart-line">
    查看回撤、杠杆使用和波动性。
  </Card>
  <Card title="交易风格" icon="sliders">
    找到符合您首选策略的交易员。
  </Card>
</CardGroup>

### 需要考虑的关键指标

| 指标 | 关注要点 |
|--------|------------------|
| **排名得分** | 分数越高代表综合平衡性越好 |
| **夏普比率** | > 2 代表优秀的风险调整后收益 |
| **最大回撤** | 越低通常越安全 (< 20%) |
| **胜率** | > 50% 结合良好的风险/回报 |
| **交易频率** | 符合您首选的活跃度 |

## 开始跟单交易

可选择符合条件的 API 钱包、Hyperliquid 原生子账户或已完成授权的 LeverAcc 账户。已有机器人运行、可用抵押品不足或余额尚未读取的账户不能选择；旧版 Owly 托管账户不再支持启动策略。

<Steps>
  <Step title="选择交易员">
    点击交易员卡片查看他们的完整资料。
  </Step>
  <Step title="查看详情">
    分析他们的交易历史、持仓和风险指标。
  </Step>
  <Step title="点击跟单">
    按下"开始跟单交易"按钮。
  </Step>
  <Step title="选择子账户">
    选择用于跟单的子账户。
  </Step>
  <Step title="设置跟单比例">
    配置每笔交易的跟单比例（例如 0.5x、1x、2x）。
  </Step>
  <Step title="配置风控设置">
    核对当前跟单账户的**止盈止损（Exit Rules）**、净值占比上限、ROE 入场过滤、交易市场和杠杆同步。止盈止损阈值默认未填，须按需设置。
  </Step>
  <Step title="确认">
    检查所有设置并开始跟单。
  </Step>
</Steps>

## 跟单比例说明

跟单比例决定了您的仓位大小与交易员仓位的对比。

例如，假设交易员的总资金为 **100,000 USDC**，您的资金为 **10,000 USDC**。如果交易员使用其总资金的 **10%** 开仓，那么这笔交易的仓位大小就是 **10,000 USDC**。在 **1x** 跟单比例下，您的仓位会按您的资金规模等比例缩放，因此您的跟单仓位会是 **1,000 USDC**。完整对比如下：

| 跟单比例 | 交易员开仓 10% 仓位（$10,000） | 您开仓 |
|------------|-------------------------------|----------|
| 0.5x | $10,000 | $500 |
| 1x | $10,000 | $1000 |
| 2x | $10,000 | $2000 |

<Note>
  跟单交易本质上是复制交易行为，而无法 100% 复制盈亏。由于交易市场的复杂性和潜在波动性，Owly 只能尽最大努力让您的业绩与交易员的接近。
</Note>

<Warning>
  更高的跟单比例会放大利润和亏损。请谨慎使用。
</Warning>

## 管理活跃跟单

### 查看状态

在投资组合页面，您可以看到：
- 活跃的跟单交易关系
- 当前跟单状态及可用持仓
- 所选周期的业绩

### 停止跟单交易

<Steps>
  <Step title="前往投资组合">
    导航到您的子账户。
  </Step>
  <Step title="找到活跃跟单">
    找到活跃的跟单交易卡片。
  </Step>
  <Step title="点击停止">
    按下"停止跟单交易"。
  </Step>
  <Step title="处理仓位">
    选择平仓现有仓位或保持开仓。
  </Step>
</Steps>

<Note>
  停止跟单交易时，您可以选择是否同时关闭所有当前持仓。
</Note>

## 当前设置与停止行为

- **账户止损／止盈及历史高点回撤止损**默认未填，不是自动启用的固定保护。请检查实际保存的阈值。
- **净值占比上限、ROE 入场过滤、交易所与币种过滤、杠杆同步**分别影响可复制的敞口和交易。ROE 过滤用于决定是否同步来源的已有仓位，不是止损。
- 设置还包括现货／永续选择、定期仓位同步、TWAP 复制、报价币同步和小仓位过滤，其效果取决于启用市场和可用抵押品。
- **LeverAcc 不支持复制挂单**，项目绑定和执行授权必须保持有效。添加账户或充值不会自动启动跟单。
- 在 **跟单交易 → 组合**中管理运行策略；停止弹窗默认同时平仓，取消勾选后仅停止自动化并保留仓位。请求提交后仍需检查剩余仓位、委托和清理状态。停止 LeverAcc 策略不会还债。
- 使用 **历史**查看过去的机器人操作，启动或修改后核对保存配置和实际成交。参见[风险管理](/zh/advantages/risk-management)及[组合与导航](/zh/guide/dashboard)。

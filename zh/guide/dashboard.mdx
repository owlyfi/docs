## 投资组合摘要

概览为覆盖的跟单账户展示四项汇总指标：

<CardGroup cols={2}>
  <Card title="总价值" icon="dollar-sign">
    所覆盖账户的当前价值，不等于可用 USDC。账户权益已经包含持仓估值时，不应再次叠加持仓价值。
  </Card>
  <Card title="总盈亏" icon="trending-up">
    所选期间的永续盈亏汇总，不等于充值或提现引起的总账户价值变化。
  </Card>
  <Card title="ROI" icon="percent">
    结合已记录资金流，通过 NAV 份额核算计算收益率，估值范围由各账户模式决定。
  </Card>
  <Card title="活跃跟单账户" icon="copy">
    当前标记为活跃的跟单账户数。多个账户跟随同一位交易员时，仍分别计数。
  </Card>
</CardGroup>

余额、策略状态、历史和收益计算可以分别加载。资源暂不可用或不完整时，页面可能显示加载中、不可用数值，或带有刷新提示的上次成功快照。缺失值不代表零。

## 业绩图表

可以在**盈亏**和**账户价值**之间切换。曲线含义取决于所选数据系列，盈亏曲线不是权益曲线。

支持的周期为 **1D、7D、30D、60D、90D 和全部**。60D、90D 根据可用的较长历史派生；**全部**表示可用账户历史，不一定从注册 Owly 的时间开始。

图表的盈亏颜色跟随展示的盈亏状态，不表示账户价值曲线的每一段都被独立判断为盈利期或亏损期。

## 跟单账户卡片

每张卡片结合账户余额、已保存跟单配置、交易员信息和策略状态。展开可用详情可以检查指标和被跟随交易员。根据当前状态与权限，可以修改设置、启动或停止跟单、平仓。

| 项目 | 阅读方式 |
| :--- | :--- |
| **账户价值／资产** | 账户估值，不一定等于立即可提现金额 |
| **盈亏与业绩详情** | 查看指标所选周期和提示，账户卡片与概览的周期可能不同 |
| **被跟随交易员** | 此账户跟单策略的来源地址 |
| **状态** | 跟单是否活跃或空闲；策略空闲时仍可能有持仓 |
| **已保存设置** | 账户当前跟单配置，包括已设置的止盈止损阈值 |

卡片的短周期回报指标可以使用永续盈亏与经已记录资金流调整的投入资本进行比较。其算法和资本范围不同于概览的 NAV ROI，比较百分比时也应查看指标提示和数据警告。

停止跟单与平仓是不同操作。请核对停止确认框中的**同时平仓**选项，并在操作后确认账户状态和持仓结果。

## 理解组合 ROI

概览通过 NAV 份额核算区分外部资金变化与收益：

```text
NAV = 账户价值 / 份额
ROI =（期末 NAV / 期初 NAV - 1）× 100%
```

充值和提现按已跟踪的 NAV 增减份额。统一账户与组合保证金账户的估值范围包含永续、现货、Vault 和质押资产；其他受支持模式使用永续账户价值。因此，一个组合可能混合不同账户范围，而展示的盈亏仍为永续盈亏。

无法确定必要的账户历史、账户模式、账本信息，或相关资金流无法归类时，ROI 会显示不可用。不要用简单的余额变化公式替代该缺失值。

## 组合止盈止损

通过组合策略控制，为所覆盖跟单账户设置亏损、止盈和从历史高点回撤的阈值。请核对覆盖账户、基线、当前触发数值及检查间隔。保存、停用与校准是不同操作。

<Tip>
在相同周期比较盈亏与 ROI，再检查费用、资金费及账户统计范围。计算口径与控制边界见[核心概念](/zh/guide/concepts)和[风险管理](/zh/advantages/risk-management)。
</Tip>

## 概述

**Owly** 將交易員發現、跟單、交易終端和自動化策略整合到 [Hyperliquid](https://hyperliquid.xyz)。通過帳戶管理連線交易錢包或受支援的協議帳戶；網站 Assistant 可以解釋現有操作流程。

    檢視交易員歷史，按所選帳戶和風險設定配置自動跟單。
  </Card>

  </Card>

## 核心使命

我們相信，獲取複雜交易策略的機會不應僅限於專業交易員。Owly 通過以下方式實現交易民主化：

<Steps>
  <Step title="發現">
    瀏覽並分析平臺上已驗證交易員的業績資料。
  </Step>
  <Step title="連線">
    新增 API 錢包帳戶、Hyperliquid 原生子帳戶或 LeverAcc 帳戶，並完成必要授權。
  </Step>
  <Step title="監控">
    檢視機器人狀態、成交、持倉和收益，檢查風險設定並按需停止策略。
  </Step>
</Steps>

## 主要功能

| 功能 | 當前行為 |
| --- | --- |
| **交易員發現** | 通過探索頁面檢視業績與風險指標 |
| **跟單交易** | 按帳戶配置策略、市場過濾和組合風險閾值 |
| **Trade 終端** | 手動交易、內嵌資金操作和 Ghost 只讀觀察 |
| **網格機器人** | 獨立交易機器人頁面的永續中性、做多和做空網格 |
| **帳戶管理** | 自動生成 API 錢包授權、原生子帳戶設定和 LeverAcc（Alpha） |
| **投資組合** | 帳戶價值、盈虧、考慮資金流的收益率和操作歷史 |

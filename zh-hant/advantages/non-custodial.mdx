Owly 通過錢包簽名和授權交易金鑰連線帳戶。資金所有權與交易金鑰的保管是兩回事：你控制資金所屬錢包，已授權的 API 錢包則可執行交易，並可能造成虧損。

## 帳戶與金鑰角色

| 角色 | 當前行為 |
| --- | --- |
| **Owly 登入錢包** | 登入並管理帳戶，也可以同時作為交易資金所有者 |
| **交易資金錢包／主錢包** | 持有或控制資金帳戶，簽署需要所有者確認的授權和提現 |
| **跟單 API 錢包** | 開戶時由 Owly 生成並儲存，用於簽署已授權的策略操作 |
| **Trade 終端 API 錢包** | 當前 Trade 介面將其持久化儲存在本裝置瀏覽器中 |
| **LeverAcc 執行錢包** | 通過協議專案繫結授權，抵押和債務遵循 LeverAcc 規則 |

三種開戶路徑見[帳戶類型](/zh-hant/guide/account-types)。API 錢包路徑不要求先建立 Hyperliquid 原生子帳戶。

## 授權允許什麼

API 錢包可簽署受支援的交易操作，包括開倉和平倉；它不能替代資金所屬錢包的對外提現簽名。這也不意味著代理錢包沒有任何協議內部資金操作許可權。

簽名前核對連線的所有者地址、API 錢包地址、有效期、Builder 費用上限及合約交易。充值和換幣還可能需要單獨的代幣授權；代幣授權額度與換幣報價的支出上限不同。

<Warning>
交易 API 金鑰洩露可能導致惡意交易和虧損。資金非託管不能消除市場虧損、清算、惡意交易或協議故障風險。
</Warning>

## 保護和撤銷許可權

- 不要將助記詞、資金錢包私鑰或交易 API 金鑰傳送給 Assistant、客服或聊天工具。
- 僅在可信裝置上使用 Trade 授權。清除瀏覽器儲存可能刪除本地交易憑據及待確認操作恢復記錄，但不會撤銷 Hyperliquid 上的授權。
- 停止受影響的機器人，檢查剩餘倉位和委託。撤銷 API 錢包時，由所屬主錢包前往 [Hyperliquid API 頁面](https://app.hyperliquid.xyz/API)操作。
- 重新啟動前更新 Owly 對應授權。LeverAcc 使用專用的執行錢包更新流程。
- 移除 Owly 基金經理會收回管理許可權，不會自動停止機器人，也不會撤銷協議授權。

資金入口及所有者簽名見[資產管理](/zh-hant/guide/asset-management)，委託範圍見[資產所有者指南](/zh-hant/guide/owner-guide)。

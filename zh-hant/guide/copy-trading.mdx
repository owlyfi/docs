學習如何有效使用 Owly 的跟單交易功能。

## 尋找交易員

從 **跟單交易 → 探索**進入，檢視來源帳戶及指標。

### 發現頁面

發現頁面採用**多維排名系統**，幫助您基於綜合指標（而不僅僅是 ROI）發現"聰明的錢"：

<CardGroup cols={2}>
  <Card title="智慧排名" icon="trophy">
    平衡收益、風險和穩定性的演算法加權評分。
  </Card>
  <Card title="業績篩選" icon="filter">
    按 ROI、勝率和時間段篩選。
  </Card>
  <Card title="風險指標" icon="chart-line">
    查看回撤、槓桿使用和波動性。
  </Card>
  <Card title="交易風格" icon="sliders">
    找到符合您首選策略的交易員。
  </Card>
</CardGroup>

### 需要考慮的關鍵指標

| 指標 | 關注要點 |
|--------|------------------|
| **排名得分** | 分數越高代表綜合平衡性越好 |
| **夏普比率** | > 2 代表優秀的風險調整後收益 |
| **最大回撤** | 越低通常越安全 (< 20%) |
| **勝率** | > 50% 結合良好的風險/回報 |
| **交易頻率** | 符合您首選的活躍度 |

## 開始跟單交易

可選擇符合條件的 API 錢包、Hyperliquid 原生子帳戶或已完成授權的 LeverAcc 帳戶。已有機器人執行、可用抵押品不足或餘額尚未讀取的帳戶不能選擇；舊版 Owly 託管帳戶不再支援啟動策略。

<Steps>
  <Step title="選擇交易員">
    點選交易員卡片檢視他們的完整資料。
  </Step>
  <Step title="檢視詳情">
    分析他們的交易歷史、持倉和風險指標。
  </Step>
  <Step title="點選跟單">
    按下"開始跟單交易"按鈕。
  </Step>
  <Step title="選擇子帳戶">
    選擇用於跟單的子帳戶。
  </Step>
  <Step title="設定跟單比例">
    配置每筆交易的跟單比例（例如 0.5x、1x、2x）。
  </Step>
  <Step title="配置風控設定">
    核對當前跟單帳戶的**止盈止損（Exit Rules）**、淨值佔比上限、ROE 入場過濾、交易市場和槓桿同步。止盈止損閾值預設未填，須按需設定。
  </Step>
  <Step title="確認">
    檢查所有設定並開始跟單。
  </Step>
</Steps>

## 跟單比例說明

跟單比例決定了您的倉位大小與交易員倉位的對比。

例如，假設交易員的總資金為 **100,000 USDC**，您的資金為 **10,000 USDC**。如果交易員使用其總資金的 **10%** 開倉，那麼這筆交易的倉位大小就是 **10,000 USDC**。在 **1x** 跟單比例下，您的倉位會按您的資金規模等比例縮放，因此您的跟單倉位會是 **1,000 USDC**。完整對比如下：

| 跟單比例 | 交易員開倉 10% 倉位（$10,000） | 您開倉 |
|------------|-------------------------------|----------|
| 0.5x | $10,000 | $500 |
| 1x | $10,000 | $1000 |
| 2x | $10,000 | $2000 |

<Note>
  跟單交易本質上是複製交易行為，而無法 100% 複製盈虧。由於交易市場的複雜性和潛在波動性，Owly 只能盡最大努力讓您的業績與交易員的接近。
</Note>

<Warning>
  更高的跟單比例會放大利潤和虧損。請謹慎使用。
</Warning>

## 管理活躍跟單

### 檢視狀態

在投資組合頁面，您可以看到：
- 活躍的跟單交易關係
- 當前跟單狀態及可用持倉
- 所選週期的業績

### 停止跟單交易

<Steps>
  <Step title="前往投資組合">
    導航到您的子帳戶。
  </Step>
  <Step title="找到活躍跟單">
    找到活躍的跟單交易卡片。
  </Step>
  <Step title="點選停止">
    按下"停止跟單交易"。
  </Step>
  <Step title="處理倉位">
    選擇平倉現有倉位或保持開倉。
  </Step>
</Steps>

<Note>
  停止跟單交易時，您可以選擇是否同時關閉所有當前持倉。
</Note>

## 當前設定與停止行為

- **帳戶止損／止盈及歷史高點回撤止損**預設未填，不是自動啟用的固定保護。請檢查實際儲存的閾值。
- **淨值佔比上限、ROE 入場過濾、交易所與幣種過濾、槓桿同步**分別影響可複製的敞口和交易。ROE 過濾用於決定是否同步來源的已有倉位，不是止損。
- 設定還包括現貨／永續選擇、定期倉位同步、TWAP 複製、報價幣同步和小倉位過濾，其效果取決於啟用市場和可用抵押品。
- **LeverAcc 不支援複製掛單**，專案繫結和執行授權必須保持有效。新增帳戶或充值不會自動啟動跟單。
- 在 **跟單交易 → 組合**中管理執行策略；停止彈窗默認同時平倉，取消勾選後僅停止自動化並保留倉位。請求提交後仍需檢查剩餘倉位、委託和清理狀態。停止 LeverAcc 策略不會還債。
- 使用 **歷史**檢視過去的機器人操作，啟動或修改後核對儲存配置和實際成交。參見[風險管理](/zh-hant/advantages/risk-management)及[組合與導航](/zh-hant/guide/dashboard)。

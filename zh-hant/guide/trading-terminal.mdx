通過 **交易** 開啟 [app.owly.fi/trade](https://app.owly.fi/trade)，檢視行情圖、訂單簿、最近成交和帳戶資訊，並從終端當前提供的永續、現貨市場中選擇交易對。

## 使用哪個帳戶交易？

在自己的交易終端中，交易地址就是**已完成 Owly 登入認證的錢包地址**，不使用跟單帳戶選擇器。在跟單開戶彈窗中連線另一個交易錢包，不會切換終端的交易身份。

Owly 使用 Privy 連線外部錢包。當前僅支援錢包登入，不建立內嵌錢包，也不提供郵箱或社交帳號登入。充值、提現和交易前都要核對顯示的地址及網路。

## 完成交易授權

終端會檢查帳戶啟用狀態、統一帳戶模式、Builder 授權和 API 錢包連線。請在**交易設定**中完成頁面提示，並逐項核對錢包請求。

1. 錢包尚未在 Hyperliquid 啟用時，先完成充值流程並等待確認到帳。
2. 按提示開啟統一帳戶模式。
3. 核對並完成 Builder 授權。已經確認的配置可以複用；頁面會提示不可用或尚未確認的步驟。
4. 授權此終端使用的 API 錢包。授權過期或發生變化時，使用設定中顯示的恢復操作。

授權完成後，終端可能使用已授權代理為尚無推薦人的帳戶嘗試可選的 Hyperliquid 推薦設定。已有推薦關係會保留；該可選步驟失敗不會阻斷交易就緒。

終端會將已授權的 API 交易金鑰儲存在本裝置瀏覽器中，供後續訪問使用。當前 Trade 介面要求持久化本地交易連線，沒有僅保留當前標籤頁的切換選項。此裝置儲存與跟單開戶時由 Owly 生成、管理的 API 錢包不同。更換授權可能使其他瀏覽器或裝置需要重新授權。

<Warning>
只在自己控制的裝置上使用交易終端。API 錢包可以簽署交易操作，金鑰被盜仍可能造成交易損失。請勿在 Owly、助手或客服聊天中輸入主錢包私鑰或助記詞。
</Warning>

## 從 Arbitrum 充值

內建資金流程目前僅支援 **Arbitrum One 主網**。資金來自所選錢包在 Arbitrum 上的 **USDC 或 USDT**，最終通過 CCTP 向該錢包的 Hyperliquid 帳戶充值 USDC。

- 選擇 USDT 時，先兌換為 USDC。
- 使用 USDC 但 ETH 不足以支付 Gas 時，在服務可用且有支援的報價條件下，可以使用 USDC 兌換 ETH。
- 兌換和充值需要分別核對。兌換完成不代表 Hyperliquid 已充值到帳。
- 此流程不把 API 簽名錢包、金庫或原生子帳戶地址作為資金所有者錢包充值，請按帳戶類型提示操作。

最初的源錢包餘額檢查要求：已啟用帳戶至少持有 **1 個所選代幣**，未啟用地址至少持有 **2 個所選代幣**。這是餘額檢查門檻，不保證以該數額就能充值成功。最終充值金額必須大於**當前 CCTP 費用與帳戶啟用費之和**；兌換和 Gas 也需要足夠資金。簽名前以頁面的費用報價和預計到帳金額為準。

建立 API 錢包跟單帳戶時，也可能出現同一充值元件。該場景充值到**開戶彈窗中明確選擇的交易錢包**，它可以與登入錢包不同，詳見[快速開始](/zh-hant/guide/quick-start)。

## 提現到 Arbitrum

終端將 **USDC 提現到當前連線錢包在 Arbitrum One 上的同一地址**，表單不提供任意收款地址輸入框。

錢包必須是已啟用的 Hyperliquid 使用者，並已開啟統一帳戶模式。提現金額必須同時滿足：

- **大於 0.2 USDC**；
- 大於當前協議提現費用；
- 不超過扣除所需提現 Gas 預留後的當前可用金額。

因此，實際最低金額取決於即時費用和帳戶狀態。請核對費用和預計到帳金額。提交請求不代表完成：流程會核對交易和目標到帳證據，再顯示已驗證完成。若仍為等待或結果不確定，請使用同一錢包檢查原操作，再決定是否重新提交。確認完成後會返回終端的**轉帳**歷史標籤頁。

## 下單與帳戶歷史

終端提供市價、限價和 TWAP 下單。下單選單中的網格選專案前為預覽，不能提交；獨立網格 Bot 請使用[機器人 → 網格交易](/zh-hant/guide/grid-bot)。

選擇市場、方向、價格或執行時長、數量及可用的風控設定，再核對確認彈窗。市場精度、保證金、最小下單金額和當前行情資料均可能限制操作。帳戶面板提供餘額、持倉、掛單、TWAP、成交歷史、資金費歷史、訂單歷史和轉帳記錄。選擇某個市場不代表帳戶歷史中所有記錄都屬於該市場；可執行操作會另外檢查。

## 用 Ghost 模式檢視其他地址

在交易員詳情頁點選地址連結，可以開啟該公開帳戶的終端。連結格式如下：

```text
https://app.owly.fi/trade?ghost=0x1111111111111111111111111111111111111111
```

請把示例替換為有效的 42 字元 EVM 地址。Ghost 模式為**只讀**：可以瀏覽市場及該地址可讀取的公開餘額、持倉、掛單和歷史，不能替該地址下單、撤單、充值或提現。點選跟單操作會進入該交易員的跟單流程，仍需另選自己的帳戶並確認。

使用 Ghost 退出控制元件返回自己的終端。Ghost 地址格式無效時會顯示錯誤，不會自動改為另一個帳戶。

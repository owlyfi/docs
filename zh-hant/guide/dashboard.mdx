開啟**跟單交易 → 投資組合**，集中檢視跟單帳戶。帳戶管理位於獨立的**帳戶**頁面，網格策略則位於**交易機器人**下的對應頁面。

餘額、策略狀態、歷史和收益計算可以分別載入。資源暫不可用或不完整時，頁面可能顯示載入中、不可用數值，或帶有重新整理提示的上次成功快照。缺失值不代表零。

## 業績圖表

可以在**盈虧**和**帳戶價值**之間切換。曲線含義取決於所選資料系列，盈虧曲線不是權益曲線。

支援的週期為 **1D、7D、30D、60D、90D 和全部**。60D、90D 根據可用的較長曆史派生；**全部**表示可用帳戶歷史，不一定從註冊 Owly 的時間開始。

圖表的盈虧顏色跟隨展示的盈虧狀態，不表示帳戶價值曲線的每一段都被獨立判斷為盈利期或虧損期。

## 跟單帳戶卡片

每張卡片結合帳戶餘額、已儲存跟單配置、交易員資訊和策略狀態。展開可用詳情可以檢查指標和被跟隨交易員。根據當前狀態與許可權，可以修改設定、啟動或停止跟單、平倉。

| 專案 | 閱讀方式 |
| :--- | :--- |
| **帳戶價值／資產** | 帳戶估值，不一定等於立即可提現金額 |
| **盈虧與業績詳情** | 檢視指標所選週期和提示，帳戶卡片與概覽的週期可能不同 |
| **被跟隨交易員** | 此帳戶跟單策略的來源地址 |
| **狀態** | 跟單是否活躍或空閒；策略空閒時仍可能有持倉 |
| **已儲存設定** | 帳戶當前跟單配置，包括已設定的止盈止損閾值 |

卡片的短週期回報指標可以使用永續盈虧與經已記錄資金流調整的投入資本進行比較。其演算法和資本範圍不同於概覽的 NAV ROI，比較百分比時也應檢視指標提示和資料警告。

停止跟單與平倉是不同操作。請核對停止確認框中的**同時平倉**選項，並在操作後確認帳戶狀態和持倉結果。

## 理解組合 ROI

概覽通過 NAV 份額核算區分外部資金變化與收益：

```text
NAV = 帳戶價值 / 份額
ROI =（期末 NAV / 期初 NAV - 1）× 100%
```

充值和提現按已跟蹤的 NAV 增減份額。統一帳戶與組合保證金帳戶的估值範圍包含永續、現貨、Vault 和質押資產；其他受支援模式使用永續帳戶價值。因此，一個組合可能混合不同帳戶範圍，而展示的盈虧仍為永續盈虧。

無法確定必要的帳戶歷史、帳戶模式、帳本資訊，或相關資金流無法歸類時，ROI 會顯示不可用。不要用簡單的餘額變化公式替代該缺失值。

## 組合止盈止損

通過組合策略控制，為所覆蓋跟單帳戶設定虧損、止盈和從歷史高點回撤的閾值。請核對覆蓋帳戶、基線、當前觸發數值及檢查間隔。儲存、停用與校準是不同操作。

<Tip>
在相同週期比較盈虧與 ROI，再檢查費用、資金費及帳戶統計範圍。計算口徑與控制邊界見[核心概念](/zh-hant/guide/concepts)和[風險管理](/zh-hant/advantages/risk-management)。
</Tip>

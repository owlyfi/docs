本指南以 **API 錢包**類型為例，帶你在 Owly 內完成跟單帳戶建立。使用可連線 Owly 的 EVM 錢包，例如 OKX Web3 瀏覽器錢包。**充值已經整合到新增帳戶流程中，無需先開啟 Hyperliquid 註冊、充值或手動建立 API 錢包。**

```text
登入 Owly → 新建跟單帳戶 → 選擇 API 錢包 → 填寫名稱並連線交易錢包
  → 未啟用時在當前流程充值 → 等待到帳核驗 → 返回開戶頁
  → 按需啟用統一帳戶 → 生成並授權 API 錢包 → 完成建立 → 選擇帳戶開始跟單
```

## 先確定交易錢包

| 名稱 | 用途 |
| --- | --- |
| **Owly 登入錢包** | 登入 Owly、新增和管理跟單帳戶 |
| **交易錢包** | 持有充值資產、接收 Hyperliquid 入金並簽署授權；可以與登入錢包相同，也可以不同 |
| **API 錢包** | 充值啟用後由 Owly 生成的交易簽名代理，不是充值地址 |

第一次使用可以直接選擇當前登入的錢包作為交易錢包，不必再建一個錢包帳號。若使用不同地址，後續充值和授權都以設定頁顯示的**交易錢包地址**為準。

<Warning>
不要把資金轉入 API 錢包地址。新增帳戶不要求輸入助記詞、主錢包私鑰或 API 錢包私鑰。
</Warning>

## 步驟 1：登入 Owly

1. 開啟 [Owly 帳戶管理](https://app.owly.fi/accounts)。
2. 點選連線錢包，選擇你的錢包，在錢包中核對地址並完成登入簽名。
3. 首次進入時，閱讀服務條款和隱私政策，按頁面提示完成首次設定。

首次登入設定與下文的跟單帳戶建立是不同流程。登入成功不代表已新增跟單帳戶，也不會自動為另一個交易錢包充值。

## 步驟 2：新建 API 錢包類型的帳戶

1. 在帳戶管理點選 **新建跟單帳戶**。
2. 在 **選擇帳戶類型**中選擇 **API 錢包**，點選 **下一步**。
3. 在 **設定 API 錢包**中填寫 **帳戶名稱**。
4. 點選 **連線**，選擇實際用於交易的錢包。核對頁面顯示的交易地址；需要更換時點選 **切換**。

<Note>
也可以從交易員詳情的 **跟單交易**彈窗進入，點選帳戶下拉中的 **建立新的獨立帳戶**，前往帳戶管理完成同一建立流程。
</Note>

Owly 會檢查連線地址是否為 Hyperliquid 的資金所屬使用者錢包。**尚未啟用的地址會自動進入下面的內嵌充值流程。** 已啟用的交易錢包會通過檢查，可直接繼續步驟 5；無需重複支付啟用費。代理錢包、原生子帳戶或金庫地址不能作為此類型的資金主錢包。

## 步驟 3：在開戶流程內準備充值資產

充值介面操作的是步驟 2 中連線的**交易錢包**，即使它與 Owly 登入錢包不同也不會改變充值歸屬。

1. 在 **充值**介面的 **幣種**中選擇 **USDC** 或 **USDT**，點選 **下一步**。
2. 確認網路為 **Arbitrum One 主網**。內嵌流程會把 USDC 充入所選交易錢包的 Hyperliquid 帳戶。
3. 若源錢包餘額不足，按頁面顯示的地址、幣種和最低餘額向該交易錢包準備資產。核對網路後再轉帳；頁面會自動檢查餘額。
4. 餘額達到當前要求後，繼續當前流程，不必轉去 Hyperliquid 網站操作。

| 頁面提示 | 下一步操作 |
| --- | --- |
| **USDC 已足夠，ETH 也足夠** | 繼續核對充值金額與費用 |
| **選擇了 USDT** | 先按報價將 USDT 換成 USDC；核驗後若 ETH 仍不足，先準備 ETH，再繼續充值 |
| **USDC 已足夠，但 ETH 不足** | 功能可用且有受支援報價時，按提示用部分 USDC 換 ETH；也可以自行準備 Arbitrum ETH 後重新檢查 |
| **沒有可用換幣報價** | 按提示準備所需的 USDC 或 ETH，再回到當前流程檢查餘額 |

換幣消耗你自己的資產：USDT 換 USDC 使用 USDT，準備 ETH 使用 USDC，不是贈送 Gas。**每個換幣步驟都要單獨核對並確認，換幣完成不代表充值已到帳。**

## 步驟 4：確認充值並等待啟用

1. 輸入充值金額，核對交易錢包地址、網路、**報價費用**和 **預計到帳**。
2. 首次啟用 Hyperliquid 地址會涉及 **1 USDC 啟用費**，另有當前路徑的 CCTP、網路或換幣費用。金額須滿足頁面的即時校驗，併為準備步驟留足餘額。
3. 按順序點選頁面要求的 **確認本步驟**、**確認兌換**或 **確認充值**，在錢包中核對授權額度及交易後簽名。已經完成的步驟會跳過。
4. 等待流程核驗源交易、Hyperliquid 實際入帳和帳戶啟用。不要只憑錢包“已提交”就關閉頁面或重複充值。
5. 核驗完成後，流程會回到 **設定 API 錢包**，重新檢查交易錢包狀態。確認名稱和地址後點擊 **下一步**。

<Note>
源錢包的餘額準備門檻與最終最低充值額不是同一個數。以頁面顯示的即時費用、可用餘額和預計到帳為準，不要把某個固定金額當作所有情況都適用的最低充值額。
</Note>

### 待確認或中途關閉怎麼辦？

使用原交易錢包和原網路，恢復已有操作並 **查詢狀態**；頁面要求時，可通過 **查詢交易**核驗已有源交易。結果不明時不要重新發送。保留瀏覽器儲存，以便恢復待確認操作；報價在提交前過期時，重新獲取並核對報價。

## 步驟 5：啟用統一帳戶並生成 API 錢包

在 **設定 API 錢包**中確認帳戶名稱和交易地址，點選 **下一步**。啟用狀態通過後，Owly 檢查交易帳戶的 **統一帳戶（Unified Account）**狀態。未啟用時，按提示由交易錢包簽名啟用；已經確認啟用的會跳過。

狀態確認後，Owly 自動生成並儲存這個跟單帳戶專用的 API 錢包，進入 **授權 API 錢包**頁面。你無需到 Hyperliquid 手動建立、複製或匯入私鑰。

## 步驟 6：授權並完成建立

1. 核對生成的 **API 錢包公開地址**和資金所屬的 **交易錢包地址**。
2. 點選 **授權並建立**，先由交易錢包簽署 API 錢包授權，等待 Owly 核驗。
3. 如仍需 **Builder 費用授權**，核對費用上限並簽名，再等待確認。常規授權上限為 **0.1%**，它是允許收費的上限，不是每筆交易的實際費率；詳見[費用結構](/zh-hant/faq/fees)。
4. 流程可能嘗試可選的 Hyperliquid 推薦設定；已有推薦關係不會被覆蓋。按頁面提示繼續，已確認的授權無需重複簽署。
5. 等待帳戶建立成功，檢查成功頁顯示的是所選**交易帳戶地址**，點選 **確定**完成。

如果取消簽名或授權仍未確認，保留正確交易錢包，按當前步驟的提示繼續。充值完成、API 錢包授權、帳戶建立和啟動跟單是不同狀態。

## 步驟 7：選擇新帳戶開始跟單

1. 回到要跟隨的交易員詳情，開啟 **跟單交易**。
2. 在帳戶下拉中選擇剛建立的帳戶。
3. 核對來源交易員、交易帳戶、跟單比例、當前帳戶的止盈止損及其他設定，再確認啟動。止盈止損閾值預設未填，應檢查實際配置。
4. 啟動成功後，頁面會進入投資組合的對應帳戶卡片。檢查機器人狀態、實際委託和持倉；建立帳戶本身不會啟動交易。

## 常見問題

### 交易錢包已經在 Hyperliquid 啟用，還要充值嗎？

不需要重複啟用。狀態檢查通過後可繼續授權；如果需要增加資金，使用[資產管理](/zh-hant/guide/asset-management)中對應帳戶的充值入口。

### 錢包裡有 USDC，為什麼還要充值？

Arbitrum 錢包中的 USDC 與 Hyperliquid 交易餘額不同。開戶內嵌充值會把所選錢包的資產轉入其 Hyperliquid 帳戶，完成入帳核驗後才能按該帳戶餘額繼續操作。

### 我用另一個錢包登入 Owly，應該向哪個地址準備資產？

向 **設定 API 錢包**及內嵌充值頁顯示的交易錢包地址準備 Arbitrum 資產。只給登入地址轉帳不會自動為另一交易地址充值，更不能向生成的 API 錢包地址轉帳。

### 餘額或充值進度一直不更新怎麼辦？

先核對原交易地址、Arbitrum One 網路、所選幣種和源交易，再使用當前流程的查詢或重新整理操作。不要反覆充值。需要支援時，只提供公開地址、問題時間和交易雜湊。

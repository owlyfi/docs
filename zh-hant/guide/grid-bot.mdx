在 **機器人 → 網格交易** 開啟[網格交易頁面](https://app.owly.fi/trading-bots/grid)，登入後管理 Bot。

## 當前支援範圍

網格編輯器支援永續市場，提供 **中性、做多、做空** 三種方向、**等差、等比** 兩種價格演算法，以及 **全倉、逐倉** 保證金模式。還可以設定觸發價、方向初始倉位，以及策略止盈價和止損價。

<Note>
此編輯器暫不支援現貨網格。向上、向下移動網格的控制元件雖然可見，但目前被停用。獨立[交易終端](/zh-hant/guide/trading-terminal)下單選單裡的網格選項也僅為預覽；管理網格 Bot 請使用網格交易頁面。
</Note>

## 選擇可用帳戶

先在[帳戶管理](https://app.owly.fi/accounts)建立或匯入帳戶，再返回網格交易。建立時的帳戶選擇器要求帳戶有可讀取的正數可用餘額，且沒有執行中的 Bot。已經配置為其他 Bot 類型的帳戶會被排除。

- **API 錢包**和 **Hyperliquid 子帳戶**滿足上述條件時可以使用。
- **鏈上借貸 / LeverAcc** 帳戶不出現在網格帳戶選擇器中。
- 舊版 **Owly 託管子帳戶**不能再修改 Bot 配置或啟動 Bot。請通過仍支援的提現流程，把剩餘資金遷移到自託管帳戶。

未出現在選擇器中的帳戶仍可能存在於帳戶管理中。先檢查帳戶類型、餘額和已有 Bot 配置，再決定是否需要新增帳戶。

## 配置網格

點選**建立**，選擇帳戶和合約交易對，再核對以下欄位。

| 欄位 | 含義 |
| --- | --- |
| 方向 | 中性、做多或做空 |
| 保證金模式和槓桿 | 全倉或逐倉，槓桿受所選市場的上限約束 |
| 區間下限和上限 | 網格執行價格區間，上限必須高於下限 |
| 網格數量 | 區間劃分數量；至少 2 格，受預估可用掛單額度約束 |
| 投入金額 | 分配給整個網格的總資金，支援兩位小數；必須大於 0 且小於帳戶可用餘額 |
| 價格演算法 | 等差為固定價格差，等比為固定價格比例 |
| 觸發價 | 可選；開啟後，價格達到所選上破或下破條件才開始執行 |
| 初始倉位 | 做多、做空模式可用，中性模式下停用 |
| 止盈價 / 止損價 | 可選的策略級價格閾值，命中後發起風險退出 |
| 同步週期 | 檢查並同步掛單的間隔，表單初始值為 15 秒 |

頁面根據市場和區間預估最低投入、單檔數量和每格利潤。這些僅是估算；能否啟動和成交仍受交易所最小下單金額、精度、費用、可用保證金和即時價格約束。

<Warning>
增加網格數量會把投入分配到更多訂單。網格越多不代表利潤越高，也可能使單檔訂單低於交易所最低要求。請為虧損和費用預留可用保證金。
</Warning>

## 方向與初始倉位

**中性**模式在參考價下方掛買單、上方掛賣單，不會自動建立方向底倉。

**做多**通過買單增加多頭敞口，用僅減倉賣單減少敞口；**做空**通過賣單增加空頭敞口，用僅減倉買單減少敞口。兩種方向模式都可以開啟初始建倉。啟動前核對已有倉位；方向不相容或保證金不足可能導致無法啟用。

## 儲存、啟動與停止

1. **儲存**只儲存配置，不啟動 Bot。
2. 使用啟動操作，核對確認彈窗，再確認啟動。如果儲存成功但啟動失敗，配置仍已儲存；檢查錯誤和狀態後再重試。
3. 持續檢視執行狀態、帳戶餘額、掛單和持倉。配置已儲存或請求已受理，不代表每檔訂單都已成交。
4. 修改前先停止 Bot；執行中的網格在編輯器中為只讀狀態。
5. 停止彈窗中的**同時關閉所有倉位**預設勾選。取消勾選會請求停止但保留持倉；保留勾選會請求停止並平倉。兩種操作後都應核對最終掛單和持倉。

止盈、止損觸發後，Bot 會離開正常網格維護流程併發起風險退出。執行可能延遲、被拒絕或部分成交。停止、平倉請求或風險閾值均不能保證立即成交或固定最終虧損。

## 介面配置與 API 相容欄位

當前表單把總投入提交為 `total_invest`，不要求填寫單檔 `order_size` 或獨立的 `bootstrap_size`。歷史配置可能仍包含這些欄位，請勿把舊版單檔數量示例當作當前投入金額。

新網格配置使用 `account_mode: "auto"`，已有配置明確指定模式時會保留原值。編輯器沒有帳戶模式選擇器；這與新增帳戶時可能要求開啟統一帳戶模式是不同步驟。

請求保留 `trailing_up_limit`、`trailing_down_limit` 的相容能力，也可以讀取歷史移動網格值。但當前介面的兩個移動網格控制元件均被停用，新建表單預設保持 `0`。後端接受或保留某個欄位，不等於使用者可以在編輯器中開啟它。`rebalance_tolerance_bps` 等後端引數同樣不是當前可編輯的表單控制元件。

帳戶準備見[帳戶類型](/zh-hant/guide/account-types)，交易成本見[費用](/zh-hant/faq/fees)。

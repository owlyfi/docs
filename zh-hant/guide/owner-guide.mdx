Owly 允許資產所有者新增經理並選擇交易管理許可權。**經理授權覆蓋該所有者名下全部活躍交易帳戶，包括以後新增的帳戶。** 這是所有者與經理之間的關係，不是對某一個子帳戶單獨分配。

## 準備交易帳戶

以資產所有者身份登入 [Owly](https://app.owly.fi/accounts)。普通交易帳戶可按[快速入門](/zh-hant/guide/quick-start)配置 API 錢包，也可按下方流程新增 Hyperliquid 原生子帳戶。Owly 的統一帳戶數量上限與 Hyperliquid 的原生子帳戶條件分別計算，詳見[帳戶類型](/zh-hant/guide/account-types)。

### 新增 Hyperliquid 原生子帳戶

1. 使用擁有該原生子帳戶或將用於建立子帳戶的 Hyperliquid 主錢包登入。
2. 開啟帳戶管理，選擇 **新建跟單帳戶**，再選擇 **Hyperliquid 子帳戶**。
3. 選擇已有子帳戶。符合條件時，也可在同一表單選擇 **建立子帳號**，輸入不重複且不超過 16 個字元的名稱，按提示完成授權與建立。該流程會先準備或複用所需的普通 API 錢包授權。繼續前核對簽名錢包地址和建立結果。
4. 若建立結果尚未確認，先重新整理子帳戶列表核對原請求，不要直接重複建立。
5. 填寫帳戶顯示名稱並繼續。使用主錢包核對並完成必要的統一帳戶啟用、專用 API 錢包授權和 Builder 費用授權。
6. 等待完成並核對所選交易帳戶地址。無需輸入或複製私鑰。

您也可以先在 [Hyperliquid](https://app.hyperliquid.xyz/subAccounts) 建立符合條件的原生子帳戶，再回到 Owly 選擇。原生子帳戶仍受支援。舊版 Owly 託管錢包屬於另一種帳戶類型，已停用新建、新配置機器人和重啟機器人。

<Note>
原生子帳戶沒有自己的私鑰，由所屬主錢包授權 API 錢包。Owly 為每次匯入生成專用 API 錢包以減少共享 Nonce 衝突；這不等於在 Hyperliquid 協議層將該代理限制為只能操作一個子帳戶。
</Note>

## 新增經理

經理必須是已註冊 Owly 的 EVM 地址，不能是本人，也不能重複新增。每位所有者最多新增 **20 位經理**。

1. 在帳戶管理找到 **管理帳戶**，選擇 **新增管理帳戶**。
2. 輸入經理已註冊的錢包地址，可填寫備註暱稱。
3. 核對 **檢視**、**啟動** 和 **停止** 許可權。預設三項均勾選，只保留您希望授予的許可權。
4. 確認後，經理可在 **我管理的子帳戶** 中按所獲許可權訪問您的帳戶。

<Warning>
此操作授權的是所有者名下全部活躍帳戶，也包括未來新增帳戶。確認前請核對完整範圍；在該所有者下另建一個交易子帳戶，不會把經理許可權縮小到該子帳戶。
</Warning>

## 許可權範圍

| 許可權 | 允許的操作 |
| --- | --- |
| **檢視（`VIEW`）** | 在受支援管理頁面檢視帳戶與策略資訊 |
| **啟動（`START`）** | 啟動或重啟受支援的機器人 |
| **停止（`STOP`）** | 停止機器人，或請求終止及清理 |

機器人配置修改使用啟動/停止許可權校驗，沒有獨立的經理“修改配置”許可權開關。經理許可權不包含提現、修改帳戶所有權或設定、新增其他經理等所有者操作；帳戶類型限制和錢包授權仍然適用。

API 錢包用於已授權的交易簽名。外部充值與提現仍需資金錢包或主錢包承擔相應簽名角色。API 錢包洩露仍可能通過惡意交易造成虧損。LeverAcc 帳戶的抵押、債務、還款及協議提現由 LeverAcc 管理；停止機器人不等於還款。

## 監控與停止交易

在帳戶管理和投資組合中檢視餘額、持倉、訂單、盈虧與機器人狀態。除生命週期狀態外，也應核對執行和清理狀態。

- **停止**會停止自動執行，本身不平掉已有持倉。
- **關閉／終止**請求終止策略並清理持倉和相關訂單。請確認清理結果及實際持倉，不要假定每次關閉都會成功。
- 清理進行中或失敗時需要繼續處理。確認剩餘風險前，應保留帳戶所需保證金。

## 修改或移除經理

在經理卡片選擇 **編輯**，修改備註暱稱或許可權；選擇 **移除**，撤銷該所有者對這位經理的授權。

**移除經理不會自動停止執行中的機器人、平倉、撤單或撤銷 Hyperliquid API 錢包授權。** 如果希望結束交易，請由所有者逐個停止或關閉相關機器人，並核對狀態及剩餘風險。移除一位經理也不會取消其他經理的許可權。

如果懷疑 API 錢包洩露，請先停止受影響的自動交易，再使用所屬主錢包到 [Hyperliquid API 頁面](https://app.hyperliquid.xyz/API)核對授權，並按 Owly 帳戶管理流程授權替換錢包。不要把助記詞或任何私鑰傳送給 Assistant、客服或經理。

## 常見問題

<AccordionGroup>
  <Accordion title="能否只給經理分配一個交易帳戶？">
    當前經理關係覆蓋所有者名下的活躍帳戶。在同一所有者下另建原生子帳戶，不會把授權範圍限制為這個帳戶。
  </Accordion>
  <Accordion title="為什麼新增經理失敗？">
    檢查 EVM 地址及註冊狀態，並確認不是本人或已新增的經理。每位所有者上限為 20 位經理。
  </Accordion>
  <Accordion title="為什麼不能建立原生子帳戶？">
    按表單返回的資格和數量限制處理，也可選擇已有子帳戶。若建立尚未確認，請先重新整理檢查，避免重複建立。
  </Accordion>
  <Accordion title="經理能提走資金嗎？">
    Owly 的檢視、啟動、停止許可權不授予提現或轉帳許可權。此類操作由所有者錢包及帳戶所在協議的規則控制。
  </Accordion>
</AccordionGroup>

資金操作前先核對 **帳戶地址**、**網路**和 **幣種**。API 錢包是交易簽名代理，不是資金帳戶，也不是充值目標。

## 選擇正確入口

| 帳戶或入口 | 當前資金操作方式 |
| --- | --- |
| **Trade 交易終端** | **充值**和 **提現**操作當前登入錢包自己的 Hyperliquid 帳戶 |
| **API 錢包開戶** | 尚未啟用的交易錢包可通過內嵌充值流程啟用 Hyperliquid 帳戶，再繼續授權 |
| **帳戶管理中的 API 錢包帳戶** | 資金按鈕引導前往 Hyperliquid，須連線實際交易錢包 |
| **帳戶管理中的 Hyperliquid 子帳戶** | 由所屬主錢包在 Hyperliquid 完成充值或劃轉 |
| **鏈上借貸（Alpha）** | **充值**、**還款**、**提現**、**借款**和 **資金劃轉**開啟內嵌 LeverAcc 介面 |
| **舊版 Owly 託管帳戶** | 已停止新增充值和一般內部轉帳；使用受支援的提現流程轉回所有者 |

Trade 終端不會切換到任意跟單帳戶。若資金帳戶地址與當前登入地址不同，應使用該帳戶對應的受支援流程。參見[帳戶類型](/zh-hant/guide/account-types)。

## 通過 Trade 終端充值

1. 開啟 **Trade → 充值**，確認當前連線的是資金所屬錢包。
2. 選擇 **Arbitrum One 主網**上的 **USDC** 或 **USDT**。轉入 Hyperliquid 的資產為 USDC；選擇 USDT 時，先按準備步驟換成 USDC。
3. 按表單顯示的要求準備源錢包餘額。ETH 不足時，如果 Gasless 服務已配置且有受支援報價，頁面可提供 USDC 換 ETH 的步驟。
4. 分別核對報價、代幣授權額度、網路費、CCTP 費用和預計到帳金額。首次啟用 Hyperliquid 地址還需頁面顯示的 **1 USDC 啟用費**。充值金額須高於適用費用；源錢包準備門檻不等於通用最低充值額。
5. 本人逐步簽名，等待目標確認及 Hyperliquid 餘額入帳後再交易。

API 錢包開戶遇到尚未啟用的交易錢包時，也可進入同一內嵌充值流程；交易錢包可以與 Owly 登入錢包不同。

<Note>
換幣使用你自己的資產：USDT 換 USDC 消耗 USDT，準備 ETH 消耗 USDC。“Gasless”不代表免費贈送 Gas。換幣支出上限與代幣授權額度是兩回事；即使換幣支出有上限，報價仍可能請求無限代幣授權。
</Note>

## 通過 Trade 終端提現

**提現**將 **USDC 傳送到當前資金錢包的 Arbitrum One 地址**。Hyperliquid 帳戶須已啟用且處於統一帳戶模式。提現金額須 **大於 0.2 USDC**、高於即時提現費，並且不超過可提現餘額。這不代表所有高於 0.2 USDC 的金額都可提現。

核對收款地址、網路、金額、費用和預計到帳後，由資金所屬錢包簽名。API 交易代理不能替代所有者的提現簽名。等待收款餘額核驗完成；請求提交不代表已到帳。

## 待確認或中斷的資金操作

保持原錢包和網路，使用 **檢查狀態**或恢復已有操作。頁面提供 **查詢交易**時，可核驗已有的源鏈交易。結果不明時不要重複轉帳；報價在提交前過期時，應獲取並核對新報價。

保留瀏覽器儲存以支援待確認操作恢復。聯絡客服時，只提供公開地址、網路、問題時間和交易雜湊，不要提供助記詞或私鑰。

## LeverAcc 資金與債務

LeverAcc 建立流程會按需檢查 **Arbitrum USDC 和 ETH**，以及 **HyperEVM HYPE**。ETH 與 HYPE 的準備步驟使用頁面顯示的獨立 USDC 預算。抵押、借款、還款和提現須遵循內嵌介面的協議規則。

停止跟單不會自動還款，平倉也不代表抵押品已全部釋放或債務清零。提現或更改專案繫結前，須單獨確認債務及還款狀態。

## 費用和餘額

資金操作可能涉及 Gas、換幣、跨鏈/CCTP、啟用及協議費用，以即時報價為準。不能對所有路徑統一承諾固定到帳時間或“只收網路 Gas”。參見[費用結構](/zh-hant/faq/fees)。

**帳戶價值**與 **可提現餘額**不同。持倉、保證金、現貨抵押和借貸都會影響可提現金額。對比 Owly 和 Hyperliquid 時，應使用同一資金帳戶地址，不要使用 API 錢包地址。

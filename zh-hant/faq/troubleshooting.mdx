## 錢包與開戶

| 現象 | 檢查事項 |
| --- | --- |
| 錢包無法連線 | 解鎖錢包，檢查站點許可權和衝突外掛，確認目標地址後重試 |
| 簽名錢包不正確 | 對比 Owly 登入、交易所有者和資金錢包地址；這些地址可以不同，應切回當前步驟要求的錢包 |
| API 錢包設定要求充值 | 資金所屬地址尚未在 Hyperliquid 啟用；先完成內嵌充值並等待啟用，再啟用統一帳戶和 API 授權 |
| 所有者地址被拒絕 | 使用資金所屬的 Hyperliquid 使用者錢包，不能使用代理、金庫或原生子帳戶地址 |
| 沒有可選原生子帳戶 | 核對登入主錢包並重新整理列表，只有資格和數量檢查通過後才能使用建立選項 |
| 已達帳戶上限 | 三種受支援類型共用最多 10 個有效 Owly 交易帳戶的上限 |
| API 錢包授權失敗 | 核對有效期和 Hyperliquid API 錢包剩餘名額，再由正確主錢包完成待處理授權 |

Owly 登入會話過期與 Hyperliquid 交易授權過期不同：前者重新連線並簽名登入，後者需更新帳戶交易授權。

## 充值、換幣與提現

- **使用正確入口。** Trade 操作當前登入資金錢包；帳戶管理中的 API 錢包和原生子帳戶按鈕引導前往 Hyperliquid；LeverAcc 使用內嵌介面。參見[資產管理](/zh-hant/guide/asset-management)。
- **網路或資產不符：**內嵌 Trade 流程使用 Arbitrum One 主網，以 USDC 入金，可先將 USDT 換成 USDC。LeverAcc 所需 HYPE 位於 HyperEVM。核對交易實際網路和代幣。
- **沒有可用換幣報價：**Gasless 依賴服務配置、受支援授權方式、餘額和新報價。沒有報價時，應自行準備所需資產。
- **ETH 已到但仍缺 HYPE：**LeverAcc 獨立檢查兩種資產；完成剩餘準備步驟，再檢查餘額。
- **提交待確認或結果不明：**恢復原操作並檢查狀態，按提示提供源交易雜湊；結果明確前不要重複傳送。
- **提現被拒絕：**核對資金所屬錢包、統一帳戶模式、可提現餘額和即時費用。Trade 提現金額須同時大於 0.2 USDC 和適用費用。
- **充值未顯示：**核對資金帳戶地址、源鏈交易和目標餘額。錢包提交成功不代表 Hyperliquid 已入帳。

## 策略與帳戶訪問

| 現象 | 檢查事項 |
| --- | --- |
| 舊版託管帳戶不能啟動機器人 | 該類型已停止啟動、重啟和配置更新；處理剩餘策略並使用受支援的提現路徑 |
| LeverAcc 無法開始跟單 | 核對專案繫結、執行錢包授權、資金及當前開放狀態；該類型不支援複製掛單 |
| 網格中找不到 LeverAcc | 當前網格機器人帳戶選擇器不包含 LeverAcc |
| 交易未複製 | 核對機器人狀態、授權有效期、可用抵押品、啟用市場、幣種過濾、最低委託額和來源活動 |
| 倉位或入場價不同 | 跟單比例、行情變化、取整、過濾條件及保證金餘額都會影響執行 |
| 已移除經理但機器人仍執行 | 移除管理許可權不會停止機器人，須由所有者單獨停止或關閉 |
| 網格追蹤控制元件不可用 | 當前介面未開放區間追蹤，後端保留欄位不代表此處可啟用 |

止損止盈不是自動填好的預設保護，須檢查實際儲存的設定。參見[風險管理](/zh-hant/advantages/risk-management)。

## 錢包與交易金鑰安全

資金所屬錢包由你控制，自動策略使用的 API 金鑰由 Owly 生成並儲存。當前 Trade 終端會將 API 交易授權持久化儲存在本裝置瀏覽器中。不要向 Assistant 或客服傳送任何私鑰和助記詞。參見[非託管安全](/zh-hant/advantages/non-custodial)。

API 錢包不能替代所有者的對外提現簽名，但能執行造成虧損的交易。核對簽名錢包及許可權範圍，發現洩露時由所屬錢包撤銷授權。停止機器人、移除經理和撤銷 API 錢包是不同操作。

## 交易風險

| 風險 | 含義 |
| --- | --- |
| **市場與槓桿** | 價格變化、資金費和清算可能減少或耗盡帳戶權益 |
| **跟單執行** | 延遲、流動性、最低委託額、市場過濾和可用抵押品會使成交及倉位與來源不同 |
| **風險閾值** | 須自行配置止損止盈；監控和平倉可能失敗，或在越過閾值後以更差價格成交 |
| **網格敞口** | 方向網格可能累積倉位，價格也可能離開設定區間 |
| **資料限制** | 收益和回放依賴可用歷史、帳戶統計範圍和資料時效 |

歷史結果不保證未來表現。排名、模擬和 Ghost 只讀觀察，都不能保證策略適合你或能夠成功複製。

## 資金與協議風險

- 簽名前檢查當前路徑使用的網路和代幣。內嵌 Trade 資金流程支援 Arbitrum One 主網，LeverAcc 還涉及 HyperEVM。
- 分別核對 Gas、換幣、跨鏈/CCTP、啟用及協議費用。
- 提交結果不明時，先檢查已有操作，不要重複傳送。
- 合約、跨鏈橋、交易所、錢包軟體及上游服務都可能出現故障；公開原始碼本身不代表已通過安全審計。
- LeverAcc 抵押借貸涉及利息和清算風險，停止交易或平倉不會自動還債。

## 出現異常時

1. 停止受影響的自動化，檢查持倉和未成交委託。
2. 由資金所屬錢包撤銷或更換受影響的交易授權；LeverAcc 使用專用執行錢包更新流程。
3. 繼續轉帳前核對待確認資金操作和交易雜湊。
4. 通過 [Telegram 客服](https://t.me/owlyfi_support)或 [security@owly.fi](mailto:security@owly.fi)提供公開地址、問題時間及脫敏證據，不要在公開群聊傳送秘密或漏洞細節。

## Wallet and setup

| Symptom | What to check |
| --- | --- |
| Wallet cannot connect | Unlock the wallet, check site permissions and competing extensions, and retry with the intended address |
| Wrong signing wallet | Compare the Owly login, trading owner, and funding addresses. They can differ; return to the wallet requested by the current step |
| API Wallet setup asks for funding | The owning address is not yet activated on Hyperliquid. Complete the embedded deposit and wait for activation before Unified Account and API authorization |
| Address rejected as owner | Use the owning Hyperliquid user wallet, rather than an agent, vault, or native sub-account address |
| No native sub-account available | Check the logged-in master, refresh the list, and use the create option only when eligibility and capacity checks pass |
| Account limit reached | All three supported types share the limit of 10 active Owly trading accounts |
| API Wallet authorization fails | Review its expiry and available Hyperliquid API Wallet slots, then complete the pending authorization with the correct master |

An expired Owly login session and an expired Hyperliquid trading authorization are different problems. Reconnect and sign in for the former; update the account's trading authorization for the latter.

## Deposits, swaps, and withdrawals

- **Use the correct entry point.** Trade funds the logged-in owning wallet; Accounts links API Wallet and native sub-account users to Hyperliquid. LeverAcc buttons open its embedded interface. See [Asset Management](/guide/asset-management).
- **Wrong network or asset:** the integrated Trade flow uses Arbitrum One mainnet and deposits USDC, with an optional USDT-to-USDC preparation. LeverAcc HYPE belongs on HyperEVM. Verify the transaction's actual network and token.
- **Swap unavailable:** gasless swaps depend on provider configuration, supported approval methods, balances, and a fresh quote. Prepare the required asset yourself if no supported quote is offered.
- **ETH prepared but HYPE still missing:** LeverAcc checks them independently. Complete the remaining preparation and recheck balances.
- **Pending or unknown submission:** resume the original operation and check status. Use its source transaction hash when prompted; do not send another transaction until the result is known.
- **Withdrawal rejected:** check owning-wallet identity, Unified Account mode, withdrawable balance, and live fees. The Trade amount must exceed both 0.2 USDC and the applicable fee.
- **Deposit not visible:** compare the funded account address, source transaction, and destination balance. A successful wallet submission does not prove credit on Hyperliquid.

## Strategies and account access

| Symptom | What to check |
| --- | --- |
| Legacy managed account cannot start a bot | This account type is retired for start/restart/configuration updates; stop or close remaining automation and use its supported withdrawal route |
| LeverAcc cannot start copying | Confirm project binding, execution-wallet authorization, funding, and current availability; pending-order copying is unsupported |
| LeverAcc missing from Grid | The current Grid Bot account selector excludes LeverAcc accounts |
| Trades not copied | Check bot state, authorization validity, available collateral, enabled markets, coin filters, minimum sizes, and source activity |
| Different position sizes or entry prices | Copy ratio, market movement, rounding, configured filters, and margin availability can change execution |
| Manager removed but bot still running | Removing management access does not stop bots. The owner must stop or close the bot separately |
| Grid trailing controls disabled | Trailing is currently unavailable in the user interface; saved backend fields do not enable it here |

SL/TP thresholds are not automatically populated protective defaults. Check the saved settings and [Risk Management](/advantages/risk-management).

## Balances and charts

Compare the same trading account address and time period. Account value is not withdrawable balance. ROI can be unavailable when valuation scope or cash-flow history cannot be established; it should not be read as zero. Refresh and check [Portfolio & Navigation](/guide/dashboard) for metric definitions.

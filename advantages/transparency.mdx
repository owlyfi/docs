Owly uses Hyperliquid account, position, fill, and ledger data to show trading activity and calculate performance. Trading records can be checked against the underlying account address, while Owly's statistics depend on the selected scope and available history.

## Reading the Evidence

<AccordionGroup>
  <Accordion title="Account-based History" icon="check">
    Inspect the trader's address and available trade history instead of relying on a trader's description alone. Select the same market and time window when comparing records.
  </Accordion>
  <Accordion title="Visible Calculation Scope" icon="chart-line">
    Perpetual PnL, whole-account value, and NAV returns measure different things. Deposits, withdrawals, fees, and funding can explain differences between them.
  </Accordion>
  <Accordion title="Data Availability" icon="sync">
    Live updates, cached history, and backend calculations can refresh at different times. Missing, loading, or incomplete data should not be interpreted as zero activity or a guaranteed complete history.
  </Accordion>
</AccordionGroup>

## Data Sources

| Data Type | Source | What to Check |
| :--- | :--- | :--- |
| Fills and trade history | Hyperliquid data and backend trade reconstruction | Address, market, timestamps, and loaded history range |
| Positions and balances | Hyperliquid account data, through live updates and snapshot requests | Account mode, valuation scope, and data freshness |
| Performance metrics | Calculations from account history, trades, and ledger cash flows | Formula, selected period, supported cash flows, and missing-data notices |
| Trading fees | Exchange fill fee fields, including builder fees where present | Separate exchange fees from the platform builder fee |
| Copy configuration and strategy status | Owly's saved configuration and strategy status data | Whether the strategy is active and which settings were saved |

Performance calculations and strategy configuration are not themselves immutable smart-contract records. A rounded or aggregated metric also cannot be reproduced by looking at one transaction alone.

## Independent Checks

Use the account address to inspect activity in Hyperliquid and compare it with Owly using the same market, period, and scope. For a copied strategy, compare both source and follower records: different capital, fees, execution timing, and filters can produce different results.

<Note>
Historical records support informed comparisons, not a guarantee of future results or exact replication. The interface can only display the history and sources currently available to it.
</Note>

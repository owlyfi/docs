В этом руководстве используется тип учетной записи **API-кошелёк** для создания учетной записи для копирования торговых операций в Owly. Используйте поддерживаемый кошелек EVM, например кошелек браузера OKX Web3. **Финансирование интегрировано в настройку учетной записи: вам не нужно сначала посещать Hyperliquid, чтобы зарегистрироваться, внести депозит или вручную создать API кошелек.**

```text
Войдите → Создание под счетом → Выберите API Портфель → Укажите название счета и подключите торговый кошелёк
  → Внесение средств в настройку, если неактивно → Дождитесь подтвержденного поступления → Вернуться к данным счета.
  → При необходимости включите единую учетную запись → Создайте и авторизуйте API Кошелек → Создать учетную запись → Начать копирование
```

## Выберите торговый кошелек

| Роль | Цель |
| --- | --- |
| **Owly вход в кошелек** | Вход в систему, добавление аккаунтов для копи-трейдинга и управление ими. |
| **Торговый кошелек** | хранит депозитные активы, получает зачисление на Hyperliquid и подписывает разрешения; он может совпадать с вашим кошельком для входа в систему или отличаться от него. |
| **API-кошелёк** | Агент для подписи торговых операций, созданная Owly после активации; это не адрес депозита |

Для вашей первой учетной записи вы можете использовать свой кошелек для входа в качестве торгового кошелька без создания второй учетной записи кошелька. Используя отдельные адреса, пополните и авторизуйте торговый кошелек **, показанный в настройке**.

<Warning>
Никогда не отправляйте средства на адрес API-кошелька. При настройке учетной записи не требуется ввод стартовой фразы, закрытого ключа владельца кошелька или закрытого ключа API кошелька.
</Warning>

## Шаг 1: Войдите в систему Owly.

1. Откройте [Owly Управление учетной записью](https://app.owly.fi/accounts).
2. Подключите свой кошелек, проверьте его адрес и подпишите сообщение для входа.
3. При первом посещении прочтите условия и политику конфиденциальности и выполните инструкции по первоначальной настройке.

Первоначальная настройка входа в систему и создание учетной записи для копирования торговых операций — это отдельные процессы. При входе в систему не создается копия торгового счета или автоматически не пополняется другой торговый кошелек.

## Шаг 2: Добавьте учетную запись API-кошелька.

1. В разделе **Счета** нажмите **Создание под счетом**, чтобы добавить торговый счёт.
2. В окне **Выберите тип счета** выберите **API Портфель** (счёт с API-кошельком) и нажмите **Следующий шаг**.
3. На экране настройки API-кошелька **Степень API Портфель** заполните поле **Название счета**.
4. Нажмите **Connect** и выберите кошелёк для торговли. Проверьте отображаемый адрес. Чтобы сменить подключённый кошелёк, нажмите **Switch**.

<Note>
В окне настройки копирования сделок для выбранного трейдера можно выбрать **Создание нового подсчета** в списке счетов. Откроется тот же мастер создания счёта в разделе **Счета**.
</Note>

Owly проверяет, является ли подключенный адрес владельцем кошелька пользователя Hyperliquid. **Неактивный адрес автоматически попадает во встроенный поток депозитов ниже.** Уже активированный торговый кошелек может перейти к шагу 5 без повторной уплаты комиссии за активацию. Агент, собственная суб-учетная запись или адрес хранилища не могут использоваться в качестве кошелька-владельца для этого типа учетной записи.

## Шаг 3: Подготовьте средства при настройке учетной записи.

Экран депозита работает на торговом кошельке **, подключенном на шаге 2**, даже если он отличается от вашего кошелька для входа в систему Owly.

1. В **Deposit** выберите **USDC** или **USDT** в разделе **Актив**, затем нажмите **Далее**.
2. Убедитесь, что выбрана **основная сеть Arbitrum One**. Интегрированный поток вносит USDC на счет Hyperliquid этого кошелька.
3. Если в исходном кошельке недостаточно средств, подготовьте активы по адресу и минимальному балансу, указанным на экране. Проверьте сеть перед передачей; страница проверяет баланс автоматически.
4. Как только баланс будет соответствовать текущим требованиям, продолжите тот же процесс в Owly.

| Что показывает экран | Что делать |
| --- | --- |
| **Хватит USDC и ETH** | Продолжайте проверять сумму депозита и комиссии. |
| **USDT выбрано** | Просмотрите и замените USDT на USDC; после проверки подготовьте ETH, если он все еще нужен, затем перейдите к депозиту |
| **Достаточно USDC, недостаточно ETH** | Если эта функция включена и доступна поддерживаемая котировка, используйте предлагаемый шаг USDC-to-ETH; альтернативно подготовьте Arbitrum ETH и перепроверьте |
| **Нет поддерживаемой котировки свопа** | Подготовьте запрошенный USDC или ETH самостоятельно, затем перепроверьте внутри того же потока. |

Свопы тратят ваши собственные активы: USDT-на-USDC потребляет USDT, а подготовка ETH потребляет USDC. Это не бесплатные гранты на газ. **Проверьте и подтвердите каждый обмен отдельно. Завершенный своп не означает, что депозит Hyperliquid поступил.**

## Шаг 4: Подтвердите депозит и дождитесь активации.

1. Введите сумму депозита. Проверьте торговый кошелек, сеть, **Котируемые комиссии** и **Оценочное получение**.
2. Первая активация адреса Hyperliquid включает в себя плату за активацию **1 USDC** помимо применимых комиссий CCTP, сети или обмена. Выполните проверку суммы в форме и оставьте достаточно средств для подготовительных этапов.
3. Следуйте **Подтвердить этот шаг**, **Подтвердить обмен** или **Подтвердить депозит** в соответствии с запросом. Перед подписанием проверьте количество токенов и транзакции в вашем кошельке. Завершенные шаги пропускаются.
4. Дождитесь проверки исходной транзакции, фактического зачисления на Hyperliquid и активации учетной записи. Представленного статуса кошелька недостаточно; не закрывайте поток и не отправляйте еще один депозит только потому, что отправка прошла успешно.
5. После проверки мастер возвращается на экран **Степень API Портфель** и повторно проверяет торговый кошелёк. Подтвердите название счёта и адрес, затем нажмите **Следующий шаг**.

<Note>
Порог готовности исходного кошелька отличается от окончательного минимального депозита. Следите за текущими комиссиями, доступным балансом и предполагаемыми поступлениями вместо того, чтобы рассматривать фиксированную сумму как универсальный минимум.
</Note>

### Если операция ожидает или прервана

Вернитесь с тем же торговым кошельком и сетью. Возобновите существующую операцию и используйте **Проверить статус** или **Найти транзакцию**, когда вас попросят проверить существующую исходную транзакцию. Не подавайте повторно, пока результат неизвестен. Не очищайте данные браузера, пока может понадобиться восстановить операцию. Если срок действия предложения истек до подачи, получите и просмотрите новое предложение.

## Шаг 5: Включите единую учетную запись и создайте API-кошелёк.

На экране **Степень API Портфель** подтвердите название счёта и торговый адрес, затем нажмите **Следующий шаг**. Owly проверяет режим **Единая учетная запись** после подтверждения активации. При необходимости подпишитесь, чтобы включить его с торговым кошельком, и дождитесь подтверждения. Подтвержденная настройка пропускается.

Owly затем создает и сохраняет выделенный API кошелек этой копии учетной записи и открывает **Approve API Wallet**. Вы не создаете его вручную на Hyperliquid, не копируете и не импортируете закрытый ключ.

## Шаг 6: Авторизация и создание

1. Проверьте сгенерированный **API публичный адрес кошелька** и финансируемый **адрес торгового кошелька**.
2. Нажмите **Авторизовать и создать**. Сначала подпишите подтверждение API с помощью торгового кошелька и подождите, пока Owly проверит его.
3. Заполните **Авторизация комиссии Builder**, если требуется, после проверки его предельного размера. Стандартный потолок — **0.1%**; это максимально разрешенная ставка, а не фактическая плата за каждую сделку. См. [Структура комиссий](/ru/faq/fees).
4. Программа установки может попытаться выполнить дополнительную настройку Hyperliquid реферала; существующий реферер сохраняется. Следуйте текущим подсказкам. Подтвержденные авторизации не нужно повторять.
5. Дождитесь создания учетной записи, убедитесь, что на экране успеха отображается выбранный вами **адрес торгового счета**, и нажмите **OK**.

Если вы отменяете подпись или одобрение остается неподтвержденным, оставьте подключенным правильный торговый кошелек и продолжите с текущего шага. Финансирование, авторизация API, создание учетной записи и запуск стратегии — это отдельные состояния.

## Шаг 7: выберите учетную запись и начните копирование.

1. Вернитесь к трейдеру, за которым хотите следить, и откройте **Copy Trade**.
2. Выберите вновь созданную учетную запись в раскрывающемся списке учетных записей.
3. Проверьте исходного трейдера, торговый счет, коэффициент копирования, правила выхода из счета и другие настройки, а затем подтвердите. Пороги SL/TP изначально не заданы. Проверьте сохранённые настройки.
4. После успешного запуска Owly открывает соответствующую карточку счета в Портфолио. Проверьте статус бота, актуальные заказы и позиции. Само по себе создание учетной записи не приводит к началу торговли.

## Общие вопросы

### Нужен ли уже активированный торговый кошелек еще один депозит?

Повторная активация не требуется. Как только проверка пройдет, продолжайте авторизацию. Чтобы добавить средства позже, используйте точку входа для конкретного аккаунта в [Управление активами](/ru/guide/asset-management).

### Зачем вносить депозит, если в моем кошельке уже есть USDC?

USDC в кошельке Arbitrum отличается от торгового баланса Hyperliquid. Интегрированный депозит перемещает активы выбранного кошелька на его счет Hyperliquid и подтверждает этот кредит.

### Какой адрес я могу пополнить, если войду в систему с другим кошельком?

Подготовьте активы в сети Arbitrum на адресе торгового кошелька, который указан на экране **Степень API Портфель** и во встроенной форме пополнения. Финансирование только вашего адреса входа не будет пополнять другой торговый счет. Никогда не пополняйте сгенерированный API-кошелёк.

### Что делать, если баланс или прогресс депозита не обновляются?

Проверьте исходный торговый адрес, сеть Arbitrum One, выбранный актив и исходная транзакция, затем используйте текущий поток или элементы управления обновлением. Не вносите депозит повторно. Для поддержки указывайте только публичные адреса, время возникновения проблемы и хеши транзакций.

Owly обслуживает две основные группы пользователей, каждая из которых имеет уникальные преимущества и возможности.

---

<a id="followers" />

## Подписчики

<Card title="Для подписчиков" icon="user-plus" color="#7C3AED">
  Лица, которые хотят расширить свое портфолио, автоматически копируя успешных трейдеров.
</Card>

### Зачем становиться подписчиком?

<CardGroup cols={3}>
  <Card title="Пассивный доход" icon="coins">
    Позвольте опытным трейдерам управлять вашими позициями, пока вы сосредоточены на других вещах.
  </Card>
  <Card title="Учитесь на практике" icon="graduation-cap">
    Наблюдайте за реальными торговыми стратегиями в действии, чтобы улучшить свои навыки.
  </Card>
  <Card title="Диверсификация" icon="chart-pie">
    Следуйте за несколькими трейдерами, чтобы распределить риск между разными стратегиями.
  </Card>
</CardGroup>

### Идеально подходит для:

- Занятые профессионалы, которым не хватает времени на активную торговлю.
- Новички, желающие учиться у опытных трейдеров
- Инвесторы, желающие получить доступ к криптовалютным деривативам без глубокого опыта.

<a id="curators" />

## Кураторы

<Card title="Кураторам" icon="crown" color="#F59E0B">
  Физические или юридические лица, уже управляющие капиталом, которым необходимы инструменты профессионального уровня для повышения доходности и управления рисками.
</Card>

### Зачем становиться куратором?

<CardGroup cols={3}>
  <Card title="Команда квантовой нулевой стоимости" icon="robot">
    Получите доступ к элитным количественным стратегиям без дорогостоящих моделей участия в прибыли, таких как найм технической команды.
  </Card>
  <Card title="Хеджирование рисков" icon="shield-halved">
    Используйте автоматизированные стратегии для эффективного хеджирования рыночных рисков для ваших управляемых активов.
  </Card>
  <Card title="Инфраструктура" icon="server">
    Используйте Owly в качестве технической базы для профессионального управления активами.
  </Card>
</CardGroup>

### Идеально подходит для:

- Управляющие фондами, стремящиеся к повышению производительности
- Лидеры сообщества, управляющие объединенным капиталом
- Управляющим активами, нуждающимся в инструментах хеджирования рисков

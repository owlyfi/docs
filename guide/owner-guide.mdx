Owly lets an asset owner add managers with selected trading permissions. **Manager authorization applies to all active trading accounts under the owner, including accounts added later.** It is an owner-to-manager relationship, not a separate assignment for one sub-account.

## Prepare Your Accounts

Sign in to [Owly](https://app.owly.fi/accounts) as the asset owner. For an ordinary trading account, use the [API Wallet setup](/guide/quick-start). You can also add native Hyperliquid sub-accounts as described below. Owly's shared account limit and Hyperliquid's native eligibility rules are separate; see [Account Type](/guide/account-types).

### Add a Native Hyperliquid Sub-account

1. Sign in with the Hyperliquid master wallet that owns, or will create, the native sub-account.
2. Open account management, choose **Create Sub Account**, then **Hyperliquid Sub-account**.
3. Select an existing sub-account. If eligible, you can choose **Create Sub-account** in the same form, enter a unique name of up to 16 characters, and follow the authorization and creation prompts. Owly first prepares or reuses the normal API Wallet authorization needed by this flow. Check the wallet address and the result before continuing.
4. If creation is unconfirmed, refresh the sub-account list to check the original attempt before creating again.
5. Enter the account's display name and continue. Review and sign any required Unified Account enablement, dedicated API Wallet approval, and Builder fee authorization with the master wallet.
6. Wait for completion and verify the selected trading account address. You do not enter or copy private keys.

You can also create an eligible native sub-account on [Hyperliquid](https://app.hyperliquid.xyz/subAccounts), then select it in Owly. Existing native sub-accounts remain supported. Legacy Owly-managed wallets are a different account type: new creation, new bot setup, and bot restart are disabled for those wallets.

<Note>
Native sub-accounts have no private key of their own. Their master wallet authorizes API Wallets. Owly generates a dedicated API Wallet for each import to reduce shared-nonce conflicts; this does not restrict the agent to that one sub-account at the Hyperliquid protocol level.
</Note>

## Add a Manager

The manager must be a registered Owly user with an EVM address. You cannot add yourself or add the same manager twice. Each owner can add **up to 20 managers**.

1. In account management, find **Manager Accounts** and select **Add Manager**.
2. Enter the manager's registered wallet address and an optional nickname.
3. Review the **View**, **Start Bot**, and **Stop Bot** permissions. All three are selected by default; keep only the permissions you intend to grant.
4. Confirm. The manager can use **Managed Sub Accounts** to access your accounts according to those permissions.

<Warning>
This grants access across your active accounts, including future additions. Review the full owner-level scope before confirming. A dedicated trading sub-account does not make the manager authorization specific to that sub-account.
</Warning>

## Permissions

| Permission | What it allows |
| --- | --- |
| **View (`VIEW`)** | View account and strategy information through the supported management views |
| **Start Bot (`START`)** | Start or restart a supported bot |
| **Stop Bot (`STOP`)** | Stop a bot or request termination and cleanup |

Bot configuration changes use the start/stop permission checks; there is no separate manager configuration-permission switch. Manager permissions do not grant owner operations such as withdrawals, editing account ownership/settings, or adding other managers. Account-type restrictions and wallet authorizations still apply.

An API Wallet signs authorized trading actions. Asset owners retain the funding-wallet or master-wallet signing role for external funding and withdrawals. A leaked API Wallet can still cause losses through malicious trading. For LeverAcc accounts, manage collateral, debt, repayment, and protocol withdrawals through LeverAcc; stopping a bot does not repay a loan.

## Monitor and Stop Trading

Review account balances, positions, orders, P&L, and bot status in account management and Portfolio. Check runtime and cleanup status as well as the displayed lifecycle state.

- **Stop** stops automated execution; it does not itself close existing positions.
- **Close / terminate** requests strategy termination and position/order cleanup. Confirm the cleanup result and actual positions; do not assume every close attempt succeeds.
- A pending or failed cleanup requires follow-up. Keep the account funded for its remaining margin obligations until you have checked the result.

## Change or Remove a Manager

Use **Edit** on the manager card to update its nickname or permissions. Use **Remove** to revoke that owner's authorization for the manager.

**Removing a manager does not automatically stop running bots, close positions, cancel orders, or revoke Hyperliquid API Wallet approvals.** If you want trading to end, stop or close each affected bot yourself and verify its state and remaining exposure. Removing one manager also does not revoke another manager's access.

If an API Wallet may be compromised, stop the affected automation and review its authorization on the [Hyperliquid API page](https://app.hyperliquid.xyz/API) using the master wallet. Follow Owly's account-management flow to approve a replacement. Never send a seed phrase or private key to the Assistant, support, or a manager.

## Common Questions

<AccordionGroup>
  <Accordion title="Can I assign a manager to just one trading account?">
    The current manager relationship covers the owner's active accounts. Creating a separate native sub-account under that owner does not narrow the grant to one account.
  </Accordion>
  <Accordion title="Why did adding a manager fail?">
    Check the EVM address, confirm the manager has registered, and ensure it is not your own address or an existing manager. The owner limit is 20 managers.
  </Accordion>
  <Accordion title="Why is native sub-account creation unavailable?">
    Follow the eligibility and capacity result in the form. You can still select an existing eligible sub-account. If creation is unconfirmed, refresh before retrying to avoid duplicates.
  </Accordion>
  <Accordion title="Can the manager withdraw funds?">
    Owly's View / Start / Stop permissions do not grant withdrawal or transfer authority. The owner's wallet and the account's protocol rules govern those actions.
  </Accordion>
</AccordionGroup>

This guide uses the **API Wallet** account type to create a copy trading account in Owly. Use a supported EVM wallet, such as the OKX Web3 browser wallet. **Funding is integrated into account setup: you do not need to visit Hyperliquid first to register, deposit, or manually create an API Wallet.**

```text
Sign in → Create Sub Account → Choose API Wallet → Name and connect the trading wallet
  → Fund inside setup if inactive → Wait for verified arrival → Return to account details
  → Enable Unified Account if needed → Generate and authorize API Wallet → Create account → Start copying
```

## Choose the trading wallet

| Role | Purpose |
| --- | --- |
| **Owly login wallet** | Signs in, adds accounts, and manages copying |
| **Trading wallet** | Holds the deposit assets, receives Hyperliquid credit, and signs authorizations; it can match or differ from your login wallet |
| **API Wallet** | A trading signer generated by Owly after activation; it is not a deposit address |

For your first account, you can use your login wallet as the trading wallet without creating a second wallet account. With separate addresses, fund and authorize the **trading wallet shown in setup**.

<Warning>
Never send funds to the API Wallet address. Account setup does not ask for a seed phrase, owning-wallet private key, or API Wallet private key.
</Warning>

## Step 1: Sign in to Owly

1. Open [Owly Account Management](https://app.owly.fi/accounts).
2. Connect your wallet, check its address, and sign the login message.
3. On your first visit, read the terms and privacy policy and complete the initial setup prompts.

Initial login setup and copy trading account creation are separate flows. Signing in does not create a copy trading account or fund another trading wallet automatically.

## Step 2: Add an API Wallet account

1. In Accounts, click **Create Sub Account**.
2. In **Choose Account Type**, select **API Wallet** and click **Next Step**.
3. Enter the **Account Name** in **Set Up API Wallet**.
4. Click **Connect** and select the wallet that will actually trade. Check the displayed address; use **Switch** to change it if needed.

<Note>
From a trader's **Copy Trade** dialog, you can instead choose **Create New Sub Account** in the account dropdown to open the same creation flow in Accounts.
</Note>

Owly checks whether the connected address is an owning Hyperliquid user wallet. **An inactive address automatically enters the embedded deposit flow below.** An already activated trading wallet can proceed to Step 5 without paying the activation fee again. An agent, native sub-account, or vault address cannot be used as the owning wallet for this account type.

## Step 3: Prepare funds inside account setup

The deposit screen operates on the **trading wallet connected in Step 2**, even when it differs from your Owly login wallet.

1. In **Deposit**, select **USDC** or **USDT** under **Asset**, then click **Next**.
2. Confirm **Arbitrum One mainnet**. The integrated flow deposits USDC into that wallet's Hyperliquid account.
3. If the source wallet lacks funds, prepare assets at the address and minimum balance shown by the screen. Check the network before transferring; the page checks balances automatically.
4. Once the balance meets the current requirement, continue the same flow in Owly.

| What the screen shows | What to do |
| --- | --- |
| **Enough USDC and ETH** | Continue to review the deposit amount and fees |
| **USDT selected** | Review and exchange USDT for USDC; after verification, prepare ETH if still needed, then continue to the deposit |
| **Enough USDC, insufficient ETH** | When enabled and a supported quote is available, use the offered USDC-to-ETH step; alternatively prepare Arbitrum ETH and recheck |
| **No supported swap quote** | Prepare the requested USDC or ETH yourself, then recheck inside the same flow |

Swaps spend your own assets: USDT-to-USDC consumes USDT, and ETH preparation consumes USDC. They are not free gas grants. **Review and confirm every swap separately. A completed swap does not mean the Hyperliquid deposit has arrived.**

## Step 4: Confirm the deposit and wait for activation

1. Enter the deposit amount. Check the trading wallet, network, **Quoted fees**, and **Estimated received**.
2. First activation of a Hyperliquid address involves a **1 USDC activation fee**, in addition to the route's current CCTP, network, or swap charges. Meet the form's live amount checks and leave enough funds for preparation steps.
3. Follow **Confirm this step**, **Confirm Swap**, or **Confirm Deposit** as requested. Review token allowances and transactions in your wallet before signing. Completed steps are skipped.
4. Wait for verification of the source transaction, actual Hyperliquid credit, and account activation. A wallet's submitted status is not enough; do not close the flow or send another deposit just because submission succeeded.
5. After verification, setup returns to **Set Up API Wallet** and checks the trading wallet again. Confirm the name and address, then click **Next Step**.

<Note>
A source-wallet readiness threshold is different from the final minimum deposit. Follow the live fees, available balance, and estimated receipt instead of treating a fixed amount as a universal minimum.
</Note>

### If the operation is pending or interrupted

Return with the same trading wallet and network. Resume the existing operation and use **Check status**, or **Find transaction** when asked to verify an existing source transaction. Do not resubmit while its outcome is unknown. Keep browser storage available for recovery. If a quote expires before submission, obtain and review a fresh quote.

## Step 5: Enable Unified Account and generate the API Wallet

In **Set Up API Wallet**, confirm the account name and trading address, then click **Next Step**. Owly checks **Unified Account** mode once activation is confirmed. If needed, sign to enable it with the trading wallet and wait for confirmation. A confirmed setting is skipped.

Owly then generates and stores this copy account's dedicated API Wallet and opens **Approve API Wallet**. You do not create one manually on Hyperliquid or copy or import a private key.

## Step 6: Authorize and create

1. Check the generated **API Wallet public address** and the funded **trading wallet address**.
2. Click **Authorize & Create**. Sign the API Wallet approval with the trading wallet first and wait for Owly to verify it.
3. Complete **Builder fee authorization** if required, after reviewing its ceiling. The standard ceiling is **0.1%**; it is the maximum permitted rate, not the actual charge on every trade. See [Fee Structure](/faq/fees).
4. Setup may attempt optional Hyperliquid referral configuration; an existing referrer is preserved. Follow the current prompts. Confirmed authorizations do not need to be repeated.
5. Wait for account creation, check that the success screen shows your selected **trading account address**, and click **OK**.

If you cancel a signature or approval remains unconfirmed, keep the correct trading wallet connected and continue from the current step. Funding, API authorization, account creation, and starting a strategy are separate states.

## Step 7: Select the account and start copying

1. Return to the trader you want to follow and open **Copy Trade**.
2. Select the newly created account in the account dropdown.
3. Review the source trader, trading account, copy ratio, account Exit Rules, and other settings, then confirm. SL/TP thresholds start unset; check the saved configuration.
4. After a successful start, Owly opens the corresponding account card in Portfolio. Check bot status, actual orders, and positions. Account creation alone does not start trading.

## Common questions

### Does an already activated trading wallet need another deposit?

It does not need activation again. Once the check passes, continue to authorization. To add funds later, use the account-specific entry point in [Asset Management](/guide/asset-management).

### Why deposit if my wallet already holds USDC?

USDC in an Arbitrum wallet is different from the Hyperliquid trading balance. The integrated deposit moves the selected wallet's assets into its Hyperliquid account and verifies that credit.

### Which address do I fund if I log in with a different wallet?

Prepare Arbitrum assets at the trading wallet address shown in **Set Up API Wallet** and the embedded deposit screen. Funding only your login address will not fund the other trading account. Never fund the generated API Wallet.

### What if the balance or deposit progress does not update?

Check the original trading address, Arbitrum One network, selected asset, and source transaction, then use the current flow's status or refresh controls. Do not repeatedly deposit. For support, provide only public addresses, the issue time, and transaction hashes.

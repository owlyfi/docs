[Grid Trading](https://app.owly.fi/trading-bots/grid)에서 **Trading Bots → Grid Trading**을 엽니다. 봇을 관리하기 전에 로그인하세요.

## 현재 지원

그리드 편집기는 영구 시장, **Neutral**, **Long** 및 **Short** 방향, **Arithmetic** 또는 **기하학적** 간격 및 **교차** 또는 **격리** 여백. 또한 발동 가격, 방향성 초기 포지션, 전략 이익 실현 및 손절매 가격을 공개합니다.

<Note>
이 편집기에서는 스팟 그리드를 사용할 수 없습니다. 상향 및 하향 후행 컨트롤이 표시되지만 비활성화됩니다. 별도의 [Trade 터미널](/ko/guide/trading-terminal)에 있는 그리드 옵션도 미리보기입니다. 그리드 트레이딩 페이지를 사용하여 그리드 봇을 관리하세요.
</Note>

## 적합한 계정을 선택하세요

[계정 관리](https://app.owly.fi/accounts)에서 계정을 생성하거나 가져온 후 그리드 트레이딩으로 돌아갑니다. 생성 선택기에는 읽을 수 있고 사용 가능한 잔액이 있고 실행 중인 봇이 없는 계정이 필요합니다. 다른 봇 유형에 대해 구성된 계정은 제외됩니다.

- **API Wallet** 및 **Hyperliquid 하위 계정** 계정은 해당 기준을 충족하는 경우 사용할 수 있습니다.
- **온체인 대출 / LeverAcc** 계정은 그리드 계정 선택기에서 제외됩니다.
- 기존 **Owly 관리 하위 계정**에서는 봇 설정을 업데이트하거나 봇을 시작할 수 없습니다. 지원되는 인출 흐름을 통해 남은 자금을 자체 관리 계좌로 이동하세요.

선택기에서 누락된 계정이 계정 관리에 여전히 존재할 수 있습니다. 다른 계정을 추가하기 전에 유형, 잔액 및 기존 봇 구성을 확인하세요.

## 그리드 구성

**Create**을 클릭하고 계정과 계약 쌍을 선택한 후 다음 필드를 검토하세요.

| 필드 | 의미 |
| --- | --- |
| 방향 | 뉴트럴, 롱, 쇼트 |
| 마진 및 레버리지 | 교차 또는 격리, 선택한 시장에서 허용되는 레버리지 내 |
| 낮은 가격과 높은 가격 | 그리드의 가격대; 높은 가격은 낮은 가격을 초과해야 합니다. |
| 그리드 수 | 간격 수; 예상 가용 주문 할당량에 따라 최소 2, |
| 투자 | 그리드에 할당된 총 자본은 소수점 이하 두 자리까지 입력됩니다. 양수여야 하며 계정의 사용 가능한 잔액보다 적어야 합니다. |
| 가격 알고리즘 | 산술은 동일한 가격 차이를 사용합니다. 기하학은 동일한 가격 비율을 사용합니다. |
| 발동가격 | 선택사항; 활성화되면 가격이 선택한 위 또는 아래 조건에 도달한 후 시작됩니다. |
| 초기 위치 | 긴 모드 또는 짧은 모드에서 사용할 수 있습니다. 중립 모드에서 비활성화됨 |
| 이익 실현/손실 중지 | 위험 이탈을 시작하는 선택적 전략 가격 수준 |
| 동기화 간격 | 주문 조정 간격; 양식은 15초에 시작됩니다. |

이 페이지는 선택한 시장과 범위에서 최소 투자액, 주문당 수량, 그리드당 이익을 추정합니다. 이는 추정치입니다. 교환 주문 최소값, 정밀도, 수수료, 사용 가능한 마진 및 실시간 가격에 따라 봇이 시작되고 실행될 수 있는지 여부가 결정됩니다.

<Warning>
그리드 수를 늘리면 더 많은 주문에 투자가 나누어집니다. 그리드 수가 더 많다고 해서 더 많은 수익이 보장되는 것은 아니며 개별 주문이 교환 최소 금액보다 낮을 수 있습니다. 손실과 수수료에 대비해 여유분을 남겨두세요.
</Warning>

## 방향과 초기 포지션

**Neutral**은 기준가 아래에 매수 주문을, 기준가 위에 매도 주문을 냅니다. 롱이나 숏 방향의 초기 포지션을 자동으로 열지 않습니다.

**Long**은 매수 주문으로 롱 포지션을 늘리고, 포지션 감소 전용(reduce-only) 매도 주문으로 줄입니다. **Short**는 매도 주문으로 숏 포지션을 늘리고, 포지션 감소 전용 매수 주문으로 줄입니다. 두 방향 모드 모두 초기 포지션 옵션을 켜면 시작 시 포지션을 만들 수 있습니다. 봇을 시작하기 전에 기존 포지션을 확인하세요. 기존 포지션이 선택한 방향과 호환되지 않거나 증거금이 부족하면 시작하지 못할 수 있습니다.

## 저장, 시작, 중지

1. **Save**는 봇을 시작하지 않고 구성을 저장합니다.
2. 시작 동작을 사용하고 확인을 검토한 후 시작을 확인하세요. 저장에 성공했지만 시작에 실패하면 구성은 저장된 상태로 유지됩니다. 다시 시도하기 전에 오류와 상태를 확인하세요.
3. 실행상태, 계좌잔액, 주문, 포지션을 모니터링하세요. 저장된 구성 또는 수락된 요청은 모든 그리드 주문이 충족되었음을 증명하지 않습니다.
4. 편집하기 전에 봇을 중지하세요. 실행 중인 그리드는 편집기에서 읽기 전용입니다.
5. ​​중지 대화상자에서 기본적으로 선택되어 있는 **모든 위치 닫기**를 검토하세요. 이를 청산하면 포지션을 청산하지 않고 정지를 요청합니다. 이를 유지하면 중지 및 닫기가 요청됩니다. 각 조치 후에 결과 주문 및 포지션을 확인하십시오.

이익 실현 및 손실 중지 트리거는 정상적인 그리드 유지 관리를 종료하고 위험 종료를 시작합니다. 실행이 지연되거나 거부되거나 부분적으로 채워질 수 있습니다. 중지, 닫기 요청 또는 위험 임계값은 즉각적인 채우기 또는 고정된 최종 손실을 보장하지 않습니다.

## UI 설정 및 API 호환성

현재 양식에서는 총 투자금을 `total_invest`로 보냅니다. 주문별 `order_size` 또는 별도의 `bootstrap_size`를 요구하지 않습니다. 이전 구성에는 여전히 해당 필드가 포함될 수 있습니다. 기존의 주문별 예시를 현재 투자 입력으로 취급하지 마세요.

새로운 그리드 구성은 기존 구성이 이미 모드를 지정하지 않는 한 `account_mode: "auto"`를 사용합니다. 편집기는 계정 모드 선택기를 제공하지 않으므로 이는 계정을 추가할 때 필요한 통합 계정 설정과 별개입니다.

페이로드는 `trailing_up_limit` 및 `trailing_down_limit`과의 호환성을 유지하며 과거 후행 값을 읽을 수 있습니다. 두 개의 후행 컨트롤은 현재 UI에서 비활성화되어 있습니다. 새로 생성된 양식 값은 `0`에 그대로 둡니다. 백엔드에서 필드를 수락하거나 유지한다고 해서 사용자가 편집기에서 해당 필드를 활성화할 수 있다는 의미는 아닙니다. 마찬가지로 `rebalance_tolerance_bps`와 같은 백엔드 매개변수는 현재 편집 가능한 양식 컨트롤이 아닙니다.

계정 설정은 [계정 유형](/ko/guide/account-types)을, 거래 비용은 [수수료](/ko/faq/fees)를 참조하세요.

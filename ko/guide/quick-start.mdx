이 가이드에서는 **API 지갑** 계정 유형으로 Owly 카피 트레이딩 계정을 만드는 방법을 설명합니다. OKX Web3 브라우저 지갑 등 지원되는 EVM 지갑을 사용하세요. **계정 설정 중에 입금할 수 있으므로 Hyperliquid에 미리 방문해 가입하거나 입금하거나 API 지갑을 직접 만들 필요가 없습니다.**

```text
로그인 → 하위 계정 만들기 → API 지갑 선택 → 계정 이름 입력 및 거래 지갑 연결
  → 비활성 상태면 설정 화면에서 입금 → 입금 확인 대기 → 계정 세부 정보로 돌아가기
  → 필요하면 통합 계정 활성화 → API 지갑 생성 및 승인 → 계정 생성 → 카피 트레이딩 시작
```

## 거래 지갑 선택

| 역할 | 용도 |
| --- | --- |
| **Owly 로그인 지갑** | 로그인, 계정 추가, 카피 트레이딩 관리에 사용 |
| **거래 지갑** | 입금할 자산을 보유하고 Hyperliquid에서 입금을 받으며 권한 승인에 서명하는 지갑. 로그인 지갑과 같은 지갑을 사용할 수 있음 |
| **API 지갑** | 계정 활성화 후 Owly가 생성하는 거래 서명용 지갑. 입금 주소로 사용하지 않음 |

첫 계정은 지갑을 새로 만들지 않고 로그인 지갑을 거래 지갑으로 사용할 수 있습니다. 두 주소가 서로 다르면 **설정 화면에 표시된 거래 지갑**에 자금을 준비하고, 그 지갑으로 권한을 승인하세요.

<Warning>
API 지갑 주소에 자금을 보내지 마세요. 계정 설정 과정에서 시드 문구, 소유 지갑의 개인 키 또는 API 지갑의 개인 키를 요구하지 않습니다.
</Warning>

## 1단계. Owly에 로그인

1. [Owly 계정 관리](https://app.owly.fi/accounts)를 엽니다.
2. 지갑을 연결하고 주소를 확인한 뒤 로그인 메시지에 서명합니다.
3. 처음 방문했다면 이용약관과 개인정보 처리방침을 읽고 화면의 안내에 따라 초기 설정을 완료합니다.

첫 로그인 설정과 카피 트레이딩 계정 생성은 별도의 절차입니다. 로그인만으로 카피 트레이딩 계정이 생성되거나 다른 거래 지갑에 자동으로 입금되지 않습니다.

## 2단계. API 지갑 계정 추가

1. **계정**에서 **계좌를 만들기**(Create Sub Account)를 클릭합니다.
2. **계정 유형 선택**에서 **API 지갑**을 선택하고 **다음 단계**를 클릭합니다.
3. API 지갑 설정 화면(**세트 Up API 지갑**)에서 **계정 이름**을 입력합니다.
4. **Connect**(연결)를 클릭하고 실제로 거래할 지갑을 선택합니다. 표시된 주소를 확인하고, 필요하면 **Switch**(전환)를 사용해 변경합니다.

<Note>
트레이더의 카피 트레이드 대화 상자에서도 계정 드롭다운의 **새로운 Sub 계정 만들기**(Create New Sub Account)를 선택하면 계정 관리의 동일한 생성 절차를 열 수 있습니다.
</Note>

Owly는 연결된 주소가 Hyperliquid 계정을 소유한 사용자 지갑인지 확인합니다. **활성화되지 않은 주소는 아래의 통합 입금 절차로 자동 이동합니다.** 이미 활성화된 거래 지갑은 활성화 수수료를 다시 내지 않고 5단계로 진행할 수 있습니다. API 에이전트, Hyperliquid 하위 계좌 또는 볼트 주소를 이 계정 유형의 소유 지갑으로 사용할 수 없습니다.

## 3단계. 계정 설정 화면에서 자금 준비

입금 화면은 **2단계에서 연결한 거래 지갑**을 사용합니다. Owly 로그인 지갑이 달라도 입금 대상은 거래 지갑입니다.

1. **Deposit**(입금) 화면의 **Asset**(자산)에서 **USDC** 또는 **USDT**를 선택하고 **Next**(다음)를 클릭합니다.
2. 네트워크가 **Arbitrum One 메인넷**인지 확인합니다. 통합 입금은 이 지갑의 Hyperliquid 계정에 USDC를 입금합니다.
3. 입금에 사용할 지갑에 자금이 부족하면 화면에 표시된 주소와 최소 잔액을 확인해 자산을 준비합니다. 전송 전에 네트워크를 확인하세요. 화면이 잔액을 자동으로 확인합니다.
4. 잔액이 현재 요건을 충족하면 Owly에서 진행 중인 절차를 이어갑니다.

| 화면 상태 | 조치 |
| --- | --- |
| **USDC와 ETH가 충분함** | 입금 금액과 수수료 검토 단계로 이동합니다. |
| **USDT 선택** | 교환 내용을 검토하고 USDT를 USDC로 교환합니다. 교환이 확인되면 필요에 따라 ETH를 준비한 뒤 입금을 진행합니다. |
| **USDC는 충분하나 ETH가 부족함** | 해당 기능이 활성화되어 있고 지원되는 견적이 있으면 제공되는 USDC → ETH 교환 단계를 이용합니다. Arbitrum의 ETH를 직접 준비한 뒤 잔액을 다시 확인할 수도 있습니다. |
| **지원되는 교환 견적이 없음** | 요청된 USDC 또는 ETH를 직접 준비한 뒤 진행 중인 절차에서 다시 확인합니다. |

교환에는 본인 자산이 사용됩니다. USDC로 바꿀 때는 USDT가, ETH를 준비할 때는 USDC가 차감됩니다. 가스비가 무료로 제공되는 방식이 아닙니다. **각 교환을 별도로 검토하고 확인하세요. 교환이 완료되어도 Hyperliquid 입금이 확인된 것은 아닙니다.**

## 4단계. 입금 확인 및 활성화 대기

1. 입금 금액을 입력합니다. 거래 지갑, 네트워크, **Quoted fees**(견적 수수료), **Estimated received**(예상 수령액)를 확인합니다.
2. Hyperliquid 주소를 처음 활성화할 때는 경로별 CCTP, 네트워크 또는 교환 수수료 외에 **1 USDC의 활성화 수수료**가 듭니다. 현재 화면에 표시되는 금액 요건을 충족하고 자금 준비 단계에 필요한 잔액을 남겨 두세요.
3. 화면에 표시되는 **Confirm this step**(이 단계 확인), **Confirm Swap**(교환 확인) 또는 **Confirm Deposit**(입금 확인)을 진행합니다. 서명하기 전에 지갑에서 토큰 사용 한도와 거래 내용을 확인하세요. 완료된 단계는 건너뜁니다.
4. 출발 네트워크의 거래, 실제 Hyperliquid 입금, 계정 활성화가 모두 확인될 때까지 기다립니다. 지갑에 거래가 제출되었다고 표시되어도 확인이 끝난 것은 아닙니다. 제출 성공만 보고 화면을 닫거나 다시 입금하지 마세요.
5. 확인이 끝나면 API 지갑 설정으로 돌아가 거래 지갑을 다시 확인합니다. 계정 이름과 주소를 확인하고 **다음 단계**를 클릭합니다.

<Note>
입금에 사용할 지갑에 필요한 준비 잔액과 최종 최소 입금액은 다릅니다. 화면에 표시되는 실시간 수수료, 사용 가능 잔액, 예상 수령액을 기준으로 진행하세요.
</Note>

### 작업이 대기 중이거나 중단된 경우

같은 거래 지갑과 네트워크로 돌아와 기존 작업을 재개합니다. **Check status**(상태 확인)를 사용하거나, 이미 제출된 거래를 확인하라는 안내가 나오면 **Find transaction**(거래 찾기)을 사용하세요. 결과를 확인하기 전에는 다시 제출하지 마세요. 작업을 복구할 수 있도록 브라우저 저장소를 유지하세요. 제출 전에 견적이 만료되면 새로 받아 검토합니다.

## 5단계. 통합 계정 활성화 및 API 지갑 생성

API 지갑 설정에서 계정 이름과 거래 주소를 확인하고 **다음 단계**를 클릭합니다. 활성화가 확인되면 Owly가 **통합 계정(Unified Account)** 모드의 사용 여부를 확인합니다. 필요하면 거래 지갑에서 통합 계정 활성화에 서명하고 확인을 기다립니다. 이미 활성화되어 있으면 이 단계를 건너뜁니다.

Owly가 이 카피 트레이딩 계정 전용 API 지갑을 생성하고 저장한 뒤 **Approve API Wallet**(API 지갑 승인) 화면을 엽니다. Hyperliquid에서 직접 생성하거나 개인 키를 복사하거나 가져올 필요가 없습니다.

## 6단계. 승인 및 계정 생성

1. 생성된 **API 지갑의 공개 주소**와 입금한 **거래 지갑 주소**를 확인합니다.
2. **Authorize & Create**(승인 및 생성)를 클릭합니다. 먼저 거래 지갑으로 API 지갑 승인에 서명한 뒤 Owly의 확인을 기다립니다.
3. 필요한 경우 수수료 상한을 검토하고 **빌더 수수료를 승인**합니다. 표준 상한은 **0.1%**이며, 각 거래에 적용할 수 있는 최고 요율입니다. 실제 수수료는 [수수료 구조](/ko/faq/fees)를 참조하세요.
4. 계정 설정 과정에서 선택 사항인 Hyperliquid 추천인 설정을 시도할 수 있습니다. 이미 등록된 추천인은 그대로 유지됩니다. 화면에 표시되는 안내를 따르세요. 이미 확인된 승인을 반복할 필요는 없습니다.
5. 계정이 생성되면 완료 화면에 선택한 **거래 계정 주소**가 표시되는지 확인하고 **확인**을 클릭합니다.

서명을 취소했거나 승인이 아직 확인되지 않은 경우, 올바른 거래 지갑을 연결한 상태로 현재 단계부터 계속 진행하세요. 입금, API 승인, 계정 생성, 전략 시작은 각각 별도의 상태입니다.

## 7단계. 계정 선택 및 카피 트레이딩 시작

1. 따라 할 트레이더의 페이지로 돌아가 **복사 무역**(Copy Trade)을 엽니다.
2. 계정 드롭다운에서 방금 만든 계정을 선택합니다.
3. 대상 트레이더, 거래 계정, 복사 비율, 계정의 **출구 규칙**(Exit Rules) 및 기타 설정을 검토한 뒤 확인합니다. 처음에는 손절·익절(SL/TP) 임계값이 설정되어 있지 않으므로 저장된 설정을 확인하세요.
4. 전략이 시작되면 Owly가 **포트폴리오**에서 해당 계정 카드를 엽니다. 봇 상태와 실제 주문, 포지션을 확인하세요. 계정만 생성하면 거래가 시작되지 않습니다.

## 자주 묻는 질문

### 이미 활성화된 거래 지갑에 다시 입금해야 하나요?

다시 활성화할 필요는 없습니다. 확인이 끝나면 승인 단계로 진행하세요. 나중에 추가로 입금하려면 [자산 관리](/ko/guide/asset-management)에 설명된 계정 유형별 입금 방법을 이용하세요.

### 지갑에 USDC가 있는데 왜 입금해야 하나요?

Arbitrum 지갑의 USDC와 Hyperliquid에서 거래할 수 있는 잔액은 별개입니다. 통합 입금은 선택한 지갑의 자산을 해당 지갑의 Hyperliquid 계정으로 옮기고 입금 여부를 확인합니다.

### 다른 지갑으로 로그인했다면 어느 주소에 자금을 준비해야 하나요?

API 지갑 설정과 통합 입금 화면에 표시된 거래 지갑 주소에 Arbitrum 자산을 준비하세요. 로그인 주소에만 입금하면 다른 거래 계정에는 반영되지 않습니다. 생성된 API 지갑에 자금을 보내지 마세요.

### 잔액이나 입금 상태가 업데이트되지 않으면 어떻게 하나요?

처음 사용한 거래 주소, Arbitrum One 네트워크, 선택한 자산 및 출발 네트워크의 거래를 확인한 뒤 현재 절차에서 상태 확인 또는 새로고침 기능을 사용하세요. 동일한 입금을 반복하지 마세요. 지원팀에 문의할 때는 공개 주소, 문제가 발생한 시간, 거래 해시만 제공하세요.

Owly에서 트레이더를 찾고 거래를 자동으로 따라 하는 방법을 안내합니다.

## 트레이더 찾기

### 탐색 페이지

**카피 트레이드 → 탐색**을 엽니다. 탐색 페이지의 **다차원 순위 시스템**은 ROI를 포함한 여러 성과 지표를 종합해 성과가 좋은 트레이더를 찾는 데 도움을 줍니다.

<CardGroup cols={2}>
  <Card title="스마트 순위" icon="trophy">
    수익, 위험, 안정성을 고려해 가중치를 부여한 점수입니다.
  </Card>
  <Card title="성과 필터" icon="filter">
    ROI, 승률, 기간을 기준으로 필터링합니다.
  </Card>
  <Card title="위험 지표" icon="chart-line">
    낙폭, 레버리지 사용 현황, 변동성을 확인합니다.
  </Card>
  <Card title="거래 스타일" icon="sliders">
    선호하는 전략에 맞는 트레이더를 찾습니다.
  </Card>
</CardGroup>

### 주요 지표

| 지표 | 확인할 사항 |
|--------|------------------|
| **순위 점수** | 점수가 높을수록 종합적인 균형이 좋습니다. |
| **샤프 비율** | 2를 초과하면 위험 조정 수익률이 우수하다는 뜻입니다. |
| **최대 낙폭** | 일반적으로 낮을수록 위험이 적습니다(20% 미만). |
| **승률** | 50%를 초과하는지, 손익비도 양호한지 함께 확인합니다. |
| **거래 빈도** | 원하는 거래 빈도와 일치하는지 확인합니다. |

## 카피 트레이딩 시작

<Steps>
  <Step title="트레이더 선택">
    트레이더 카드를 클릭해 전체 프로필을 엽니다.
  </Step>
  <Step title="세부 정보 검토">
    거래 이력, 보유 포지션, 위험 지표를 분석합니다.
  </Step>
  <Step title="카피 트레이딩 열기">
    **복사 무역**(Copy Trade) 버튼을 누릅니다.
  </Step>
  <Step title="하위 계정 선택">
    사용 가능한 API 지갑 계정, Hyperliquid 하위 계좌 또는 승인된 LeverAcc 계정을 선택합니다. 이미 봇을 실행 중이거나 사용 가능 담보를 확인할 수 없는 계정은 선택할 수 없습니다. 기존 Owly 관리 계정도 선택할 수 없습니다.
  </Step>
  <Step title="복사 비율 설정">
    각 거래를 어느 정도 규모로 따라 할지 설정합니다(예: 0.5x, 1x, 2x).
  </Step>
  <Step title="위험 설정">
    이 계정의 **출구 규칙**(SL/TP), PE 비율 상한, ROE 진입 필터, 시장·코인 선택, 레버리지 동기화를 검토합니다. SL/TP 임계값은 처음에 설정되어 있지 않으므로 필요한 값을 직접 설정합니다.
  </Step>
  <Step title="확인">
    모든 설정을 검토하고 카피 트레이딩을 시작합니다.
  </Step>
</Steps>

## 복사 비율 계산

복사 비율은 트레이더의 포지션에 비례해 내 포지션의 규모를 결정합니다.

예를 들어 트레이더의 총자본이 **100,000 USDC**이고 내 자본이 **10,000 USDC**라고 가정합니다. 트레이더가 자본의 **10%**로 포지션을 열면 거래 규모는 **10,000 USDC**입니다. 복사 비율이 **1x**이면 내 자본에도 같은 비중을 적용하므로 내 거래 규모는 **1,000 USDC**입니다. 복사 비율에 따른 결과는 다음과 같습니다.

| 복사 비율 | 트레이더의 10% 포지션($10,000) | 내 포지션 규모 |
|------------|-------------------------------------|----------|
| 0.5x | $10,000 | $500 |
| 1x | $10,000 | $1000 |
| 2x | $10,000 | $2000 |

<Note>
  카피 트레이딩은 트레이더의 거래를 따라 하기 때문에 손익까지 100% 일치하지는 않습니다. 시장이 복잡하고 빠르게 움직일 수 있어, Owly는 트레이더의 성과에 가능한 한 가까워지도록 거래를 실행합니다.
</Note>

<Warning>
  복사 비율이 높을수록 이익과 손실이 모두 커집니다. 신중하게 설정하세요.
</Warning>

## 실행 중인 카피 트레이딩 관리

### 상태 확인

**카피 트레이드 → 포트폴리오**에서 다음 내용을 확인합니다.
- 실행 중인 카피 트레이딩 연결
- 현재 카피 트레이딩 상태와 확인 가능한 포지션
- 선택한 기간의 성과

### 카피 트레이딩 중지

<Steps>
  <Step title="포트폴리오로 이동">
    해당 하위 계정을 엽니다.
  </Step>
  <Step title="실행 중인 카피 트레이딩 찾기">
    실행 중인 카피 트레이딩 카드를 찾습니다.
  </Step>
  <Step title="중지 클릭">
    **카피 트레이딩 중지**(Stop Copy Trading)를 누릅니다.
  </Step>
  <Step title="포지션 처리 선택">
    기존 포지션을 청산할지 유지할지 선택합니다.
  </Step>
</Steps>

<Note>
  중지 대화 상자에서는 기본적으로 포지션 청산 옵션이 선택되어 있습니다. 포지션을 유지하면서 자동화만 중지하려면 해당 옵션을 해제하세요. 요청 후 남은 포지션, 주문 및 봇 정리 상태를 확인하세요. 요청이 제출되어도 모든 청산 주문이 체결되었다고 볼 수는 없습니다. LeverAcc 전략을 중지해도 대출금은 상환되지 않습니다.
</Note>

## 고급 설정 및 계정 한도

카피 설정에는 현물·무기한 계약 선택, 거래 장소 필터, 주기적 포지션 동기화, TWAP 복사, 호가 통화 동기화 및 소규모 포지션 필터가 포함됩니다. 설정의 효과는 활성화한 시장과 사용 가능한 담보에 따라 달라집니다. ROE 필터는 원본 트레이더의 기존 포지션을 동기화할지 결정합니다. 손절은 별도로 설정합니다.

**LeverAcc** 계정은 미체결 주문을 복사할 수 없습니다. 프로젝트 연결과 실행 권한을 유효하게 유지해야 합니다. 계정을 추가하거나 입금해도 카피 트레이딩이 자동으로 시작되지 않습니다.

**내역**에서 이전 봇 작업을 확인합니다. 전략을 시작하거나 변경한 후에는 저장된 설정과 실제 체결 내역을 확인하세요. [위험 관리](/ko/advantages/risk-management)와 [포트폴리오 및 탐색](/ko/guide/dashboard)을 참조하세요.

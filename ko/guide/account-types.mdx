## Hyperliquid API 지갑 이해하기

Hyperliquid의 **API 지갑**은 **에이전트 지갑**이라고도 합니다. 마스터 계정에서 승인한 서명용 에이전트이며, 마스터 계정이나 그에 속한 Hyperliquid 하위 계좌의 지원되는 거래 작업에 서명할 수 있습니다. **API 지갑을 생성하거나 승인해도 별도의 Hyperliquid 마스터 계정이 생성되거나 별도의 거래 자금이 배정되지는 않습니다.** 잔액, 포지션 및 손익을 조회할 때는 실제 마스터 계정 또는 하위 계좌 주소를 사용하세요. [Hyperliquid API 지갑 문서](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/nonces-and-api-wallets#api-wallets)를 참조하세요.

API 지갑 권한으로는 자금을 보유한 지갑의 입금에 서명하거나 마스터 계정의 자금을 외부 지갑으로 출금할 수 없습니다. 입금은 자금을 보유한 지갑에서 시작하고, 출금에는 마스터 지갑의 서명이 필요합니다. API 지갑은 입금 대상 주소가 아닙니다. 이 제한은 외부 입출금에 관한 것이며, 에이전트에 내부 자금 작업 권한이 전혀 없다는 뜻은 아닙니다. [Hyperliquid 입금 가이드](https://hyperliquid.gitbook.io/hyperliquid-docs/onboarding/how-to-start-trading)와 [출금 엔드포인트](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/exchange-endpoint#initiate-a-withdrawal-request)를 참조하세요.

<Warning>
API 지갑이 유출되면 악의적인 거래와 손실이 발생할 수 있습니다. API 지갑 주소에 입금하거나 카피 트레이딩 자금을 보관하는 별도 계정으로 취급하지 마세요.
</Warning>

## Owly 로그인 계정과 거래 계정 구분하기

Owly는 사용자가 관리하는 거래 계정을 통틀어 ‘하위 계정’이라고 부릅니다. 생성 화면에는 **API 지갑**, **Hyperliquid 하위 계좌**, **온체인 대출(알파)**의 세 가지 유형이 표시됩니다. Hyperliquid 하위 계좌는 기존 하위 계좌를 가져오거나 마스터 계정이 자격 요건을 충족하면 새로 생성합니다. 온체인 대출은 내장 화면에서 LeverAcc 프로토콜 계정을 생성하거나 연결합니다.

- **Owly 기본 계정**은 Owly에 로그인하고 계정을 관리하는 데 사용하는 지갑입니다.
- **거래 계정**은 Hyperliquid 거래 자금과 포지션을 보유한 계정입니다.
- **API 지갑**은 거래 계정의 승인을 받은 서명용 에이전트입니다. 거래 자금은 거래 계정에 보관됩니다.

**Owly 기본 계정과 거래 계정에는 같은 지갑 주소를 사용할 수 있습니다.** 한 주소로 로그인한 뒤 다른 주소를 별도 거래 계정으로 추가할 수도 있습니다. 주소를 분리한 경우 로그인 주소, 입금 주소, 서명 주소를 각각 확인하세요. 주소 하나를 사용하는 경우 지갑 계정을 추가로 만들 필요가 없습니다.

**Owly 기본 계정 하나에서 활성 거래 계정은 세 유형을 합해 최대 10개입니다.** 예를 들어 API 지갑 또는 Hyperliquid 하위 계좌 유형의 계정 9개와 활성 온체인 대출 계정 1개를 추가하면 한도에 도달합니다. 아래에서 설명하는 Hyperliquid 자체 하위 계좌의 생성 요건과 한도는 별개입니다.

## 세 가지 유형 비교

| 유형 | 적합한 경우 | 준비 사항 | 고려 사항 |
|:--|:--|:--|:--|
| **API 지갑** | 본인이 관리하는 Hyperliquid 마스터 계정으로 거래하려는 경우. 대부분의 신규 사용자에게 적합 | Owly에 연결해 권한을 승인할 거래 지갑 | 각 거래 계정에는 별도의 Hyperliquid 마스터 주소가 필요하며, 그중 하나는 Owly 로그인 주소와 같아도 됨 |
| **Hyperliquid 하위 계좌** | Hyperliquid 마스터 계정에 속한 하위 계좌를 관리하려는 경우 | 마스터 지갑과 기존 하위 계좌 또는 하위 계좌 생성 자격. Owly가 전용 API 지갑을 생성 | 새 하위 계좌의 생성에는 Hyperliquid의 자격 및 한도 확인이 적용됨 |
| **온체인 대출(알파)** | LeverAcc에서 담보로 USDC를 빌려 거래하려는 경우 | 설정 화면이 요구하는 USDC와 가스비 자산을 보유한 자금 지갑 또는 기존 LeverAcc 거래 계정 | 알파 기능. 생성, 연결, 차입, 전략 시작은 별도 작업 |

## API 지갑 한도 및 사용하지 않는 승인 철회

Hyperliquid 마스터 계정은 기본적으로 **이름이 지정된 API 지갑을 최대 3개** 승인할 수 있습니다. 마스터 계정을 사용하는 모든 앱이 이 한도를 공유합니다. 이름이 없는 API 지갑 1개도 승인할 수 있으며, Hyperliquid 하위 계좌마다 이름이 지정된 API 지갑 한도가 2개씩 늘어납니다. [Hyperliquid의 공식 API 지갑 한도](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/exchange-endpoint#approve-an-api-wallet)를 참조하세요. 이 승인 한도와 위에서 설명한 Owly 거래 계정 한도는 별개입니다.

한도에 도달해 API 지갑을 생성하거나 갱신하지 못한 경우 다음과 같이 진행하세요.

1. [Hyperliquid API 페이지](https://app.hyperliquid.xyz/API)를 열고 승인 권한을 가진 마스터 지갑을 연결합니다. Hyperliquid 하위 계좌에 대해서는 해당 계좌의 마스터 지갑을 사용하세요.
2. API 지갑 이름과 주소를 확인한 뒤 더 이상 사용하지 않는 승인을 삭제하거나 철회합니다. Owly나 다른 앱이 사용 중인 API 지갑을 제거하면 해당 앱에서 그 지갑으로 거래를 계속할 수 없습니다.
3. 승인 한도에 여유가 있는지 확인한 뒤 Owly로 돌아가 API 지갑 생성 또는 승인 갱신을 다시 시도합니다.

## API 지갑 승인 유효 기간과 갱신

Hyperliquid에서 API 지갑 승인의 유효 기간은 **최대 180일**입니다. 이 기간은 승인에 적용되며 거래 계정에는 적용되지 않습니다. [Hyperliquid의 공식 API 지갑 승인 규칙](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/exchange-endpoint#approve-an-api-wallet)을 참조하세요.

Owly의 기본 승인 유효 기간은 다음과 같습니다.

| 계정 유형 | 기본 API 지갑 승인 유효 기간 |
|:--|:--|
| API 지갑 | **180일** |
| Hyperliquid 하위 계좌 | **180일** |
| LeverAcc 온체인 대출(알파) | 현재 설정 화면에는 **90일**로 표시됩니다. 확인된 실제 만료 시점을 확인하세요. |

<Warning>
**API 지갑 및 Hyperliquid 하위 계좌** 유형은 승인 만료까지 **10분**이 남으면 정기 만료 확인 작업이 실행 중인 봇의 종료를 시도합니다. 이 작업은 LeverAcc에 적용되지 않으며 정확한 중지 시점이나 포지션 정리 성공을 보장하지 않습니다. 이 기간에 들어가기 전에 충분한 여유를 두고 승인을 갱신한 뒤, 새로 확인된 만료 시점과 봇 상태 및 포지션을 확인하세요.
</Warning>

## Owly의 API 지갑 계정 유형

이 유형은 **자금을 보유한 EVM 주소에 해당하는 별도의 Hyperliquid 마스터 계정**을 사용합니다. Hyperliquid 자체 하위 계좌와는 다릅니다. 이 유형의 거래 계정을 여러 개 추가하려면 마스터 계정 하나에 API 지갑을 여러 개 만드는 대신 마스터 주소를 각각 준비하세요. 거래 계정 하나는 Owly 로그인 주소를 사용해도 됩니다.

**API 지갑**을 선택하고 계정 이름을 입력한 뒤 Hyperliquid 거래 계정의 지갑을 **Connect**(연결)합니다. 표시된 주소를 확인하세요. Owly 로그인 주소를 사용해도 됩니다. 주소가 Hyperliquid에서 아직 활성화되지 않았다면 입금 안내에 따라 진행하고 활성화를 기다리세요. API 에이전트, 볼트 또는 Hyperliquid 하위 계좌 주소를 이 유형의 소유 지갑으로 사용할 수 없습니다. 이 설정 화면에는 API 지갑 개인 키 입력란이 없습니다.

Owly는 거래 계정이 **통합 계정(Unified Account)** 모드를 사용하는지 확인하고, 필요한 경우 서명으로 활성화하도록 요청합니다. 그런 다음 API 지갑을 생성해 안전하게 보관하고 공개 주소를 표시한 뒤, 연결된 거래 지갑으로 승인하도록 요청합니다. 필요한 경우 요율 상한을 확인하고 **빌더 수수료 승인**을 완료하세요. 이미 확인된 승인은 건너뜁니다.

<Info>
생성된 API 거래 키는 Owly가 관리하며 마스터 지갑은 사용자가 관리합니다. 잔액, 포지션, 손익은 거래 계정 주소에 귀속됩니다. API 지갑으로 입금하지 마세요. 설정을 위해 Hyperliquid의 API 페이지에서 지갑을 직접 생성하거나 개인 키를 복사할 필요가 없습니다.
</Info>

처음 계정을 추가하는 경우 [빠른 시작](/ko/guide/quick-start)에 따라 준비, 입금, 연결 및 승인을 진행하세요.

## Hyperliquid 하위 계좌

이 유형은 Hyperliquid 마스터 계정에 속한 **프로토콜 자체 하위 계좌**를 사용합니다. 앞서 설명한 별도 마스터 계정과 다릅니다. [Hyperliquid의 규칙](https://hyperliquid.gitbook.io/hyperliquid-docs/trading/sub-accounts)에 따르면 **거래량이 $100,000**에 도달하면 하위 계좌를 최대 **10개**까지 만들 수 있습니다. **거래량이 $100,000,000**씩 추가될 때마다 한도가 1개씩 늘어나며 최대 **50개**까지 만들 수 있습니다. 즉, 10개는 Hyperliquid의 기본 할당량이며 최대 한도가 아닙니다. 이 할당량은 위에서 설명한 Owly 계정 한도와 별개입니다.

하위 계좌를 소유한 Hyperliquid 마스터 지갑으로 Owly에 로그인한 뒤 **Hyperliquid 하위 계좌**를 선택해 그 지갑의 하위 계좌 목록을 불러옵니다. 기존 하위 계좌를 선택하고 이름을 입력하세요. Owly는 마스터 계정의 통합 계정 모드를 확인하고 필요한 경우 활성화 서명을 요청한 뒤, 가져올 하위 계좌의 전용 API 지갑을 생성해 보관합니다. 생성된 API 지갑 주소를 확인한 다음 **마스터 지갑**으로 API 지갑 승인과 필요한 빌더 수수료 승인을 완료합니다. Hyperliquid에서 API 지갑을 만들거나 개인 키를 입력할 필요가 없습니다. 이미 추가한 하위 계좌는 다시 선택할 수 없습니다.

Owly가 마스터 계정의 자격과 남은 한도를 확인하면 선택 화면에서 Hyperliquid 하위 계좌를 새로 생성할 수도 있습니다. 사용할 수 있는 계정 이름을 입력하고 생성 옵션을 선택하세요. 마스터 계정의 API 지갑 승인을 요청하는 경우 먼저 완료하세요. Owly가 하위 계좌 생성 요청을 제출하려면 이 승인이 필요합니다. Hyperliquid에서 새 계좌를 확인한 뒤 가져오기 절차를 이어가고 전용 API 지갑을 승인하세요. 생성할 수 없는 경우 마스터 지갑과 [Hyperliquid 하위 계좌](https://app.hyperliquid.xyz/subAccounts)에 표시된 생성 자격을 확인하세요.

<Warning>
Hyperliquid 자체 하위 계좌에는 별도의 개인 키가 없습니다. 마스터 계정이 API 지갑을 승인합니다. Owly는 같은 논스를 사용해 충돌하는 일을 줄이기 위해 가져온 하위 계좌마다 별도의 API 지갑을 자동으로 생성합니다. 프로토콜 차원에서 해당 API 지갑이 하위 계좌 하나에만 제한되는 것은 아닙니다. [하위 계좌 서명](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/exchange-endpoint#subaccounts-and-vaults)과 [API 지갑](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/nonces-and-api-wallets#api-wallets)을 참조하세요.
</Warning>

관리를 위임하려면 [자산 소유자 가이드](/ko/guide/owner-guide)를 참조하세요.

## 온체인 대출(알파)

**온체인 대출**은 담보로 빌린 USDC로 거래할 수 있도록 LeverAcc 계정을 연결하는 유형입니다. 계정 유형 선택 화면에서 **온체인 대출(알파)**을 직접 선택합니다.

<Warning>
이 계정 유형은 **알파** 단계입니다. 프로젝트 연결이 확인되었고 실행 권한이 유효한 계정을 카피 트레이딩에 사용할 수 있습니다. 현재 그리드 봇의 계정 선택 화면에는 LeverAcc 계정이 표시되지 않습니다. 계정 추가만으로 전략이 시작되거나 자금이 자동으로 차입되지는 않습니다. 사용 가능 여부는 현재 앱 설정과 프로토콜 확인 결과에 따라 달라집니다.
</Warning>

1. 계정 이름을 입력하고 **Connect Funding Wallet**(자금 지갑 연결)을 선택합니다. 이 지갑은 Owly 로그인 지갑과 다를 수 있습니다. Owly가 기존 LeverAcc 거래 계정을 감지하므로 개인 키를 붙여넣거나 거래 계약 주소를 수동으로 입력할 필요가 없습니다.
2. 거래 계정이 필요하면 Owly에 내장된 LeverAcc 생성 화면을 이용합니다. 설정 과정에서 자금 지갑의 Arbitrum USDC와 가스비 잔액을 먼저 확인합니다. 표시된 최소 금액을 준비하고 계정 생성 및 활성화가 확인될 때까지 기다립니다.
3. 지원되는 경우 USDC를 ETH 또는 HYPE로 교환해 준비할 수 있습니다. 각각의 예산이 따로 적용되므로 교환 견적의 지출 금액과 토큰 사용 한도를 별도로 확인하세요. ETH를 준비해도 HYPE 요건은 따로 충족해야 합니다. 견적이 없으면 요청된 자산을 직접 준비한 뒤 잔액을 다시 확인합니다.
4. 자금 계정과 거래 계정 주소를 확인한 뒤 **Link project**(프로젝트 연결)로 진행합니다. 다른 프로젝트가 연결되어 있으면 **Link to Owly**(Owly 연결)를 선택하고 서명 요청과 계약 거래를 확인하세요. 미상환 부채나 변경을 막는 프로토콜 위험이 없어야 프로젝트를 변경할 수 있습니다. 변경하면 이전 실행 지갑이 비활성화됩니다.
5. 자금 지갑으로 실행 지갑 승인과 필수 빌더 수수료 승인을 완료합니다. Owly가 연결을 확인하고 계정 추가 완료를 표시할 때까지 기다리세요. 다른 작업을 시작하기 전에 대기 중인 작업을 재개하거나 상태를 확인하세요.
6. **계정**에서 LeverAcc 계정의 **Deposit**(입금), **Repay**(상환), **Withdraw**(출금) 또는 메뉴의 **Borrow**(차입), **Fund transfer**(자금 이체)를 선택하면 내장 LeverAcc 화면이 열립니다. 계정에 자금을 입금하고 승인을 마치면 해당 전략의 설정에서 계정을 선택하고 전략을 별도로 확인합니다.

전략이 중지된 동안에도 차입 이자가 발생할 수 있습니다. 봇을 중지하거나 포지션을 청산해도 대출금은 상환되지 않습니다. LeverAcc 화면에서 상환 및 출금 한도를 확인하세요. 알파 기능의 사용 가능 여부와 지원되는 거래 기능은 현재 화면에 표시된 상태를 따릅니다.

## 기존 Owly 관리 계정

기존 Owly 관리 계정 유형(`sub`)은 신규 생성, 입금, 내부 이체와 봇 시작·재시작·설정 갱신을 지원하지 않습니다. 기존 계정을 조회하거나 해당 봇을 중지 또는 종료하고 지원되는 방식으로 출금할 수 있습니다. 이 제한은 위에서 설명한 **Hyperliquid 하위 계좌** 유형(`hl_sub`)에는 **적용되지 않습니다**.

## 민감한 정보 보호

- 시드 문구, Owly 로그인 지갑의 개인 키, 거래용 마스터 지갑의 개인 키를 도우미나 지원팀 또는 제3자에게 보내지 마세요.
- 새 API 지갑 계정 또는 Hyperliquid 하위 계좌를 설정할 때 Owly가 API 거래 키를 만들고 보관합니다. 키를 직접 생성하거나 복사하거나 가져올 필요가 없습니다.
- 도우미는 계정 유형과 공개 주소를 바탕으로 이용 절차를 설명할 수 있습니다. 연결, 승인, 입금, 이체 및 거래 내역은 직접 확인하세요.
- API 지갑이 유출되면 악의적인 거래와 손실이 발생할 수 있습니다. 유출된 경우 관련 봇을 중지하고 Hyperliquid에서 승인을 철회하세요. 만료 또는 교체 시에는 Owly 계정 관리 화면의 갱신 안내를 따르세요.

[app.owly.fi/trade](https://app.owly.fi/trade)에서 **Trade**를 열어 시장 차트, 주문장, 최근 거래 및 계좌 정보를 확인하세요. 터미널에서 이용 가능한 영구 및 현물 시장 중에서 시장을 선택하세요.

## 어떤 계좌가 거래되고 있나요?

귀하의 거래 세션에서 거래 주소는 귀하의 **인증된 Owly 로그인 지갑**입니다. 단말기는 카피 트레이딩 계좌 선택기를 사용하지 않습니다. 카피 트레이딩 설정 대화 상자에서 별도의 계좌를 연결해도 단말기의 트레이딩 ID는 전환되지 않습니다.

Owly는 외부 지갑 연결을 위해 Privy을 사용합니다. 현재 로그인은 지갑을 지원합니다. 내장형 지갑을 생성하거나 이메일 또는 소셜 로그인을 제공하지 않습니다. 각 자금 조달 또는 거래 활동 전에 표시된 주소와 네트워크를 확인하세요.

## 거래 승인 설정

거래는 계정 활성화, 통합 계정 모드, 빌더 승인 및 API 지갑 연결을 확인합니다. **거래 설정**에 표시된 단계를 완료하고 각 지갑 요청을 검토하세요.

1. Hyperliquid에 지갑이 활성화되지 않은 경우 입금 절차를 완료하고 도착 확인을 기다립니다.
2. 요청 시 통합 계정 모드를 활성화합니다.
3. Builder 인증을 검토하고 완료합니다. 기존에 확인된 설정을 재사용할 수 있습니다. 페이지에서는 사용할 수 없거나 확인되지 않은 단계를 보고합니다.
4. 이 단말기에서 사용하는 API 지갑을 승인하세요. 인증이 만료되었거나 변경된 경우 설정에 표시된 복구 조치를 사용하세요.

승인 후 단말은 승인된 에이전트를 이용하여 추천인이 없는 계정에 대해 선택적인 Hyperliquid 추천 설정을 시도할 수 있습니다. 기존 리퍼러는 유지됩니다. 이 선택적 단계가 실패하더라도 거래 준비가 차단되지는 않습니다.

단말기는 나중에 방문할 수 있도록 승인된 API 거래 키를 이 기기의 브라우저에 저장합니다. 현재 Trade 인터페이스는 지속적인 로컬 연결이 필요하며 세션 전용 옵션을 노출하지 않습니다. 이 기기 저장소는 Owly에서 카피 트레이딩 계정을 위해 생성 및 관리하는 API 지갑과 별개입니다. 대체 승인을 위해서는 다른 브라우저나 장치에서 다시 승인이 필요할 수 있습니다.

<Warning>
트레이딩 터미널은 자신이 제어하는 ​​기기에서만 사용하세요. API 지갑은 거래 활동에 서명할 수 있으며 손상된 키로 인해 거래 손실이 발생할 수 있습니다. Owly, 어시스턴트 또는 지원 채팅에 기본 지갑 개인 키나 시드 문구를 입력하지 마십시오.
</Warning>

## Arbitrum에서 입금

통합 자금 흐름은 **Arbitrum One 메인넷**만 지원합니다. 선택한 지갑의 **USDC 또는 USDT를 Arbitrum**에서 사용한 다음 CCTP를 통해 해당 지갑의 Hyperliquid 계좌에 USDC를 입금합니다.

- USDT를 먼저 USDC로 바꿔야 합니다.
- USDC 자금이 가스용 ETH가 부족한 경우, 지원되는 견적과 필수 서비스가 제공될 때 흐름은 USDC에서 ETH로의 교환을 제공할 수 있습니다.
- 각 스왑과 입금을 별도로 검토합니다. 스왑이 완료되었다고 해서 Hyperliquid 보증금이 도착했다는 의미는 아닙니다.
- 에이전트 지갑, 볼트, 네이티브 서브 계정 주소는 이 흐름을 통해 소유 지갑으로 자금을 조달할 수 없습니다. 대신 계정별 프롬프트를 따르세요.

초기 소스-지갑 잔액 확인에는 활성화된 계정의 경우 선택한 토큰의 최소 **1 단위**, 활성화되지 않은 주소의 경우 **2 단위**가 필요합니다. 이는 잔고 확인이며, 허용되는 최소 입금액이 보장되지 않습니다. 최종 입금액은 **현재 CCTP 수수료에 계좌 개설 수수료**를 더한 금액을 초과해야 합니다. 스왑과 가스에도 충분한 자금이 필요합니다. 서명하기 전에 표시된 수수료 견적과 예상 영수증을 사용하세요.

API 월렛 카피 트레이딩 계좌를 생성하는 동안에도 동일한 자금 구성 요소가 나타날 수 있습니다. 해당 설정에서는 대화상자**에서 명시적으로 선택한 **거래 지갑에 자금을 지원하며 이는 로그인 지갑과 다를 수 있습니다. [빠른 시작](/ko/guide/quick-start)을 참조하세요.

## Arbitrum로 출금

거래 출금은 **USDC을 Arbitrum One**에 연결된 동일한 지갑 주소로 보냅니다. 이 양식은 임의의 수신자 필드를 제공하지 않습니다.

지갑은 통합 계정 모드에서 활성화된 Hyperliquid 사용자여야 합니다. 요청 금액은 다음과 같아야 합니다.

- 는 **가 0.2 USDC**보다 큽니다.
- 현재 프로토콜 출금 수수료를 초과합니다.
- 필요한 인출 가스 비축량 이후 현재 사용 가능한 금액에 맞습니다.

실제 최소 출금 금액은 현재 수수료와 계정 상태에 따라 달라집니다. 수수료와 예상 수령액을 확인하세요. 시스템은 트랜잭션과 받는 지갑의 입금을 확인한 뒤 출금 완료를 표시합니다. 출금이 대기 중이거나 결과가 불확실하면 같은 지갑으로 기존 출금 요청의 상태를 확인하세요. 결과를 확인할 때까지 출금 요청을 다시 제출하지 마세요. 완료를 확인하면 터미널의 **이체** 기록 탭으로 돌아갑니다.

## 주문 및 계정 내역

단말기는 Market, Limit, TWAP 주문입력 기능을 제공합니다. 주문 메뉴의 그리드 선택은 현재 제출이 비활성화된 미리보기입니다. 별도의 그리드 봇은 [Trading Bots → Grid Trading](/ko/guide/grid-bot)을 사용하세요.

시장, 방향, 가격 또는 기간, 규모, 사용 가능한 위험 설정을 선택한 후 확인을 검토하세요. 시장별 정밀도, 마진, 최소 주문 및 현재 시장 데이터는 조치를 차단할 수 있습니다. 계정 패널에는 잔액, 포지션, 미결 주문, TWAP, 거래 내역, 자금 조달 내역, 주문 내역 및 전송이 포함됩니다. 시장을 선택한다고 해서 모든 계정 내역 행이 해당 시장에 속한다는 의미는 아닙니다. 작업 가용성은 별도로 확인됩니다.

## 고스트 모드로 다른 주소 검사

트레이더 상세 페이지에서 주소 링크를 이용해 해당 공개계좌의 단말기를 엽니다. URL의 모양은 다음과 같습니다.

```text
https://app.owly.fi/trade?ghost=0x1111111111111111111111111111111111111111
```

예시를 유효한 42 문자 EVM 주소로 바꾸세요. 고스트 모드는 **읽기 전용**입니다. 시장과 해당 주소의 사용 가능한 공개 잔액, 포지션, 주문 및 내역을 탐색할 수 있습니다. 해당 주소에 대한 거래, 취소, 입금 또는 출금은 불가능합니다. 카피 트레이딩 작업을 통해 트레이더의 카피 트레이딩 흐름이 시작되며, 여기서 자신의 계좌를 선택하고 별도로 확인해야 합니다.

자신의 단말기로 돌아가려면 고스트 종료 제어를 사용하세요. 유효하지 않은 Ghost 주소는 다른 계정으로 전환하는 대신 오류를 표시합니다.

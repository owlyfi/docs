Owly는 지갑 서명과 인증된 거래 키를 통해 거래 계좌를 연결합니다. 펀드 소유권과 거래 키 보관은 다릅니다. 소유 지갑을 통제하는 반면 승인된 API 지갑은 거래를 실행하고 손실을 입을 수 있습니다.

## 계정 및 주요 역할

| 역할 | 현재 동작 |
| --- | --- |
| **Owly 로그인 지갑** | 로그인하고 계정을 관리합니다. 거래 소유자가 될 수도 있습니다. |
| **거래 소유자/마스터 지갑** | 자금이 조달된 계좌를 보유 또는 통제하고 소유자가 요구하는 승인 및 인출에 서명합니다. |
| **카피 트레이딩 API 지갑** | 설정 중에 Owly에 의해 생성 및 저장됩니다. 승인된 전략 조치에 서명하는 데 사용됩니다. |
| **거래 단말기 API 지갑** | 현재 Trade 인터페이스에 의해 이 기기의 브라우저에 영구적으로 저장됩니다. |
| **LeverAcc 실행 지갑** | 프로토콜의 프로젝트 바인딩을 통해 승인됩니다. 담보 및 부채는 LeverAcc의 규칙을 따릅니다. |

세 가지 현재 설정 경로는 [계정 유형](/ko/guide/account-types)을 참조하세요. API 지갑 경로에는 기본 Hyperliquid 하위 계정을 생성할 필요가 없습니다.

## 승인이 허용하는 것

API 지갑은 포지션 개시 및 청산을 포함하여 지원되는 거래 활동에 서명할 수 있습니다. 이는 소유 지갑의 외부 출금 서명을 대체하지 않습니다. 이는 에이전트에 프로토콜 내부 자금 권한이 없다는 의미는 아닙니다.

서명하기 전에 연결된 소유자 주소, API 지갑 주소, 만료, 빌더 수수료 한도 및 모든 계약 거래를 검토하세요. 예금과 스왑에는 별도의 토큰 승인이 필요할 수 있습니다. 토큰 승인 한도는 제시된 스왑 지출 한도와 다릅니다.

<Warning>
유출된 거래 API 키는 악의적인 거래와 손실을 초래할 수 있습니다. 비수탁형 펀드 소유권은 시장 손실, 청산, 악의적인 거래 또는 프로토콜 실패로부터 보호하지 않습니다.
</Warning>

## 접근권한 보호 및 철회

- 어시스턴트, 지원 또는 채팅에 시드 문구, 지갑 소유 개인 키 또는 거래 API 키를 보내지 마십시오.
- 거래 승인을 위해서는 신뢰할 수 있는 기기를 사용하세요. 브라우저 저장소를 지우면 로컬에 저장된 거래 자격 증명 및 보류 중인 작업 복구가 제거될 수 있습니다. Hyperliquid 승인은 취소되지 않습니다.
- 영향을 받은 봇을 중지하고 나머지 위치와 주문을 검사합니다. API 지갑을 취소하려면 [Hyperliquid의 API 페이지](https://app.hyperliquid.xyz/API)에서 소유하고 있는 마스터 지갑을 사용하세요.
- 다시 시작하기 전에 해당 Owly 인증을 업데이트하세요. LeverAcc 전용 실행 지갑 업데이트 흐름을 사용합니다.
- Owly 펀드매니저를 삭제하면 관리 액세스 권한도 삭제됩니다. 자동으로 봇 실행을 중지하거나 프로토콜 인증을 취소하지 않습니다.

자금 조달 진입점과 소유자 서명에 대해서는 [자산 관리](/ko/guide/asset-management)를 읽어보세요. 위임 범위는 [자산 소유자용](/ko/guide/owner-guide)을 읽어보세요.

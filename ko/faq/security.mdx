## 지갑 및 거래 키 보안

소유 지갑을 통제할 수 있습니다. Owly는 자동화된 전략에 사용되는 API 키를 생성하고 저장합니다. 현재 Trade 터미널은 API 거래 승인을 이 기기의 브라우저에 지속적으로 저장합니다. 개인 키나 시드 문구를 어시스턴트나 지원팀에 보내지 마세요. [비구속 보안](/ko/advantages/non-custodial)을 참조하세요.

API 지갑은 소유자의 외부 출금 서명을 대체할 수 없지만 자금 손실이 발생하는 거래를 실행할 수 있습니다. 서명자와 권한 범위를 확인하고, 소유한 지갑을 통해 손상된 권한을 취소합니다. 봇 중지, 관리자 제거, API 지갑 취소는 별도의 작업입니다.

## 거래 위험

| 위험 | 의미 |
| --- | --- |
| **시장 및 활용** | 가격 변동, 자금 조달 비용 및 청산으로 인해 계정 자산이 감소하거나 소진될 수 있습니다. |
| **복사 실행** | 지연 시간, 유동성, 최소 주문 규모, 시장 필터 및 사용 가능한 담보에 따라 소스에서 다양한 채우기 또는 위치가 생성될 수 있습니다. |
| **위험 기준** | SL/TP 설정을 구성해야 합니다. 모니터링 및 청산 주문은 임계값 이후 더 나쁜 가격으로 실패하거나 실행될 수 있습니다. |
| **그리드 노출** | 방향성 그리드는 노출을 누적할 수 있으며 가격은 구성된 범위를 벗어날 수 있습니다. |
| **데이터 제한** | 반환 및 재생은 사용 가능한 기록, 계정 범위 및 데이터 최신성에 따라 다릅니다. |

과거의 결과가 미래의 성과를 보장하지 않습니다. 순위 점수, 시뮬레이션 또는 읽기 전용 Ghost 보기는 전략이 적합하거나 성공적으로 복사된다는 것을 보장하지 않습니다.

## 자금 및 프로토콜 위험

- 서명하기 전에 경로의 네트워크와 토큰을 확인하세요. 통합된 거래 자금 입출금 절차은 Arbitrum One 메인넷을 지원합니다. LeverAcc도 HyperEVM을 사용합니다.
- 가스, 스왑, 브리지/CCTP, 활성화, 프로토콜 요금을 별도로 검토하세요.
- 보류 중인 제출이 불확실할 수 있습니다. 반복하기 전에 기존 작업을 확인하십시오.
- 스마트 계약, 브리지, 거래소, 지갑 소프트웨어 및 업스트림 공급자가 실패할 수 있습니다. 코드 가용성만으로는 보안 감사의 증거가 아닙니다.
- LeverAcc 담보 및 차입은 이자와 청산 위험을 초래합니다. 거래를 중단하거나 포지션을 닫는 것은 부채를 상환하지 않습니다.

## 사고 관리

1. 영향을 받는 자동화를 중지하고 위치 및 미결제 주문을 검사합니다.
2. 해당 거래 승인을 취소하거나 소유 지갑으로 대체합니다. LeverAcc의 경우 실행-지갑 업데이트 흐름을 따르세요.
3. 추가 전송을 하기 전에 보류 중인 자금 작업 및 거래 해시를 확인하세요.
4. [Telegram 지원](https://t.me/owlyfi_support) 또는 [security@owly.fi](mailto:security@owly.fi)에 연락하여 공개 주소, 문제 발생 시간, 수정된 증거를 알려주세요. 공개 채팅에 비밀이나 취약점을 공개하지 마세요.

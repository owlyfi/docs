## 지갑 및 설정

| 증상 | 확인사항 |
| --- | --- |
| 지갑을 연결할 수 없습니다 | 지갑을 잠금 해제하고 사이트 권한 및 경쟁 확장 프로그램을 확인한 후 원하는 주소로 다시 시도하세요. |
| 잘못된 지갑 서명 | Owly 로그인, 거래 소유자, 자금 주소를 비교하세요. 그들은 다를 수 있습니다; 현재 단계에서 요청한 지갑으로 돌아갑니다. |
| API 지갑 설정에서 자금 요청 | Hyperliquid에서는 소유 주소가 아직 활성화되지 않았습니다. 통합계좌 및 API 인증 전 내장입금을 완료하고 활성화를 기다립니다. |
| 주소가 소유자로 거부됨 | 에이전트, 볼트, 기본 하위 계정 주소가 아닌 소유한 Hyperliquid 사용자 지갑을 사용하세요. |
| 기본 하위 계정을 사용할 수 없습니다. | 로그인된 마스터를 확인하고, 목록을 새로고침한 후, 자격 및 용량 확인이 통과된 경우에만 생성 옵션을 사용하세요. |
| 계정 한도 도달 | 지원되는 세 가지 유형 모두 10 활성 Owly 거래 계좌 한도를 공유합니다. |
| API 지갑 승인 실패 | 만료 및 사용 가능한 Hyperliquid API 지갑 슬롯을 검토한 다음 올바른 마스터로 보류 중인 승인을 완료하세요. |

만료된 Owly 로그인 세션과 만료된 Hyperliquid 거래 승인은 다른 문제입니다. 전자에 다시 연결하고 로그인하세요. 후자에 대한 계정의 거래 승인을 업데이트합니다.

## 예금, 스왑, 출금

- **올바른 진입점을 사용하세요.** 로그인한 소유 지갑에 자금을 거래하세요. 계정은 API 지갑 및 기본 하위 계정 사용자를 Hyperliquid에 연결합니다. LeverAcc 버튼을 누르면 내장된 인터페이스가 열립니다. [자산 관리](/ko/guide/asset-management)를 참조하세요.
- **잘못된 네트워크 또는 자산:** 통합 거래 흐름은 Arbitrum One 메인넷과 예금 USDC를 사용하며 선택적으로 USDT-to-USDC 준비가 가능합니다. LeverAcc HYPE는 HyperEVM에 속합니다. 거래의 실제 네트워크와 토큰을 확인하세요.
- **스왑 불가:** 가스리스 스왑은 공급자 구성, 지원되는 승인 방법, 잔액 및 새로운 견적에 따라 달라집니다. 지원되는 견적이 제공되지 않는 경우 필요한 자산을 직접 준비하세요.
- **ETH가 준비되었지만 여전히 HYPE가 누락되었습니다.** LeverAcc가 독립적으로 확인합니다. 남은 준비를 완료하고 잔액을 다시 확인하세요.
- **보류 중이거나 알 수 없는 제출:** 원래 작업을 재개하고 상태를 확인합니다. 메시지가 표시되면 소스 트랜잭션 해시를 사용합니다. 결과가 알려질 때까지 다른 거래를 보내지 마십시오.
- **출금 거부됨:** 보유 지갑 ID, 통합 계정 모드, 출금 가능 잔액, 실시간 수수료를 확인하세요. 거래 금액은 0.2 USDC 및 해당 수수료를 모두 초과해야 합니다.
- **입금이 표시되지 않음:** 입금된 계좌 주소, 원본 거래 및 대상 잔액을 비교하세요. 성공적인 지갑 제출은 Hyperliquid에서의 신용을 증명하지 않습니다.

## 전략 및 계정 액세스

| 증상 | 확인사항 |
| --- | --- |
| 기존 관리 계정에서는 봇을 시작할 수 없습니다. | 이 계정 유형은 시작/다시 시작/구성 업데이트를 위해 사용 중지됩니다. 나머지 자동화를 중지하거나 종료하고 지원되는 철수 경로를 사용하십시오. |
| LeverAcc 복사를 시작할 수 없습니다. | 프로젝트 바인딩, 실행-지갑 승인, 자금 조달 및 현재 가용성을 확인합니다. 지정가 주문 복사는 지원되지 않습니다. |
| LeverAcc 그리드에서 누락됨 | 현재 Grid Bot 계정 선택기는 LeverAcc 계정을 제외합니다. |
| 거래가 복사되지 않았습니다. | 봇 상태, 승인 유효성, 사용 가능한 담보, 활성화된 시장, 코인 필터, 최소 크기 및 소스 활동을 확인하세요. |
| 다양한 포지션 규모 또는 진입 가격 | 복사 비율, 시장 움직임, 반올림, 구성된 필터 및 마진 가용성은 실행을 변경할 수 있습니다. |
| 관리자가 제거되었지만 봇은 계속 실행 중입니다. | 관리 액세스 권한을 제거해도 봇은 중지되지 않습니다. 소유자는 별도로 봇을 중지하거나 종료해야 합니다. |
| 그리드 후행 컨트롤이 비활성화되었습니다. | 현재 사용자 인터페이스에서는 후행을 사용할 수 없습니다. 저장된 백엔드 필드는 여기서 활성화하지 마세요 |

SL/TP 임계값은 자동으로 채워지는 보호 기본값이 아닙니다. 저장된 설정과 [Risk Management](/ko/advantages/risk-management)를 확인하세요.

## 잔액 및 차트

동일한 거래계좌 주소와 기간을 비교해보세요. 계좌 금액은 인출 가능한 잔액이 아닙니다. ROI는 평가범위나 현금흐름 내역을 확정할 수 없는 경우에는 이용이 불가능할 수 있습니다. 0으로 읽어서는 안 됩니다. 새로고침하여 [Portfolio & Navigation](/ko/guide/dashboard)에서 측정항목 정의를 확인하세요.

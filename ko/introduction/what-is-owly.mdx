## 개요

**Owly**는 [Hyperliquid](https://hyperliquid.xyz)에서 트레이더 탐색, 카피 트레이딩, 거래 터미널, 자동화 전략을 제공합니다. 계정 관리에서 거래 지갑이나 지원되는 프로토콜 계정을 연결하세요. 사용 가능한 기능과 이용 절차는 웹사이트의 도우미에게 물어볼 수 있습니다.

## Owly의 목표

Owly는 누구나 전문적인 거래 전략을 이용할 수 있어야 한다고 생각합니다. 다음 기능을 통해 거래 전략을 더 쉽게 이용할 수 있습니다.

<Steps>
  <Step title="탐색">
    플랫폼에서 검증된 트레이더의 성과 데이터를 찾아 분석할 수 있습니다.
  </Step>
  <Step title="연결">
    API 지갑 계정, Hyperliquid 하위 계좌 또는 LeverAcc 계정을 추가하고 필요한 권한을 승인할 수 있습니다.
  </Step>
  <Step title="모니터링">
    봇 상태, 체결 내역, 포지션, 수익률을 확인할 수 있습니다. 위험 설정을 검토하고 필요할 때 전략을 중지하세요.
  </Step>
</Steps>

## 주요 기능

| 기능 | 지원 범위 |
| --- | --- |
| **트레이더 탐색** | 성과 및 위험 지표로 트레이더 탐색 |
| **카피 트레이딩** | 계정별 전략 설정, 시장 필터, 포트폴리오 위험 임계값 설정 |
| **거래 터미널** | 수동 거래, 통합 입금, 읽기 전용 Ghost 모드 |
| **그리드 봇** | 거래 봇 페이지에서 무기한 계약의 중립, 롱, 숏 그리드 설정 |
| **계정** | 생성된 API 지갑 승인, Hyperliquid 하위 계좌 설정, LeverAcc(알파) |
| **포트폴리오** | 계정 가치, 손익, 현금 흐름을 반영한 수익률, 작업 내역 |

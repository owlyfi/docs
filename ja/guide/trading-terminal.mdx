[app.owly.fi/trade](https://app.owly.fi/trade) で**Trade** を開き、市場チャート、オーダーブック、最近の取引、口座情報を表示します。ターミナルで利用可能な永久市場とスポット市場から市場を選択します。

## どのアカウントで取引されていますか?

あなた自身の取引セッションでは、取引アドレスはあなたの**認証済みOwlyログインウォレット**です。端末はコピー取引アカウントセレクターを使用しません。コピー取引設定ダイアログで別のアカウントを接続しても、端末の取引 ID は切り替わりません。

Owly は、外部ウォレット接続に Privy を使用します。現在のログインはウォレットをサポートしています。埋め込みウォレットを作成したり、電子メールやソーシャル ログインを提供したりすることはありません。資金調達や取引を行う前に、表示されているアドレスとネットワークを確認してください。

## 取引承認の設定

取引は、アカウントのアクティブ化、統合アカウント モード、ビルダーの承認、およびその API ウォレット接続をチェックします。 **取引設定**に示されている手順を完了し、各ウォレットリクエストを確認します。

1. Hyperliquid にウォレットがアクティブ化されていない場合は、入金フローを完了し、到着が確認されるまで待ちます。
2. 要求されたら、統合アカウント モードを有効にします。
3. Builder の承認を確認して完了します。既存の確認済み設定は再利用できます。このページでは、利用できないステップまたは未確認のステップが報告されます。
4. この端末で使用するAPI ウォレットを認証します。認証の有効期限が切れているか変更されている場合は、設定に表示されている回復アクションを使用してください。

承認後、端末は承認されたエージェントを使用して、紹介者なしでアカウントのオプションの Hyperliquid 紹介セットアップを試みることができます。既存のリファラーは保持されます。このオプションのステップを失敗しても、取引の準備が妨げられることはありません。

端末は、後でアクセスできるように、承認された API 取引キーをこのデバイスのブラウザに保存します。現在の Trade インターフェイスでは永続的なローカル接続が必要であり、セッションのみのオプションは公開されていません。このデバイスのストレージは、コピー取引アカウント用に Owly によって生成および管理される API ウォレットとは別のものです。認証を置き換えると、他のブラウザまたはデバイスの再認証が必要になる場合があります。

<Warning>
取引ターミナルは、あなたが管理するデバイス上でのみ使用してください。 API ウォレットは取引アクションに署名する可能性があり、侵害されたキーにより取引損失が発生する可能性があります。メインウォレットの秘密キーやシードフレーズをOwly、アシスタント、またはサポートチャットに入力しないでください。
</Warning>

## Arbitrum からの入金

統合された資金フローは、**Arbitrum One メインネットのみ** をサポートします。選択したウォレットの **USDC または USDT を Arbitrum** で使用し、CCTP を通じてそのウォレットの Hyperliquid アカウントに USDC を入金します。

- USDT をまず USDC と交換する必要があります。
- USDC 資金にガス用の十分な ETH が不足している場合、サポートされている相場と必要なサービスが利用可能な場合、フローは USDC から ETH へのスワップを提供できます。
- 各スワップと入金を個別に確認します。スワップが完了しても、Hyperliquid デポジットが到着したことを意味するものではありません。
- エージェント ウォレット、ボールト、およびネイティブ サブアカウント アドレスには、このフローを通じてウォレットを所有するものとして資金を提供することはできません。代わりに、アカウント固有のプロンプトに従ってください。

最初のソースウォレット残高チェックには、少なくとも**1単位の選択されたトークン**（アクティブ化されたアカウントの場合）または**2ユニット**（アクティブ化されていないアドレスの場合）が必要です。これらは残高チェックであり、保証された最低入金額を保証するものではありません。最終入金額は、**現在のCCTP手数料とアカウント有効化手数料**を超える必要があります。スワップやガスにも十分な資金が必要です。署名する前に表示される料金見積書と領収書の見積額を使用してください。

API ウォレットのコピー取引アカウントの作成中に、同じ資金調達コンポーネントが表示されることがあります。その設定では、ダイアログ**で明示的に選択された**取引ウォレットに資金が供給されますが、これはログインウォレットとは異なる場合があります。 [クイックスタート](/ja/guide/quick-start)を参照してください。

## Arbitrum に撤退

取引の出金は、**USDC をArbitrum One** の同じ接続されたウォレットアドレスに送信します。このフォームには任意の受信者フィールドはありません。

ウォレットは、統合アカウント モードでアクティブ化された Hyperliquid ユーザーである必要があります。要求された金額は次のとおりである必要があります。

- **が 0.2 USDC** より大きくなる。
- は現在のプロトコルの引き出し手数料を超えます。
- は、必要な回収ガス予備量を考慮した上で、現在利用可能な量の範囲内に収まります。

実際の最低出金額は、その時点の手数料とアカウントの状態によって異なります。手数料と受取予定額を確認してください。システムはトランザクションと受取先への着金を確認してから、出金完了を表示します。出金が保留中、または結果が不明な場合は、同じウォレットで元の出金リクエストの状態を確認してください。結果が分かるまでは出金リクエストを再送信しないでください。完了を確認して端末の**転送**履歴タブに戻ります。

## 注文とアカウント履歴

この端末は、成行注文、指値注文、および TWAP 注文エントリーを提供します。注文メニューのグリッドの選択は現在プレビューであり、送信は無効になっています。別のグリッド ボットには、[Trading Bots → Grid Trading](/ja/guide/grid-bot) を使用します。

市場、方向、価格または期間、サイズ、および利用可能なリスク設定を選択し、確認を確認します。市場固有の精度、マージン、最小注文数、および現在の市場データにより、アクションがブロックされる可能性があります。口座パネルには、残高、ポジション、オープン注文、TWAP、取引履歴、資金調達履歴、注文履歴、送金が含まれます。マーケットを選択しても、すべてのアカウント履歴行がそのマーケットに属するわけではありません。アクションの可用性は個別にチェックされます。

## ゴーストモードで別のアドレスを検査する

トレーダーの詳細ページから、アドレスリンクを使用してその公開口座のターミナルを開きます。 URL は次のような形になります。

```text
https://app.owly.fi/trade?ghost=0x1111111111111111111111111111111111111111
```

この例を有効な 42 文字の EVM アドレスに置き換えます。ゴースト モードは**読み取り専用**: マーケットとアドレスの利用可能な公開残高、ポジション、注文、履歴を閲覧できます。そのアドレスでは取引、キャンセル、入金、または出金ができません。コピー取引アクションにより、トレーダーのコピー取引フローが開きます。ここでは、自分の口座を選択して個別に確認する必要があります。

Ghost 終了コントロールを使用して、自分の端末に戻ります。 Ghost アドレスが無効な場合は、別のアカウントに切り替える代わりにエラーが表示されます。

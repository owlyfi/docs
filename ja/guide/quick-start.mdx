このガイドでは、**API ウォレット**タイプを使って、Owly にコピートレード用のアカウントを作成します。OKX Web3 ブラウザーウォレットなど、対応する EVM ウォレットを用意してください。**アカウント設定画面から入金できます。事前に Hyperliquid で登録や入金を済ませたり、API ウォレットを手動で作成したりする必要はありません。**

```text
ログイン → サブアカウント作成 → API ウォレットを選択 → アカウント名を入力して取引ウォレットを接続
  → 未有効化なら設定画面で入金 → 着金確認を待つ → アカウント詳細に戻る
  → 必要に応じて統一アカウントを有効化 → API ウォレットを生成して承認 → アカウントを作成 → コピートレードを開始
```

## 取引ウォレットを選ぶ

| ウォレット | 用途 |
| --- | --- |
| **Owly ログイン用ウォレット** | ログイン、アカウントの追加、コピートレードの管理に使います |
| **取引ウォレット** | 入金に使う資産を保有し、Hyperliquid で入金を受け取り、承認に署名します。ログイン用ウォレットと同じものも別のものも使えます |
| **API ウォレット** | アカウントの有効化後に Owly が生成する取引署名用のウォレットです。入金先には使いません |

初めてアカウントを作成する場合は、ログインに使ったウォレットを取引にも使えます。別のアドレスを使う場合は、**設定画面に表示された取引ウォレット**で入金と承認を行ってください。

<Warning>
API ウォレットのアドレスには資金を送らないでください。アカウント設定でシードフレーズ、資金を保有するウォレットの秘密鍵、API ウォレットの秘密鍵の入力を求められることはありません。
</Warning>

## ステップ 1：Owly にログインする

1. [Owly のアカウント管理](https://app.owly.fi/accounts)を開きます。
2. ウォレットを接続し、アドレスを確認してログイン用メッセージに署名します。
3. 初回は利用規約とプライバシーポリシーを読み、画面の案内に沿って初期設定を完了します。

ログインの初期設定とコピートレード用アカウントの作成は別の手続きです。ログインしても、コピートレード用アカウントの作成や、別の取引ウォレットへの入金は自動で行われません。

## ステップ 2：API ウォレットのアカウントを追加する

1. **アカウント**画面で **サブアカウント作成** をクリックします。
2. アカウント種別の選択画面（**会計タイプを選択**）で API ウォレット（**API 財布**）を選び、**次のステップ** をクリックします。
3. API ウォレットの設定画面（**セットアップ API 財布**）でアカウント名（**会計名**）を入力します。
4. **Connect** をクリックし、実際に取引に使うウォレットを選びます。表示されたアドレスを確認し、必要に応じて **Switch** で切り替えます。

<Note>
トレーダー詳細のコピートレード画面（**コピー貿易**）からも、アカウントのドロップダウンで **新しいサブアカウントを作成する** を選ぶと、アカウント画面で同じ作成手順を開始できます。
</Note>

Owly は、接続したアドレスが資金を保有する Hyperliquid ユーザーのウォレットかどうかを確認します。**未有効化のアドレスは、以下の入金手続きに自動で進みます。** すでに有効な取引ウォレットは、有効化手数料を再度支払わずにステップ 5 に進めます。このアカウントタイプでは、エージェント、ネイティブサブアカウント、Vault のアドレスを資金を保有するウォレットとして使用できません。

## ステップ 3：設定画面で入金用の資金を準備する

入金画面で使うのは、**ステップ 2 で接続した取引ウォレット**です。Owly ログイン用ウォレットと異なる場合も、対象は変わりません。

1. **Deposit** 画面の **Asset** で **USDC** または **USDT** を選び、**Next** をクリックします。
2. ネットワークが **Arbitrum One メインネット**になっていることを確認します。この入金手続きでは、取引ウォレットに対応する Hyperliquid アカウントに USDC が入金されます。
3. 送金元のウォレットに資金が足りない場合は、画面に表示されたアドレスに、表示された最低額以上の資産を用意します。送金前にネットワークを確認してください。残高は自動で確認されます。
4. 残高が画面の条件を満たしたら、Owly で同じ手続きを続けます。

| 画面に表示された状況 | 対処方法 |
| --- | --- |
| **USDC と ETH が十分にある** | 入金額と手数料の確認に進みます |
| **USDT を選択した** | 見積もりを確認し、USDT を USDC に交換します。交換が確認された後で ETH が不足していれば用意し、入金に進みます |
| **USDC は十分だが ETH が不足している** | 機能が有効で利用できる見積もりがあれば、案内に沿って USDC を ETH に交換します。Arbitrum 上の ETH を自分で用意し、再確認することもできます |
| **利用可能な交換の見積もりがない** | 指定された USDC または ETH を自分で用意し、同じ画面で再確認します |

交換には自分の資産を使います。USDT を USDC に交換するときは USDT を、手数料支払い用の ETH を準備するときは USDC を支払います。手数料支払い用の資産が無償で提供されるわけではありません。**交換は一件ずつ内容を確認して承認してください。交換が完了しても、Hyperliquid への入金は別途確認が必要です。**

## ステップ 4：入金を確認し、有効化を待つ

1. 入金額を入力します。取引ウォレット、ネットワーク、見積もり手数料（**Quoted fees**）、着金予定額（**Estimated received**）を確認します。
2. Hyperliquid のアドレスを初めて有効化する際は、入金経路に応じた CCTP、ネットワーク、交換の手数料に加えて **1 USDC の有効化手数料**がかかります。画面に表示される金額条件を満たし、準備に必要な資金も残してください。
3. 画面の指示に従い、**Confirm this step**、**Confirm Swap**、または **Confirm Deposit** を選択します。ウォレットに表示されるトークンの利用許可額と取引内容を確認して署名してください。完了済みの操作はスキップされます。
4. 送金元の取引、Hyperliquid への実際の着金、アカウントの有効化がすべて確認されるまで待ちます。ウォレットで送信済みになっても、この画面を閉じたり、再度入金したりしないでください。
5. 確認が済むと API ウォレットの設定画面に戻り、取引ウォレットが再確認されます。名前とアドレスを確認し、**次のステップ** をクリックします。

<Note>
送金元ウォレットで必要な残高と、最終的な最低入金額は異なります。固定額を一律の最低額とみなさず、画面に表示される最新の手数料、利用可能残高、着金予定額を確認してください。
</Note>

### 処理が保留中、または途中で中断した場合

同じ取引ウォレットとネットワークで戻り、進行中の操作を再開してください。**Check status** で状態を確認できます。すでに送信した取引を確認するよう求められた場合は、**Find transaction** を使います。結果が不明な間は再送信しないでください。再開できるよう、ブラウザーに保存されたデータを削除しないでください。送信前に見積もりの有効期限が切れた場合は、新しい見積もりを取得して内容を確認してください。

## ステップ 5：統一アカウントを有効化し、API ウォレットを生成する

API ウォレットの設定画面でアカウント名と取引アドレスを確認し、**次のステップ** をクリックします。有効化を確認した後、Owly が **統一アカウント（Unified Account）** モードを確認します。未設定の場合は、取引ウォレットで有効化に署名して確認を待ちます。確認済みの場合はスキップされます。

次に、Owly がこのコピートレード用アカウント専用の API ウォレットを生成して保存し、**Approve API Wallet** 画面を開きます。Hyperliquid での手動作成や、秘密鍵のコピー、インポートは不要です。

## ステップ 6：承認してアカウントを作成する

1. 生成された **API ウォレットの公開アドレス**と、入金済みの**取引ウォレットのアドレス**を確認します。
2. **Authorize & Create** をクリックします。まず取引ウォレットで API ウォレットの承認に署名し、Owly による確認を待ちます。
3. **Builder 手数料の承認**が必要な場合は、上限を確認してから承認します。通常の上限は **0.1%** です。これは許可する最大料率であり、実際の手数料率は取引によって異なります。[手数料体系](/ja/faq/fees)を参照してください。
4. 設定中に、任意の Hyperliquid 紹介設定が試行される場合があります。すでに紹介者が登録されていれば維持されます。画面の案内に従ってください。確認済みの承認を繰り返す必要はありません。
5. アカウントが作成されるまで待ち、完了画面に選択した**取引アカウントのアドレス**が表示されていることを確認して、**OK** をクリックします。

署名を取り消した場合や承認が未確認の場合は、正しい取引ウォレットを接続したまま、現在のステップから続けてください。入金、API ウォレットの承認、アカウントの作成、戦略の開始はそれぞれ別の処理です。

## ステップ 7：アカウントを選んでコピートレードを開始する

1. フォローしたいトレーダーの詳細ページに戻り、コピートレード画面（**コピー貿易**）を開きます。
2. アカウント一覧から、作成したアカウントを選びます。
3. コピー元のトレーダー、取引アカウント、コピー比率、決済ルール（**出力ルール**）などの設定を確認し、確定します。損切りと利確（SL/TP）の閾値は初期状態では未設定です。保存した設定を確認してください。
4. 開始に成功すると、Owly は **ポートフォリオ**で該当するアカウントカードを開きます。ボットの稼働状況、実際の注文、ポジションを確認してください。アカウントを作成しただけでは取引は始まりません。

## よくある質問

### 有効化済みの取引ウォレットにも入金が必要ですか？

再度有効化する必要はありません。ウォレットの確認が済んだら承認に進んでください。後から資金を追加する場合は、[資産管理](/ja/guide/asset-management)でアカウント種別に応じた入金方法を確認してください。

### ウォレットに USDC があるのに、なぜ入金が必要ですか？

Arbitrum 上のウォレットにある USDC と、Hyperliquid で取引に使える残高は別です。設定画面での入金は、選択したウォレットの資産をその Hyperliquid アカウントに移し、着金を確認します。

### 別のウォレットで Owly にログインしたときは、どのアドレスに資産を用意しますか？

API ウォレットの設定画面と入金画面に表示される取引ウォレットのアドレスに、Arbitrum 上の資産を用意してください。ログイン用アドレスにだけ資金を送っても、別の取引アカウントには入金されません。生成された API ウォレットには送金しないでください。

### 残高や入金の進捗が更新されない場合はどうすればよいですか？

当初の取引アドレス、Arbitrum One ネットワーク、選択した資産、送金元の取引を確認し、現在の画面でステータス確認や更新を行ってください。入金を繰り返さないでください。サポートに連絡する場合は、公開アドレス、問題が発生した時刻、トランザクションハッシュのみを共有してください。

## アカウントの種類

A Hyperliquid **API Wallet** は、新規に資金提供されたマスターアカウントではなく、認可された署名代理人です。 Owly は 3 つの取引口座タイプをサポートしています:

- **API Wallet**: 認定エージェントを通じて Hyperliquid マスター/EVM アドレスに接続します。資金はその取引アドレスに留まります。
- **Hyperliquid サブアカウント**: ネイティブのサブアカウントに接続します。マスターウォレットがHyperliquidの要件を満たしている場合は、既存のサブアカウントを選択するか、サポートされているオンボーディングフローでサブアカウントを作成できます。
- **オンチェーン融資 (アルファ)**: 担保付きUSDC 借入を使用する LeverAcc アカウントを接続します。アカウントをリンクしても取引は開始されません。その後、コピー取引用に設定できます。現在の Grid アカウント セレクターでは、このタイプは除外されます。

Owly メインアカウントがログインと管理を処理します。取引口座は、その戦略で使用される資本を保持またはアクセスします。これらの役割は、同じアドレスを使用することも、異なるアドレスを使用することもできます。独立したアドレスを追加しても、ログインウォレットから資金が自動的に移動されるわけではありません。

Owly は、最初の 2 つのアカウント タイプに使用される API ウォレット署名エージェントを生成および保存します。認可は取引ウォレットまたはネイティブのサブアカウントのマスターウォレットから行われます。 3 つのアカウント タイプはすべて、Owly メイン アカウント** ごとに、**10 のアクティブな取引アカウントの制限を共有しています。 Hyperliquid 自身のネイティブ サブアカウントの資格と割り当ては別のものです。

前提条件とセキュリティ境界については、[アカウント タイプ](/ja/guide/account-types) を読むか、[クイック スタート](/ja/guide/quick-start) に従ってください。

## 主要指標

同じ時間枠とアカウント範囲にわたるメトリクスを比較します。永久取引で表示される価値は、必ずしもアカウントが保有するすべての資産の収益を示すものではありません。

### ROI そして戻る

入出金は資本の移動であり、取引利益ではありません。したがって、口座価値を初期残高で割った単純な変更により、パフォーマンスが虚偽表示される可能性があります。

コピー取引**ポートフォリオ概要**はNAVシェア会計を使用します。外部資本の流れによって株式が追加または削除され、1 株あたりの口座価値によって NAV が決まります。

```text
NAV = Account value / Shares
ROI = (Ending NAV / Starting NAV - 1) × 100%
```

統合証拠金口座およびポートフォリオ証拠金口座の場合、この計算では永久、スポット、ボールト、およびステーキングの価値を含む総合口座評価が使用されます。サポートされている他のアカウント モードでは、永久アカウント評価が使用されます。したがって、ポートフォリオ ROI は、その横に表示される永続的な PnL とは異なるスコープを持つことができます。

トレーダー統計やパフォーマンスレポートなどの他のサーフェスでは、異なる期間を使用して計算を返すことができます。たとえば、バックエンドのパフォーマンス レポートでは、Modified Dietz を使用してキャッシュ フローのタイミングに合わせて資本を調整します。すべての ROI ラベルが 1 つの式を使用すると仮定するのではなく、メトリック ツールチップと選択した範囲を読んでください。口座履歴や台帳データが欠落している場合、またはサポートされていないキャッシュ フローがある場合は、返品ができなくなる可能性があります。

### シャープレシオ

シャープレシオは、リターンボラティリティ単位当たりの超過リターンを測定します。一般に、値が高いほど、そのボラティリティに対する過去のリターンがより優れていることを示しますが、比較はサンプリング期間と手法によって異なります。将来のパフォーマンスを保証するものではありません。

### 最大ドローダウン

測定された履歴を通じて、ピークからその後の谷までの最大の観察された減少。これは過去の損失を説明するものであり、将来の損失の上限を示すものではありません。ドローダウンをリターン曲線および選択した期間と比較します。

### 勝率

```text
Win rate = Winning trades / Trades included in the metric × 100%
```

ビューが完了した取引、約定、または現在のポジションを測定しているかどうかを確認します。高い勝率だけでは収益性が確立されません。少数の大きな損失が、多くの勝ちトレードを上回る可能性があります。

### ボラティリティ

ボラティリティはリターンの変動を測定します。過去のボラティリティが低いということは、市場リスクを排除することなく、その期間における一連のリターンがよりスムーズであることを示しています。

## 取引ロジックのコピー

### トレーダーの評価

利用可能なフィルター、並べ替え、トレーダー履歴、リスク分析を組み合わせて使用します。有用な次元には、収益性、ドローダウン、取引頻度、ポジション集中、約定制約などが含まれます。ランキングや過去のスコアは、異なるアカウント サイズや料金レベルでも同じ結果がコピーできることを保証するものではありません。

### アカウントとポートフォリオ SL/TP

個々のコピー戦略には、ストップロス、テイクプロフィット、および高しきい値からのドローダウンを設定できます。ポートフォリオの概要では、コピー取引口座のグループをカバーする**ポートフォリオSL/TP**構成も提供されます。

ポートフォリオ SL/TP は、個別の損失、利食い、ドローダウンのしきい値を使用して、設定された初期資本と利益のベースラインを追跡します。対象のアカウントを確認し、間隔を確認し、保存または再調整するときに値をトリガーします。これは、1 つのポジションに対する逆指値注文よりも範囲が広くなります。

これらの制御装置は、その状態が検出されると保護閉鎖を開始できます。ポーリング間隔、データの可用性、流動性、実行は最終結果に影響します。設定されたしきい値は、正確な決済価格や元本の維持を保証するものではありません。 [リスク管理](/ja/advantages/risk-management)を参照してください。

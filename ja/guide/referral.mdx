# Owlyfi の紹介制度

紹介コードやリンクを共有して、友人を Owly に招待できます。招待した友人の対象取引アカウントで発生した Builder 手数料が精算に含まれると、直接紹介（L1）の報酬を受け取れます。その友人が招待したユーザーの取引からは、間接紹介（L2）の報酬を受け取れる場合があります。招待されたユーザーは、適用される条件に応じて、一定期間プラットフォーム取引手数料の割引を受けられます。

## 直接紹介（L1）と間接紹介（L2）

A が B を招待し、B が C を招待した場合は、次のようになります。

| 手数料を支払うユーザー | 報酬を受け取るユーザー | 適用する報酬率 |
| :--- | :--- | :--- |
| B | A が L1 報酬を受け取る | A のランクの L1 報酬率 |
| C | B が L1 報酬を受け取る | B のランクの L1 報酬率 |
| C | A が L2 報酬を受け取る | A のランクの L2 報酬率 |

精算の対象は L1 と L2 の報酬のみです。それぞれの報酬に、受取人自身のランクの報酬率が適用されます。C が割引対象であれば、直接の招待者である B のランクにかかわらず、C の手数料は 5% 割引になります。

## 紹介ランクと報酬

紹介ランクには Normal、Advanced、VIP があります。以下はデフォルトの条件です。実際の条件はプラットフォームの設定で変わる場合があります。

| ランク | 直接紹介の累計手数料の基準額 | L1 報酬率 | L2 報酬率 | 招待されたユーザーの手数料割引 | 割引期間 | 直接招待の上限 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Normal | $0 | 30% | 2% | 5% | 14 日間 | 5 人 |
| Advanced | $10 | 35% | 3% | 5% | 14 日間 | 20 人 |
| VIP | $500 | 40% | 5% | 5% | 14 日間 | 上限なし |

<Note>
ここに示す割引期間と招待上限はデフォルトで、プラットフォームの設定により変わる場合があります。現在のランク、招待枠、出金可能な報酬残高、報酬の記録は **紹介**ページで確認してください。
</Note>

ランクは、**アクティブな直接紹介（L1）の報酬記録に含まれる Builder 手数料の累計額**に基づいて自動判定されます。間接紹介（L2）の手数料、取引高、招待人数は判定に影響しません。ランクは精算後に再判定され、その後の精算には更新された報酬率が適用されます。ランクが変わっても精算済みの報酬は自動で再計算されません。アカウントによっては、ランクの指定や招待枠の個別調整が行われる場合があります。

直接の招待は、招待されたユーザーがまだ取引していなくても、紹介が紐づけられた時点で招待枠を 1 つ使います。間接紹介では直接招待の枠を消費しません。

## 報酬の計算基準

プラットフォームの Builder 手数料は戦略ごとに異なります。基本料率は、選択した戦略の設定に応じて **2–10 bps（0.02%–0.1%）** です。取引高が同じでも、戦略によって手数料と紹介報酬は異なります。紹介割引が適用される場合は、実際に支払う手数料も変わります。

報酬は **精算対象期間に実際に支払われた Builder 手数料 × 受取人に適用される報酬率** で計算します。対象となるのは、招待されたユーザーの現在アクティブな取引サブアカウントのうち、精算に含まれた取引から発生した手数料です。同じウォレットでも、他のアカウントやプラットフォームでの取引がすべて対象になるわけではありません。

招待されたユーザーが支払う手数料が減ると、報酬の計算基準額も減ります。Hyperliquid の取引所手数料、資金調達料、ネットワーク費用はこの計算に含まれません。

## 招待されたユーザーの手数料割引

紹介が紐づけられると、直接の招待者に適用されるランクの規則に基づいて、割引の有効期限が設定されます。初回取引を待たず、**紹介が紐づけられた時点**から割引が始まります。デフォルトの期間は 14 日間です。実際の期間は紐づけ時点の設定によって決まります。ブラウザーに紹介コードが保存される期間とは別です。

- 割引期間中は、対象の Owly 管理戦略で Builder 手数料の割引が自動で適用されます。
- すべての標準ランクで、**適用される Builder 手数料が 5% 割引**になります。招待者のランクが上がっても、割引率は変わりません。
- 招待者のランクが上がっても、すでに設定された割引期限は自動で延長されません。割引期間の満了だけで、紹介の紐づけや紹介報酬が終了することはありません。
- 割引によって、取引時に請求される手数料が減ります。割引分を別途出金する必要はありません。
- サードパーティーの Builder を使う戦略や、独自の低料率が維持される戦略には、標準の割引条件が上書き適用されません。取引前に適用料率を確認してください。

割引は、選択した戦略に適用される基本料率を基準に計算します。Builder 手数料の基本料率が **5.5 bps（0.055%）** で、招待されたユーザーに 5% の割引が適用される場合、理論上の割引後の料率は `5.5 × (1 − 5%) = 5.225 bps` です。5.5 bps は計算例です。実際の基本料率は、戦略の設定に応じて 2–10 bps になります。注文時に送信する料率は、取引インターフェースが対応する精度に合わせて切り上げられます。報酬には、約定に記録された実際の手数料が使われます。

取引手数料と Builder 手数料の承認上限の違いについては、[手数料体系](/ja/faq/fees)を参照してください。

## 招待者の判定

登録前は、**同じブラウザーで最初に開いた紹介リンク**を優先します。

1. 正しい形式の紹介コードを含むリンクを開くと、そのブラウザーの Cookie に最初のコードが最大 **30 日間**保存されます。コードが存在し、招待枠に空きがあるかは、登録時または紐づけ時に確認されます。
2. Cookie が有効な間は、後から別の紹介リンクを開いても保存済みのコードは変わりません。ログイン中のユーザーにすでに招待者がいる場合も、リンクを開いて招待者が変わることはありません。
3. 登録時に、保存されたコードで紐づけを試みます。サーバーがコードと招待枠の空きを確認し、コードが無効か枠が埋まっている場合はリクエストを拒否します。コードを使った自動登録が失敗した場合、画面にエラーが表示され、コードを使わずに再試行されます。登録完了後は、**紹介**ページで招待者が紐づけられているか確認してください。

Cookie は登録前に参照するデータです。Cookie を削除したとき、有効期限が切れたとき、別のブラウザーや端末を使ったときは、保存された紹介情報が失われることがあります。すでにアカウントに招待者が紐づいている場合、通常の手順では変更できません。登録時に招待者が紐づかなかった場合、条件を満たすユーザーは **紹介**ページで紹介コードを一度入力できます。

紹介コードは **英字、数字、アンダースコア、ハイフンのいずれかを使った 4–16 文字**です。英字の大文字と小文字は区別されません。紐づけ時にはコードの有効性、招待枠の空き、紹介の適用条件が確認されます。

## 報酬の記録と精算

定期処理で対象の取引手数料を取得し、取引サブアカウントごとの未精算期間の報酬を計算します。精算が成功すると、報酬記録と出金可能な報酬残高が同時に更新されます。処理を再実行しても、精算済みの期間について報酬が二重に支払われることはありません。

精算処理はデータ同期を待つため、報酬記録への反映に時間がかかる場合があります。反映時期は処理のスケジュール、アカウントの精算状況、データ提供元の稼働状況によって変わります。取引直後に出金可能な報酬が発生するわけではありません。API に一時的な問題がある場合は、その後の精算が成功するまで反映されません。

対象となる手数料の発生が記録されるまで、紹介のステータスが `pending` のままになる場合があります。**紹介**ページでは、招待したユーザー、取引したユーザー、報酬記録、出金履歴をそれぞれ確認できます。

### 過去の取引と精算時刻

- 新しい取引アカウントの初回精算では、以後の精算の起点が設定されます。それ以前のすべての取引が自動で報酬対象になるわけではありません。後から紹介コードを紐づけた場合も、過去の取引への遡及適用は保証されません。
- 照合待ちの既存アカウントは、照合が完了してから精算を再開できます。過去の報酬は自動で補填されません。
- 報酬記録の **精算時刻**は、報酬が実際に精算されて残高に反映された時刻です。精算日は処理上の会計日であり、すべての対象手数料が発生した日を示すものではありません。記録の作成時刻も精算時刻とは別です。過去の記録には精算時刻がないことがあるため、画面表示を確認してください。

### 出金

1. **紹介**を開き、出金可能な報酬残高を確認します。
2. 残高の範囲内で金額を入力します。現在の出金フォームでは最低 **1 USDC** が必要です。適用される出金規則で、さらに高い最低額が設定される場合があります。
3. 出金を申請します。処理中は、申請額が出金可能な報酬残高から差し引かれます。
4. 出金履歴を開き、最終ステータスと取引の参照情報を確認します。

| ステータス | 内容 |
| :--- | :--- |
| `pending` | 申請済みで審査待ち |
| `approved` | 審査で承認され、処理待ち |
| `processing` | 処理中 |
| `completed` | 処理が完了し、取引の参照情報が記録された状態 |
| `rejected` / `failed` | 審査で却下されたか、処理に失敗した状態。申請額は出金可能な報酬残高に戻り、理由が記録されます |

<Note>
申請した直後にオンチェーン送金が実行されるわけではありません。処理時間は一定ではないため、出金履歴で結果を確認してください。
</Note>

## 計算例

A と B にデフォルトの Normal ランクの報酬率が適用され、A が B を、B が C を招待したとします。この例では、割引と端数処理を適用した後の **実際の Builder 手数料率が 5.5 bps（0.055%）** と仮定します。

1. B が 10,000 USDC を取引し、実際の Builder 手数料が `10,000 × 0.055% = 5.50 USDC` になります。A は L1 報酬として `5.50 × 30% = 1.65 USDC` を受け取ります。
2. C が 20,000 USDC を取引し、実際の Builder 手数料が `20,000 × 0.055% = 11.00 USDC` になります。B は L1 報酬として `11.00 × 30% = 3.30 USDC` を、A は L2 報酬として `11.00 × 2% = 0.22 USDC` を受け取ります。
3. A が受け取る報酬の合計は `1.65 + 0.22 = 1.87 USDC` です。C が支払った同じ手数料に対し、B の L1 報酬と A の L2 報酬がそれぞれ計算されます。

5.5 bps はこの計算例の前提です。実際の料率は戦略ごとに異なります。例に示した報酬率は、現在適用されるランクの条件を示すものではありません。実際の金額は、適用される条件と精算済みの報酬記録を確認してください。

## 紹介の適用条件

自分自身の紹介や、関係が循環する紹介は拒否されます。適用されるランクや個別の招待枠で別途認められている場合を除き、紹介コードには使用回数の上限があります。架空のアカウントや作為的な取引などで紹介のルールを回避しないでください。

**コピー取引 → ポートフォリオ** を開いて、コピー取引口座をまとめて表示します。アカウント管理は**アカウント**で個別に利用でき、グリッド戦略は**取引ボット**に独自のページがあります。

## ポートフォリオの概要

概要には、対象コピー取引口座の 4 つの概要指標が表示されます。

<CardGroup cols={2}>
  <Card title="合計値" icon="dollar-sign">
    対象口座の現在の口座価値。これは単にUSDC で利用できるものではなく、オープンポジションの価値をすでにそれが含まれている株式残高に再度追加してはなりません。
  </Card>
  <Card title="合計 PnL" icon="trending-up">
    選択した期間の永続的なPnL を集約します。これは、入金または出金によって引き起こされる口座総額の変化とは異なります。
  </Card>
  <Card title="ROI" icon="percent">
    NAV株式会計および記録された資本フローを使用して計算されたリターン。評価範囲は各口座のモードによって決定されます。
  </Card>
  <Card title="アクティブコピーアカウント" icon="copy">
    現在アクティブとしてマークされているコピー取引口座の数。同じトレーダーをコピーする複数のアカウントは引き続き別々にカウントされます。
  </Card>
</CardGroup>

残高、戦略ステータス、履歴、収益計算を個別にロードできます。リソースが使用できないか不完全な場合、インターフェイスは読み込み状態、使用できない値、または更新通知とともに以前の成功したスナップショットを表示できます。欠損値はゼロを意味しません。

## 性能チャート

**PnL** と **アカウント値** を切り替えます。選択した系列によって、線が何を表すかが決まります。 PnL ラインは資本曲線ではありません。

利用可能な期間は、**1D、7D、30D、60D、90D、およびAll**です。 60D および 90D ビューは、利用可能な長い履歴から派生しています。 **すべて** は利用可能なアカウント履歴を使用しますが、必ずしもOwly の登録以降の時間ではありません。

チャートの利得/損失の色は、表示された PnL 状態に従います。口座価値曲線の各セクションを独立した収益期または損失期としてマークするわけではありません。

## トレーディングアカウントカードのコピー

各カードには、アカウントの残高、保存されたコピー設定、トレーダー情報、戦略ステータスが組み合わされています。利用可能な詳細を展開して、メトリクスとコピーされたトレーダーを検査します。ステータスと権限に応じて、アクションには設定、コピーの開始または停止、位置のクローズなどが含まれます。

| 商品 | 読み方 |
| :--- | :--- |
| **口座価値/資産** | アカウントの評価額、必ずしもすぐに出金できる金額ではありません |
| **PnL および性能詳細** | メトリクスの選択された期間とツールチップを読み取ります。アカウントカードと概要の期間は異なる場合があります |
| **コピートレーダー** | このアカウントのコピー戦略の送信元アドレス |
| **ステータス** | コピーがアクティブかアイドルか。アイドル戦略にはまだポジションがある可能性があります |
| **保存された設定** | アカウントの現在のコピー構成 (構成済みの SL/TP しきい値を含む) |

カードの短期収益指標は、記録されたキャッシュ フローに合わせて調整された資本と永続的な PnL を比較できます。それらの計算と資本の範囲は、概要のNAV ROIとは異なります。ツールチップとデータ警告、および表示されるパーセンテージを比較します。

コピーの停止とポジションのクローズは別の操作です。ストップダイアログの**ポジションを閉じる**オプションをチェックし、結果の口座ステータスとポジションを確認します。

## ポートフォリオを理解する ROI

この概要では、NAV 株式会計を使用して、外部資本の変化と収益を区別しています。

```text
NAV = Account value / Shares
ROI = (Ending NAV / Starting NAV - 1) × 100%
```

入金と出金は、追跡されたNAVを使用して株式を追加または削除します。統合証拠金口座およびポートフォリオ証拠金口座の場合、評価範囲には永久、スポット、Vault、およびステーキング資産が含まれます。サポートされている他のモードでは、永久アカウント値が使用されます。したがって、ポートフォリオは、表示される PnL が永続的な PnL のままである一方で、アカウント スコープを組み合わせることができます。

ROI は、必要な口座履歴、口座モード、元帳情報が確立できない場合、または関連するキャッシュ フローを分類できない場合には利用できません。利用できない値を単純な残高変更式で置き換えないでください。

## ポートフォリオ SL/TP

ポートフォリオ戦略コントロールを使用して、カバードコピー取引口座の損失、利益確定、および高値からのドローダウンのしきい値を設定します。対象となるアカウント、ベースライン、現在のトリガー値、およびチェック間隔を確認します。保存、無効化、再調整は別のアクションです。

<Tip>
同じ期間のPnL と ROI を比較し、手数料、資金調達、対象となるアカウントの範囲を確認します。計算と制御の境界については、[中核概念](/ja/guide/concepts) および[リスク管理](/ja/advantages/risk-management)を参照してください。
</Tip>

資金を移動する前に、**アカウントアドレス**、**ネットワーク**、**資産**を確認してください。 API ウォレットは取引署名者であり、資金提供されたアカウントや入金先ではありません。

## 正しいエントリーポイントを選択してください

| アカウントまたはエントリーポイント | 現在の資金の流れ |
| --- | --- |
| **取引ターミナル** | **入金** および **出金** は、ログインしているウォレットのHyperliquid アカウントで動作します |
| **API ウォレット設定** | 非アクティブな取引ウォレットは、埋め込み入金フローを使用して、承認前にHyperliquid アカウントをアクティブ化できます |
| **API アカウントのウォレット アカウント** | 資金管理は Hyperliquid に誘導されます。実際の取引ウォレットを接続する |
| **Hyperliquid アカウントのサブアカウント** | マスターウォレットを使用してHyperliquid 資金調達/送金フローに従います |
| **オンチェーンレンディング (アルファ)** | **入金**、**返済**、**出金**、**借入**、**資金移動**は埋め込みを開きますLeverAccインターフェース |
| **レガシー Owly 管理アカウント** | 新規預金と一般内部送金は廃止されます。サポートされている出金を使用して所有者に返却します |

取引ターミナルは任意のコピー取引口座に切り替わりません。資金を提供したいアカウントのアドレスがログイン情報と異なる場合は、そのアカウントでサポートされているフローを使用してください。 [アカウントタイプ](/ja/guide/account-types)を参照してください。

## 取引ターミナルを通じて入金

1. **Trade → Deposit** を開き、接続されている所有ウォレットを確認します。
2. **Arbitrum One メインネット** で**USDC** または **USDT** を選択します。 Hyperliquid への転送には USDC が使用されます。提供された準備ステップを通じて、まず USDT を USDC に交換する必要があります。
3. フォームに表示されているソースウォレット残高を準備します。 ETH が不十分な場合、ガスレスプロバイダーが構成され、サポートされている見積もりが利用可能な場合、USDC から ETH へのスワップが提供される場合があります。
4. 各見積もり、トークン許容量、ネットワーク料金、CCTP 料金、推定受取額を確認します。新しいHyperliquidアドレスには、表示されている**1USDCアクティベーション料金**も必要です。入金額は適用される手数料を超えなければなりません。ソースウォレットの準備状況のしきい値は、普遍的な最低入金額ではありません。
5. 要求された各ステップに自分で署名します。取引前に目的地の確認と入金されたHyperliquid残高を待ちます。

同じ埋め込み入金フローは、非アクティブな取引ウォレットのAPI ウォレット設定中に、その取引ウォレットがOwly ログインと異なる場合を含めて表示されることがあります。

<Note>
スワップは独自の資産を使用します: USDT からUSDC は USDT を使用し、ETH の準備には USDC を使用します。 「ガスレス」とは、無料のガス補助金を意味するものではありません。引用された支出制限とトークン承認制限は別のものです。スワップ支出が制限されている場合でも、見積もりでは無制限のトークン許容量をリクエストできます。
</Note>

## 取引ターミナルを通じて出金

**出金** 送信します **USDC 接続されている所有ウォレットに Arbitrum One**。アカウントはアクティブ化されている必要があります Hyperliquid 統合アカウントモードのユーザー。金額は次のとおりです。 **より大きい 0.2 USDC**、現在の出金手数料を超え、出金可能な残高に適合します。上記すべての金額を意味するものではありません 0.2 USDC 引き出し可能です。

所有するウォレットで署名する前に、受信者、ネットワーク、金額、手数料、および予想される受け取り額を確認してください。 API 取引署名者は、所有者の出金署名に代わるものではありません。受取残高が確認されるまで待ちます。リクエストの送信は到着の証明にはなりません。

## 保留中または中断された転送

元のウォレットとネットワークを選択したままにしておきます。 **ステータスの確認** を使用するか、既存の操作を再開します。利用可能な場合、**トランザクションの検索** により、フローは既存のソース トランザクションを検証できます。結果が不明な間は転送を繰り返さないでください。送信前に見積の有効期限が切れた場合は、新しい見積を取得して確認してください。

ブラウザのストレージを保留中の操作の回復に利用できるようにしておきます。サポートが必要な場合は、パブリック アドレス、ネットワーク、発行時刻、トランザクション ハッシュを提供してください。シード フレーズや秘密キーを決して提供しないでください。

## LeverAcc 資金と負債

LeverAcc アカウント作成は、現在の設定で必要な**Arbitrum USDC と ETH** および **HyperEVM HYPE** をチェックします。 ETH と HYPE の準備には、ページに示されている個別の USDC 予算があります。埋め込みインターフェイスの担保、借入、返済、および引き出しのルールに従ってください。

コピー取引を停止してもローンは返済されません。ポジションを決済しても、それ自体ですべての担保や債務が免除されるわけではありません。プロジェクトの撤退や縛りを変更する前に、負債と返済状況を個別に確認してください。

## 手数料と残高

資金調達には、ガス、スワップ、ブリッジ/CCTP、アクティベーション、プロトコル料金が発生する場合があります。ライブ見積もりを確認してください。固定到着時間もネットワークガスのみの料金モデルもすべてのルートに適用されません。 [料金体系](/ja/faq/fees)を参照してください。

**口座金額**と**出金可能残高**は異なります。ポジション、証拠金要件、スポット担保、借入は、出金できる額に影響を与える可能性があります。 API ウォレット アドレスではなく、Owly と Hyperliquid の同じ入金済みアカウント アドレスを比較します。

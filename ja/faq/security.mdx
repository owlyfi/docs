## ウォレットとトレーディングキーのセキュリティ

所有するウォレットを管理するのはあなたです。 Owly は、自動化された戦略で使用される API キーを生成および保存します。現在の取引端末は、その API 取引承認をこのデバイスのブラウザに永続的に保存します。秘密キーやシード フレーズをアシスタントやサポートに決して送信しないでください。 [非保管セキュリティ](/ja/advantages/non-custodial)を参照してください。

API ウォレットは、所有者の外部出金署名を置き換えることはできませんが、資金を失う取引を実行することはできます。署名者と権限の範囲を確認し、侵害された権限を所有するウォレットを通じて取り消します。ボットの停止、マネージャーの削除、API ウォレットの取り消しは別の操作です。

## 取引リスク

| リスク | それが意味するもの |
| --- | --- |
| **市場とレバレッジ** | 価格変動、資金調達コスト、清算により、アカウントの資本が減少または枯渇する可能性があります |
| **コピー実行** | レイテンシー、流動性、最小注文サイズ、市場フィルター、利用可能な担保により、ソースとは異なる約定やポジションが生成される可能性があります |
| **リスク閾値** | SL/TP 設定を構成する必要があります。モニタリングとクローズ注文が失敗したり、しきい値を超えてより悪い価格で実行される可能性があります |
| **グリッド露光** | 指向性グリッドはエクスポージャーを蓄積することができ、価格は設定された範囲を離れることができます |
| **データ制限** | 返品とリプレイは、利用可能な履歴、アカウントの範囲、データの鮮度によって異なります |

過去の実績は将来のパフォーマンスを保証するものではありません。ランキング スコア、シミュレーション、または読み取り専用の Ghost ビューは、戦略が適切であること、または戦略が正常にコピーされることを保証するものではありません。

## 資金調達とプロトコルのリスク

- 署名する前にルートのネットワークとトークンを確認してください。統合された入出金フローは、Arbitrum One メインネットをサポートします。 LeverAcc も HyperEVM を使用します。
- ガス、スワップ、ブリッジ/CCTP、アクティベーション、およびプロトコルの料金を個別に確認します。
- 保留中の提出物は不確実な場合があります。繰り返す前に既存の操作を確認してください。
- スマートコントラクト、ブリッジ、取引所、ウォレットソフトウェア、上流プロバイダーは失敗する可能性があります。コードの可用性だけではセキュリティ監査の証拠にはなりません。
- LeverAcc 担保と借入は利息と清算リスクをもたらします。取引を停止したり、ポジションを閉じたりしても借金は返済されません。

## インシデントの管理

1. 影響を受けるオートメーションを停止し、ポジションと未処理の注文を検査します。
2. 影響を受ける取引承認を取り消すか、所有ウォレットに置き換えます。 LeverAcc の場合は、実行ウォレットの更新フローに従います。
3. さらなる送金を行う前に、保留中の資金調達操作とトランザクションのハッシュを確認してください。
4. 公開アドレス、発行時間、編集された証拠を添えて、[Telegram サポート](https://t.me/owlyfi_support) または [security@owly.fi](mailto:security@owly.fi) に連絡してください。公開チャットで秘密や脆弱性を公開しないでください。

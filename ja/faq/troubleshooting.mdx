## ウォレットとセットアップ

| 症状 | 確認事項 |
| --- | --- |
| ウォレットが接続できません | ウォレットのロックを解除し、サイトの権限と競合する拡張機能を確認し、目的のアドレスで再試行します |
| 間違った署名ウォレット | Owly ログイン、取引所有者、および資金提供アドレスを比較します。それらは異なる場合があります。現在のステップで要求されたウォレットに戻ります |
| API ウォレットの設定で資金を要求しています | 所有アドレスはHyperliquid でまだアクティブ化されていません。埋め込みデポジットを完了し、統合アカウントと API 認証の前にアクティベーションを待ちます |
| アドレスが所有者として拒否されました | エージェント、ボールト、またはネイティブのサブアカウント アドレスではなく、所有する Hyperliquid ユーザー ウォレットを使用します |
| ネイティブのサブアカウントは利用できません | ログインしたマスターを確認し、リストを更新し、資格と容量のチェックに合格した場合にのみ作成オプションを使用します。 |
| アカウント制限に達しました | サポートされている 3 つのタイプはすべて、10 アクティブなOwly 取引口座の制限を共有します |
| API ウォレットの認証に失敗しました | 有効期限と利用可能なHyperliquid API ウォレットスロットを確認し、正しいマスターで保留中の認証を完了します |

期限切れの Owly ログインセッションと期限切れの Hyperliquid 取引許可は別の問題です。前者の場合は、再接続してサインインします。後者のアカウントの取引承認を更新します。

## 入金、スワップ、出金

- **正しいエントリーポイントを使用してください。** ログインした所有ウォレットで資金を取引します。アカウントは、API ウォレットおよびネイティブ サブアカウント ユーザーを Hyperliquid にリンクします。 LeverAcc ボタンは、組み込みインターフェースを開きます。 [資産管理](/ja/guide/asset-management)をご覧ください。
- **ネットワークまたは資産が間違っています:** 統合されたトレードフローは、Arbitrum One メインネットとデポジットUSDC を使用し、オプションでUSDT からUSDC への準備も可能です。 LeverAcc HYPE は HyperEVM に属します。トランザクションの実際のネットワークとトークンを確認します。
- **スワップは利用できません:** ガスレススワップは、プロバイダーの構成、サポートされている承認方法、残高、および新しい見積もりによって異なります。サポートされている見積もりが提供されていない場合は、必要なアセットを自分で準備します。
- **ETH は準備されましたが、HYPE がまだ見つかりません:** LeverAcc はそれらを個別にチェックします。残りの準備を完了し、残高を再確認します。
- **保留中または不明な送信:** 元の操作を再開し、ステータスを確認します。プロンプトが表示されたら、ソース トランザクション ハッシュを使用します。結果が判明するまで、別のトランザクションを送信しないでください。
- **出金が拒否されました:** 所有ウォレット ID、統一アカウント モード、出金可能残高、およびライブ料金を確認します。取引金額は、0.2 USDC と該当する手数料の両方を超える必要があります。
- **入金が表示されない:** 入金されたアカウントアドレス、ソーストランザクション、および宛先残高を比較します。ウォレットの送信が成功しても、Hyperliquid での信用は証明されません。

## 戦略とアカウントアクセス

| 症状 | 確認事項 |
| --- | --- |
| 従来の管理アカウントではボットを開始できません | このアカウント タイプは、起動/再起動/構成更新のために廃止されました。残りの自動化を停止または閉じて、サポートされている撤退ルートを使用します |
| LeverAcc はコピーを開始できません | プロジェクトのバインディング、実行ウォレットの承認、資金調達、および現在の利用可能性を確認します。保留中のオーダーのコピーはサポートされていません |
| LeverAcc がグリッドから欠落しています | 現在の Grid Bot アカウント セレクターは LeverAcc アカウントを除外します |
| 取引はコピーされませんでした | ボットの状態、認証の有効性、利用可能な担保、有効な市場、コインフィルター、最小サイズ、ソースアクティビティを確認します |
| 異なるポジションサイズまたはエントリー価格 | コピー率、市場の動き、四捨五入、設定されたフィルター、およびマージンの利用可能性により約定が変化する可能性があります |
| マネージャーは削除されましたが、ボットはまだ実行中です | 管理アクセスを削除してもボットは停止しません。所有者はボットを個別に停止または閉じる必要があります |
| グリッドトレーリングコントロールは無効です | トレーリングは現在、ユーザー インターフェイスでは使用できません。保存されたバックエンドフィールドではここでは有効になりません |

SL/TP のしきい値は、保護のデフォルトとして自動的に設定されません。保存された設定と[リスク管理](/ja/advantages/risk-management)を確認してください。

## 天びんとチャート

同じ取引口座アドレスと期間を比較します。アカウントの金額は引き出し可能な残高ではありません。評価範囲またはキャッシュ フロー履歴が確立できない場合、ROI は利用できない場合があります。ゼロとして読み取ってはいけません。メトリック定義を更新して、[ポートフォリオとナビゲーション](/ja/guide/dashboard)を確認します。

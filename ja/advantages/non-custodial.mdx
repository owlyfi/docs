Owly はウォレット署名と認可された取引キーを通じて取引アカウントを接続します。ファンドの所有権と取引キーの保管は異なります。所有するウォレットを管理するのはあなたですが、認可されたAPI ウォレットは取引を実行して損失を被る可能性があります。

## アカウントと主要な役割

| 役割 | 現在の動作 |
| --- | --- |
| **Owly ログインウォレット** | サインインしてアカウントを管理します。取引所有者になることもできます |
| **取引オーナー/マスターウォレット** | 資金提供された口座を保持または管理し、所有者が必要とする承認と引き出しに署名します。 |
| **コピートレード API ウォレット** | セットアップ中にOwly によって生成および保存されます。承認された戦略アクションに署名するために使用される |
| **取引ターミナルAPI ウォレット** | 現在の取引インターフェースによってこのデバイスのブラウザに永続的に保存されます |
| **LeverAcc 実行ウォレット** | プロトコルのプロジェクト バインディングを通じて承認されます。担保と借金はLeverAccのルールに従います |

現在の 3 つのセットアップ パスについては、「[アカウント タイプ](/ja/guide/account-types)」を参照してください。 API ウォレット パスでは、ネイティブ Hyperliquid サブアカウントを作成する必要はありません。

## 認可によって許可されること

API ウォレットは、ポジションのオープンとクローズを含む、サポートされている取引アクションに署名できます。これは、所有するウォレットの外部出金署名を置き換えるものではありません。これは、エージェントにプロトコル内部の資金権限がないことを意味するものではありません。

署名する前に、接続されている所有者アドレス、API ウォレット アドレス、有効期限、ビルダー料金制限、および契約トランザクションを確認してください。デポジットとスワップには個別のトークンの承認が必要になる場合があります。トークンの承認制限は、見積もられたスワップ支出制限とは異なります。

<Warning>
取引 API キーの漏洩により、悪意のある取引や損失が発生する可能性があります。非保管ファンドの所有権は、市場の損失、清算、悪意のある取引、またはプロトコルの失敗から保護されません。
</Warning>

## アクセスの保護と取り消し

- シードフレーズ、所有ウォレットの秘密鍵、取引API キーをアシスタント、サポート、チャットに決して送信しないでください。
- 取引承認には信頼できるデバイスを使用してください。ブラウザのストレージをクリアすると、ローカルに保存された取引資格情報と保留中の操作の回復が削除される場合があります。 Hyperliquid 認証は取り消されません。
- 影響を受けるボットを停止し、残りのポジションとオーダーを検査します。 API ウォレットを取り消すには、[Hyperliquid の API ページ](https://app.hyperliquid.xyz/API) で所有するマスターウォレットを使用します。
- 再起動する前に、対応する Owly 認証を更新します。 LeverAcc は、専用の実行ウォレット更新フローを使用します。
- Owly ファンドマネージャーを削除すると、管理アクセスが削除されます。実行中のボットを自動的に停止したり、プロトコルの承認を取り消したりすることはありません。

資金調達のエントリーポイントと所有者の署名については、[資産管理](/ja/guide/asset-management)をお読みください。委任範囲については、[アセットオーナー向け](/ja/guide/owner-guide)をお読みください。

Owly は戦略アクションを Hyperliquid に送信し、実行結果が利用可能になるとアカウントの状態を更新します。コピー、取引所の受け入れ、約定、ポートフォリオの更新は別の段階です。

## 実行に影響を与えるもの

| ステージ | 何が影響するのか |
| --- | --- |
| **音源観測** | データの鮮度と情報源の市場活動 |
| **戦略決定** | アカウントの状態、コピー率、有効な会場、コインフィルター、リスク設定 |
| **注文送信** | オーソリゼーションの有効性、最小注文サイズ、担保、為替ルール |
| **フィル** | 注文タイプ、価格、流動性、部分約定、市場の動き |
| **表示更新** | WebSocket 接続、API 可用性、およびキャッシュまたは更新されたデータ |

送信された注文は、オープンのままになるか、部分的に約定されるか、または拒否される場合があります。開始リクエストが成功したということは、すべてのソース ポジションがすでにコピーされていることを意味するのではなく、ストラテジー リクエストが受け入れられたことを意味します。

## コピーと同期

コピー設定には、定期的なポジション、スポット、レバレッジ、およびオプションの未決注文の同期が含まれます。それぞれに独自の有効状態と間隔があります。同期間隔は、エンドツーエンドの実行を保証するものではありません。 LeverAcc は未決注文のコピーをサポートしていません。

Grid Bot は、設定されたグリッドを独自の間隔で調整します。その動作とアカウント要件については、[Grid Bot](/ja/guide/grid-bot) で説明されています。

## 結果の確認

1. ボットの現在の状態と報告されたエラーを確認します。
2. 部分注文または拒否された注文を含む、実際の注文と約定を検査します。
3. ソースとの違いを判断する前に、同じ市場とアカウント範囲を比較してください。
4. 停止またはクローズ後、残りの注文、ポジション、クリーンアップ状況を検査します。

Owly のソース実装では、固定レイテンシーまたはスリッページ保証が確立されていません。市場の状況と上流の可用性が結果に影響します。実行が予想と異なる場合は、[トラブルシューティング](/ja/faq/troubleshooting)を参照してください。

チームの非同期 Hyperliquid SDK については、「[async-hyperliquid](https://github.com/owlyfi/async-hyperliquid)」を参照してください。 SDK ベンチマークは独自のテスト条件を記述したものであり、ユーザーの取引レイテンシーを保証するものとして扱うべきではありません。

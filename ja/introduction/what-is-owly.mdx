## 概要

**Owly** は、トレーダーの検索、コピートレード、取引端末、自動売買戦略を [Hyperliquid](https://hyperliquid.xyz) で利用できるようにします。アカウント管理から、取引に使用するウォレットや対応プロトコルのアカウントを接続できます。操作手順はサイト内のアシスタントに確認できます。

## Owly の使命

高度な取引戦略を、プロのトレーダーに限らず誰でも利用できるようにすることが、Owly の目標です。

<Steps>
  <Step title="探す">
    プラットフォーム上の確認済みトレーダーの実績を閲覧し、分析できます。
  </Step>
  <Step title="接続する">
    API ウォレット、Hyperliquid のネイティブサブアカウント、LeverAcc アカウントのいずれかを追加し、必要な承認を行います。
  </Step>
  <Step title="運用状況を確認する">
    ボットの稼働状況、約定、ポジション、リターンを確認できます。必要に応じてリスク設定を見直し、戦略を停止できます。
  </Step>
</Steps>

## 主な機能

| 機能 | できること |
| --- | --- |
| **トレーダーの検索** | 実績やリスク指標を使ってトレーダーを探せます |
| **コピートレード** | アカウントごとに戦略、対象市場のフィルター、ポートフォリオのリスク閾値を設定できます |
| **取引端末** | 手動取引、画面内からの入出金、Ghost モードでの閲覧専用モニタリングを利用できます |
| **グリッドボット** | 専用の「取引ボット」ページから、無期限先物の中立・ロング・ショートのグリッド戦略を利用できます |
| **アカウント** | 自動生成された API ウォレットの承認、ネイティブサブアカウントの設定、LeverAcc（Alpha）を利用できます |
| **ポートフォリオ** | アカウントの評価額、損益、資金の流出入を考慮したリターン、操作履歴を確認できます |
